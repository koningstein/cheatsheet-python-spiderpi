M4.5: Method Overriding (Servo)

Uitleg: Gedrag Specialiseren

De standaard .reset() van de Parent class is niet nuttig genoeg voor een Servo. Een Servo-reset moet iets specifieks doen: naar 90 graden gaan.

Dit noemen we Method Overriding (Overschrijven). We maken in de Child class (Servo) een methode met exact dezelfde naam als in de Parent class. Python zal dan de methode van het Child kiezen in plaats van die van de Parent.

Stap 1: Override in Servo

Open spiderpi_core/servo.py en voeg de reset methode toe. 

# In spiderpi_core/servo.py
class Servo(RobotComponent):
    # ... (rest van de code) ...

    # DIT IS DE OVERRIDE:
    def reset(self) -> None:
        """
        Overschrijft de standaard reset.
        Een Servo reset zet de hoek naar 90 graden.
        """
        print(f"SERVO RESET: {self.name} going to 90 degrees.")
        self.set_angle(90.0) # Specifiek gedrag voor een Servo

Stap 2: Testen

We testen nu opnieuw. 

# In main.py
motor = Servo(1, 150.0) # Zet hem eerst op 150
motor.reset()           # Reset hem
print(f"Current angle: {motor.current_angle}")

Uitleg: Het Resultaat

Output:
SERVO RESET: Servo_1 going to 90 degrees.
Current angle: 90.0

De saaie tekst van de Parent class ("STANDARD reset") is weg. De Child class heeft het overgenomen.
