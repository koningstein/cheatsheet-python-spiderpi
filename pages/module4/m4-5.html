M4.5: Method Overriding (Servo)

Theorie: Gedrag Specialiseren

Probleem: De standaard .reset() (Les 4.4) is niet nuttig. Een Servo reset zou iets specifieks moeten doen: naar 90 graden gaan.

Oplossing: Method Overriding (Methode Overschrijven). We definiëren in de Kind-klasse (Servo) een methode met exact dezelfde naam als in de Ouder-klasse (RobotComponent).

Python zal dan *altijd* de methode van het Kind kiezen. Het "kind" overschrijft het gedrag van de "ouder".

Python Voorbeeld (`servo.py`)

We voegen de reset methode toe aan Servo, die de reset van RobotComponent zal overschrijven.

# In spiderpi_core/servo.py
class Servo(RobotComponent):
    # ... (init, set_angle, etc.)

    # DIT IS DE OVERRIDE:
    def reset(self) -> None:
        """
        Overschrijft de standaard reset.
        Een Servo reset zet de hoek naar 90 graden.
        """
        print(f"SERVO RESET: {self.name} gaat naar 90 graden.")
        self.set_angle(90.0) # Specifiek gedrag
