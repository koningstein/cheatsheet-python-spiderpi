M4.2: Overerving Toepassen

Uitleg: De Child Class Koppelen

Nu we de Parent class (RobotComponent) hebben, moeten we de Child classes (Servo, Leg) vertellen wie hun Parent is.

In Python gebruiken we hiervoor haakjes () achter de klassenaam. Dit vertelt Python dat Servo nu automatisch alle methoden en properties van RobotComponent "erft".

class Servo(RobotComponent): betekent: "Ik ben een Servo, en ik ben ook een RobotComponent."

Stap 1: Servo aanpassen

Open spiderpi_core/servo.py. We moeten eerst de Parent class importeren en dan de klassenaam aanpassen. 

# In spiderpi_core/servo.py

# 1. Importeer de Parent class
from .component import RobotComponent

# 2. Geef de Parent aan tussen de haakjes
class Servo(RobotComponent):
    """
    Servo 'IS EEN' RobotComponent.
    """
    # ... (rest van de code laten we even staan)

Stap 2: Leg aanpassen

Doe hetzelfde voor spiderpi_core/leg.py. 

# In spiderpi_core/leg.py

from .component import RobotComponent # Importeren
from .servo import Servo

class Leg(RobotComponent): # Koppelen aan Parent
    # ...

Uitleg: De Crash

Als je nu main.py probeert te draaien, zal je code crashen met een foutmelding: TypeError.

Waarom? De Parent class (RobotComponent) verwacht een name in zijn constructor. Maar onze Child classes (Servo, Leg) hebben hun eigen constructor en roepen die van de Parent niet aan. Dat lossen we op in de volgende les.
