M4.2: Overerving Toepassen

Theorie: Het 'Kind' Koppelen

Nu we de Ouder (RobotComponent) hebben, moeten we de kinderen (Servo, Leg) vertellen wie hun ouder is.

In Python gebruiken we hiervoor haakjes () achter de klassenaam. Dit vertelt Python dat Servo nu automatisch alle methoden en properties van RobotComponent "erft".

class Servo(RobotComponent): betekent: "Ik ben een Servo, en ik ben ook een RobotComponent."

Python Voorbeeld

We passen servo.py, leg.py en robot.py aan.

In spiderpi_core/servo.py:

# Importeer de Ouder-klasse
from .component import RobotComponent

# Geef de Ouder aan tussen de haakjes
class Servo(RobotComponent):
    """
    Servo 'IS EEN' RobotComponent.
    Het erft nu .name en .__init__(name)
    """

    def __init__(self, start_id: int, start_angle: float) -> None:
        # ... (doet nog niks met de ouder, dit crasht!)
        self._id = start_id
        # ...

In spiderpi_core/leg.py:

# Importeer de Ouder-klasse
from .component import RobotComponent
from .servo import Servo

# Geef de Ouder aan tussen de haakjes
class Leg(RobotComponent):
    # ... (de rest van de klasse)

Testen (CRASH!)

Als je nu main.py draait, crasht de code. Dit is de *bedoeling*!

(venv) C:\...> python main.py
# ...
# TypeError: __init__() missing 1 required positional argument: 'name'

Dit gebeurt omdat de __init__ van Servo wordt aangeroepen, maar Python weet dat zijn Ouder (RobotComponent) een name verwacht in *zijn* __init__. Die geven we nog niet mee. Dat lossen we in de volgende les op.
