M4.7: Polymorfisme (Vele Vormen)

Uitleg: Alles is een Component

Polymorfisme is een moeilijk woord voor een simpel idee: "Vele Vormen".

Omdat zowel Servo als Leg "kinderen" zijn van RobotComponent (de Parent), mogen we ze allebei behandelen als "gewoon een component".

De Kracht: We kunnen een lijst maken met allerlei verschillende objecten (Servo's en Poten door elkaar). We kunnen over die lijst "loopen" en op elk item .reset() aanroepen. We hoeven niet te weten wat het is. Python kiest automatisch de juiste versie van reset().

Stap 1: Een gemengde lijst maken

In main.py maken we een lijst met willekeurige onderdelen. 

# In main.py
from spiderpi_core.servo import Servo
from spiderpi_core.leg import Leg

# Een 'gemixte' lijst.
# Het zijn allemaal RobotComponents.
my_components = [
    Servo(1, 120.0),
    Leg(10, 11, 12),
    Servo(2, 45.0)
]

Stap 2: Polymorfisme in Actie

Nu gaan we de lijst af. We weten niet of component een Servo of een Leg is. En het boeit ons ook niet! 

print("--- START RESET ---")

for component in my_components:
    # We roepen .reset() aan.
    # Python kijkt: "Wat ben jij? Een Servo? Dan doe ik de Servo-reset."
    # "Ben jij een Leg? Dan doe ik de Leg-reset."
    component.reset()

print("--- DONE ---")

Uitleg: Het Resultaat

Dit is de output. Zie hoe het gedrag verschilt per regel! 

--- START RESET ---
SERVO RESET: Servo_1 going to 90 degrees.
LEG RESET: Leg_10_11_12 resetting all servos.
(Hier volgen 3 servo resets van de poot...)
SERVO RESET: Servo_2 going to 90 degrees.
--- DONE ---
