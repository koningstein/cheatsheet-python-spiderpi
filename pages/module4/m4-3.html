M4.3: super() Gebruiken

Uitleg: De Parent Bellen

We crashten in de vorige les omdat de Parent class niet werd geïnitialiseerd. Wanneer een Child class (Servo) zijn eigen __init__ heeft, wordt de __init__ van de Parent class (RobotComponent) genegeerd.

De Oplossing: We moeten de __init__ van het Child ook de __init__ van de Parent laten aanroepen. Dit doen we met de functie super().

super() betekent letterlijk: "mijn Parent class".

Stap 1: Servo Repareren

In servo.py voegen we de super() aanroep toe. We moeten een naam bedenken voor de servo (bv. Servo_1). 

# In spiderpi_core/servo.py

    def __init__(self, start_id: int, start_angle: float) -> None:

        # 1. Roep EERST de __init__ van de PARENT aan
        # We geven het een logische naam (bv. "Servo_1")
        super().__init__(name=f"Servo_{start_id}")

        # 2. Doe DAN je eigen child-specifieke dingen
        self._id = start_id
        self.set_angle(start_angle)

Stap 2: Leg Repareren

Hetzelfde doen we voor leg.py. 

# In spiderpi_core/leg.py

    def __init__(self, id_hip: int, id_knee: int, id_ankle: int) -> None:
        # 1. Parent aanroepen
        super().__init__(name=f"Leg_{id_hip}_{id_knee}_{id_ankle}")

        # 2. Eigen dingen doen
        self._hip_servo = Servo(start_id=id_hip, start_angle=90.0)
        # ... (rest van de init)

Stap 3: Testen

Als je nu main.py draait, werkt alles weer! En je zult in de output zien dat de Parent class ook zijn werk doet. 

Component 'Servo_1' initialized.
Component 'Leg_1_2_3' initialized.

Je ziet nu twee berichten: eentje van de Parent (Component...) en eentje van het Child (indien aanwezig).
