M4.3: super() Gebruiken

Theorie: De Ouder Constructor Aanroepen

Probleem: We crashten in Les 4.2. Waarom? Wanneer een 'kind'-klasse (Servo) zijn *eigen* __init__ definieert, "vervangt" (override) het de __init__ van de 'ouder' (RobotComponent). De __init__ van de ouder (die de name instelt) wordt dus *nooit* aangeroepen.

Oplossing: We moeten de __init__ van het kind *ook* de __init__ van de ouder laten aanroepen. Dit doen we met super().

super() verwijst naar de "ouder-klasse". super().__init__(...) roept de constructor van de ouder aan.

Python Voorbeeld (`servo.py`)

We repareren de __init__ in Servo (en ook in Leg en SpiderPi).

from .component import RobotComponent

class Servo(RobotComponent):

    def __init__(self, start_id: int, start_angle: float) -> None:

        # 1. Roep EERST de __init__ van de OUDER aan
        # We geven het een logische naam
        super().__init__(name=f"Servo_{start_id}")

        # 2. Doe DAN je eigen kind-specifieke dingen
        self._id = start_id
        self._current_angle = start_angle
        print(f"Servo {self.name} specifiek geïnitialiseerd.")

    # ... (rest van de Servo klasse)

# --- In main.py ---
