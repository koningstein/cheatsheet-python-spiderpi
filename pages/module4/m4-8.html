M4.8: Protected (Conventie en Overerving)

Uitleg: Delen met de Familie

We hebben in M3.3 geleerd dat _property (met underscore) betekent: "Blijf af, dit is privé".

Maar bij overerving is er een nuance. protected (_) betekent eigenlijk: "Dit is voor intern gebruik, EN voor mijn Child classes".

Een Child class (Servo) mag dus wel aan de protected properties van zijn Parent class (RobotComponent) komen.

Stap 1: Parent class aanpassen

We voegen een "configuratie" variabele toe aan de Parent in component.py. We maken hem _protected. 

# In spiderpi_core/component.py
class RobotComponent:
    _name: str
    _config: dict # Nieuwe protected property

    def __init__(self, name: str) -> None:
        self._name = name
        # Data die de Parent beheert, maar die kinderen mogen lezen
        self._config = {"version": "1.0", "maker": "Techniek College"}

Stap 2: Child class leest Parent-data

In Servo (het Child) gaan we deze data lezen en printen tijdens de reset. 

# In spiderpi_core/servo.py
class Servo(RobotComponent):
    # ...

    def reset(self) -> None:
        # Het Child mag bij _config van de Parent!
        version = self._config["version"]
        print(f"SERVO RESET: {self.name} (Version: {version})")
        self.set_angle(90.0)

Stap 3: Testen

# In main.py
from spiderpi_core.servo import Servo

s = Servo(1, 100)
s.reset()

Uitleg: Resultaat

SERVO RESET: Servo_1 (Version: 1.0)

Het werkt! Het Child heeft succesvol in de "privé-spullen" van de Parent gekeken. Dit mag, omdat ze familie zijn. Een buitenstaander (zoals main.py) mag dit niet doen (s._config is verboden terrein).
