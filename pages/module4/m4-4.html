M4.4: Methode Definitie (Parent)

Uitleg: Gedrag Delen

Een groot voordeel van overerving: je kunt gedrag (methoden) definiëren in de Parent class, en alle Child classes krijgen dat gedrag gratis.

We willen dat elk component een .reset() methode heeft. Als we dit in RobotComponent zetten, hebben Servo en Leg het automatisch ook.

Stap 1: Reset toevoegen aan Parent

Open spiderpi_core/component.py en voeg de methode toe. 

# In spiderpi_core/component.py
class RobotComponent:
    # ... (init en properties) ...

    def reset(self) -> None:
        """
        Voert een standaard reset uit voor dit component.
        """
        print(f"Component '{self.name}' performing STANDARD reset.")

Stap 2: Testen in main.py

Je hoeft servo.py of leg.py niet aan te passen. Ze hebben de methode nu "geërfd". 

# In main.py
from spiderpi_core.servo import Servo

# Maak een servo
motor = Servo(1, 90.0)

# Roep de geërfde methode aan
motor.reset()

Uitleg: Het Resultaat

In de terminal zie je nu:
Component 'Servo_1' performing STANDARD reset.

Het werkt! Maar... een "standaard reset" doet eigenlijk niks. Een servo moet naar 90 graden bewegen bij een reset. Dat gaan we in de volgende les fixen.
