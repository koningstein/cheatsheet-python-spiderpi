M4.4: Methode Definitie (Ouder)

Theorie: Gedeeld Gedrag

Een groot voordeel van overerving: je kunt gedrag (methoden) definiëren in de Ouder-klasse (RobotComponent), en alle kinderen (Servo, Leg) *krijgen dat gedrag gratis*.

Als we willen dat *elk* component een .reset() methode heeft, definiëren we een *standaard* (default) implementatie in de ouder. Elk kind-object kan deze methode nu aanroepen, ook al hebben we servo.py of leg.py niet aangepast.

Python Voorbeeld (`component.py`)

We voegen de standaard reset() methode toe aan de Ouder-klasse.

# In spiderpi_core/component.py
class RobotComponent:
    # ... (init en name getter)

    def reset(self) -> None:
        """
        Voert een standaard reset uit voor dit component.
        Kinderen *mogen* dit overschrijven (zie M4.5).
        """
        print(f"Component '{self.name}' voert een STANDAARD reset uit.")

# --- In main.py ---
# (Je hoeft servo.py of leg.py NIET aan te passen)

# Roep de geërfde methode aan
# test_servo.reset()
# test_leg.reset()
