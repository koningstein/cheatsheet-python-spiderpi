M4.6: Method Overriding (Leg)

Uitleg: Overerving + Delegatie

We gaan nu ook de Leg (poot) zijn eigen reset() geven. Maar wat betekent een reset voor een poot?

Een poot resetten betekent: "Vertel al jouw onderdelen (de 3 servo's) dat zij moeten resetten."

We combineren hier twee technieken: 1. Overerving: We overschrijven de Parent-methode. 2. Delegatie: We geven het werk door aan de servo's (Compositie).

Stap 1: Override in Leg

Open spiderpi_core/leg.py en voeg de reset methode toe. 

# In spiderpi_core/leg.py
class Leg(RobotComponent):
    # ...

    # DIT IS DE OVERRIDE:
    def reset(self) -> None:
        """
        Overschrijft de standaard reset.
        Een Leg reset delegeert de reset aan zijn 3 servo's.
        """
        print(f"LEG RESET: {self.name} resetting all servos.")

        # Delegatie! (We roepen de .reset() van de kinderen aan)
        self.hip_servo.reset()
        self.knee_servo.reset()
        self.ankle_servo.reset()

Stap 2: Testen

# In main.py
from spiderpi_core.leg import Leg

leg = Leg(1, 2, 3)
leg.reset()

Uitleg: De Kettingreactie

Je ziet nu een mooie kettingreactie in de output: 

LEG RESET: Leg_1_2_3 resetting all servos.
SERVO RESET: Servo_1 going to 90 degrees.
SERVO RESET: Servo_2 going to 90 degrees.
SERVO RESET: Servo_3 going to 90 degrees.

De poot reset zichzelf door zijn onderdelen te resetten.
