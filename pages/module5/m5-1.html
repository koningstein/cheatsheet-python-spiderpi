M5.1: Abstract Base Class (ABC)

Theorie: Het 'Contract' (Deel 1)

Probleem: In Module 4 (Polymorfisme) [cite: 247-248] maakten we een for-loop die component.reset() aanriep. Dit *werkte* alleen omdat we *toevallig* in Servo en Leg een reset() methode hadden geïmplementeerd. Wat als we het vergeten? De code crasht.

Oplossing: Een Abstract Base Class (ABC). Dit is een 'ouder'-klasse die dient als een contract. We kunnen deze klasse "abstract" maken om later regels af te dwingen.

In Python doen we dit door de klasse te laten erven van ABC (die we moeten importeren). Dit is stap 1.

Python Voorbeeld (`actions.py`)

We maken een nieuw bestand spiderpi_core/actions.py voor al onze robot-acties.

# We importeren ABC (Abstract Base Class)
from abc import ABC, abstractmethod
from spiderpi_core.robot import SpiderPi # Aanname dat robot.py bestaat

# Stap 1: Laat de klasse erven van ABC
class AbstractRobotAction(ABC):
    """
    Dit is nu een 'abstracte' klasse.
    Het dient als een contract voor alle acties.
    """
    _robot: SpiderPi

    def __init__(self, robot: SpiderPi) -> None:
        """Initialiseert de actie met de robot die hij moet besturen."""
        self._robot = robot
        print("Abstracte actie wordt voorbereid...")
