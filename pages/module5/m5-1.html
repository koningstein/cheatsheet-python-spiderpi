M5.1: Abstract Base Class (ABC)

Uitleg: Het Contract (Deel 1)

In de vorige module maakten we een lijst met reset() commando's. Dat werkte omdat we toevallig in zowel Servo als Leg een reset methode hadden gemaakt. Maar wat als we dat vergeten waren? Dan crasht de code.

We willen dit afdwingen. We willen een Contract maken.

Een Abstract Base Class (ABC) is een speciale Parent class die dient als zo'n contract. Je kunt van deze klasse zelf geen objecten maken (je kunt geen "Contract" bouwen, alleen iets dat zich aan het contract houdt).

Stap 1: De Abstracte Klasse Maken

We maken een nieuw bestand spiderpi_core/actions.py. We importeren de ABC module uit Python. 

# In spiderpi_core/actions.py

# We importeren ABC (Abstract Base Class)
from abc import ABC
from .robot import SpiderPi

# Stap 1: Laat de klasse erven van ABC
class AbstractRobotAction(ABC):
    """
    Dit is nu een 'abstracte' klasse.
    Het dient als een contract voor alle acties.
    """
    _robot: SpiderPi

    def __init__(self, robot: SpiderPi) -> None:
        """Initialiseert de actie met de robot die hij moet besturen."""
        self._robot = robot
        print("Abstract action initialized.")

Uitleg: Wat hebben we nu?

We hebben nu een klasse die "Abstract" heet. Maar... hij doet nog niks bijzonders. We kunnen er nog steeds objecten van maken.
