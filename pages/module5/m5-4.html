M5.4: Implementatie (Complex)

Theorie: Hergebruik en Delegatie

Dit is een *herhaling* van de vorige les, maar nu met een complexere implementatie. We maken een WaveAction die het execute-contract vervult.

In plaats van *nieuwe* code te schrijven, kan de execute methode ook *bestaande* code hergebruiken. We delegeren (M1.9) [cite: 58-59] het werk aan de wave() methode die al in onze SpiderPi-klasse (M3.7) [cite: 245-246] bestaat.

Dit is "clean code": de WaveAction-klasse is alleen de 'knop', de SpiderPi-klasse bevat de 'logica'.

Python Voorbeeld (`actions.py`)

We voegen een *tweede* concrete klasse toe en testen met Polymorfisme (M4.7) [cite: 247-248].

# In spiderpi_core/actions.py
# ... (AbstractRobotAction en WalkAction) ...

class WaveAction(AbstractRobotAction):
    """
    Een TWEEDE CONCRETE actie. Vervult ook het contract.
    DELEGEERT het zwaai-werk aan de SpiderPi klasse.
    """

    def execute(self) -> None:
        """
        Implementatie van het 'execute' contract.
        """
        print("Actie: Zwaaien...")

        # We hebben self._robot (een SpiderPi object)
        # en die *heeft* al een wave() methode!
        self._robot.wave() # Delegatie!

# --- In main.py (Polymorfisme!) ---
from spiderpi_core.actions import WalkAction, WaveAction

acties = [
    WalkAction(my_robot),
    WaveAction(my_robot)
]

print("--- Start Polymorfische Actie Loop ---")
for actie in acties:
    actie.execute() # Python kiest automatisch de juiste!
