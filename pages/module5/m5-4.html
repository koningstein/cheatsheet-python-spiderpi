M5.4: Implementatie (Complex)

Uitleg: Hergebruik en Delegatie

We maken nu een tweede actie: WaveAction (Zwaaien).

We hebben in Module 3 al een wave() methode gemaakt in de SpiderPi-klasse. We willen die code niet overtypen (kopiëren).

We gebruiken Delegatie. De WaveAction is alleen de 'knop'. Als je op de knop drukt (execute), vraagt hij de robot om het echte werk te doen.

Stap 1: WaveAction Maken

We voegen de tweede actie toe aan actions.py. 

# In spiderpi_core/actions.py
# ... (WalkAction) ...

class WaveAction(AbstractRobotAction):
    """
    Een TWEEDE CONCRETE actie.
    """

    def execute(self) -> None:
        print("Action: Waving...")

        # We hebben self._robot (een SpiderPi object)
        # en die *heeft* al een wave() methode!
        self._robot.wave() # Delegatie!

Stap 2: Polymorfisme Testen

Nu komt de echte kracht. We maken een lijst van acties. Omdat ze allebei dezelfde Parent hebben (en het contract volgen), kunnen we ze hetzelfde behandelen. 

# In main.py
from spiderpi_core.actions import WalkAction, WaveAction

# Maak een lijst met verschillende acties
actions_list = [
    WalkAction(my_robot),
    WaveAction(my_robot)
]

print("--- Start Action Loop ---")
for action in actions_list:
    # We weten niet wat voor actie het is...
    # Maar we weten ZEKER dat hij .execute() heeft!
    action.execute()

print("--- Done ---")
