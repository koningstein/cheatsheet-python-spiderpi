M5.2: Abstracte Methoden

Uitleg: De Eis (Het Contract)

Een Abstracte Klasse wordt pas krachtig als we het combineren met Abstracte Methoden.

Dit betekent: "Ik (de Parent) heb geen code voor deze methode, maar ik eis dat elk Kind (Child class) deze methode zelf implementeert."

We gebruiken hiervoor de decorator @abstractmethod.

Stap 1: De Eis Toevoegen

We passen actions.py aan. We eisen dat elke actie een methode execute() (uitvoeren) heeft. 

# In spiderpi_core/actions.py
from abc import ABC, abstractmethod # Importeer abstractmethod
from .robot import SpiderPi

class AbstractRobotAction(ABC):
    # ... (init blijft hetzelfde) ...

    # DIT IS HET CONTRACT:
    @abstractmethod
    def execute(self) -> None:
        """
        Voert de specifieke robot-actie uit.
        Child classes MOETEN dit implementeren.
        """
        pass # Geen code hier, alleen 'pass'

Stap 2: Testen (De Crash)

Nu proberen we in main.py een object te maken van deze klasse. 

# In main.py
from spiderpi_core.actions import AbstractRobotAction

# Dit crasht NU!
try:
    actie = AbstractRobotAction(my_robot)
except TypeError as e:
    print(f"FOUT: {e}")

Uitleg: Het Resultaat

Je krijgt een foutmelding:
Can't instantiate abstract class AbstractRobotAction with abstract method execute.

Dit is precies wat we wilden! Je mag geen object maken van een contract. Je moet eerst een Child class maken die zich aan de regels houdt. Dat doen we in de volgende les.
