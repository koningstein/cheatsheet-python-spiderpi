M5.8: Class Variables

Theorie: 'van het Object' vs. 'van de Klasse'

Er zijn twee soorten variabelen:

1. Instance Variable (Wat we al kennen):

  • Gedefinieerd in __init__ met self.
  • self._current_angle = 90.0
  • Uniek voor elk object. motor1.current_angle kan anders zijn dan motor2.current_angle.

2. Class Variable:

  • Gedefinieerd *direct* onder de class regel (buiten __init__).
  • Wordt gedeeld door *alle* objecten van die klasse.
  • Vergelijking (Auto): mijn_auto.kleur (instance) vs Auto.AANTAL_WIELEN = 4 (class).

Python Voorbeeld (`robot.py`)

We voegen gedeelde constanten toe aan onze klassen.

In spiderpi_core/robot.py:

from .leg import Leg
from .component import RobotComponent

class SpiderPi(RobotComponent):
    # --- CLASS VARIABLES ---
    # Gedeeld door alle SpiderPi objecten
    DEFAULT_IP: str = "192.168.1.100"
    LEG_COUNT: int = 6

    _leg_front_r: Leg # Instance variable
    # ...

    def __init__(self) -> None:
        super().__init__(name="SpiderPi_Robot")
        # --- INSTANCE VARIABLES ---
        self._leg_front_r = Leg(...)
        # ...

In spiderpi_core/servo.py:

We verplaatsen MIN_ANGLE en MAX_ANGLE *in* de klasse, zodat ze logisch bij de Servo horen.

class Servo(RobotComponent):
    # --- CLASS VARIABLES ---
    MIN_ANGLE: float = 0.0
    MAX_ANGLE: float = 180.0

    _id: int # Instance variable
    _current_angle: float # Instance variable

    def set_angle(self, new_angle: float) -> None:
        # Gebruik 'self.' of 'Servo.' om de class variable te lezen
        if not (self.MIN_ANGLE <= new_angle <= self.MAX_ANGLE):
            raise ValueError("Hoek buiten bereik")
        # ...

In main.py:

from spiderpi_core.robot import SpiderPi
from spiderpi_core.servo import Servo

# Je kunt ze aanroepen ZONDER een object te maken:
print(f"Een SpiderPi heeft {SpiderPi.LEG_COUNT} poten.")
print(f"De max hoek van een Servo is {Servo.MAX_ANGLE} graden.")
