M5.8: Class Variables

Uitleg: Gedeelde Variabelen

Net als statische methoden (M5.7), bestaan er ook statische variabelen. We noemen dit Class Variables.

  • Instance Variable (self.x): Uniek voor elk object.
  • Class Variable: Gedeeld door *alle* objecten van die klasse. Als je hem verandert, verandert hij voor iedereen.

Dit is handig voor constanten (zoals de MIN_ANGLE uit Module 1) of standaardinstellingen.

Stap 1: Class Variable Toevoegen

We voegen een standaard IP-adres toe aan de SpiderPi klasse in robot.py. We zetten dit *buiten* de __init__. 

# In spiderpi_core/robot.py

class SpiderPi(RobotComponent):
    # --- CLASS VARIABLES ---
    # Gedeeld door alle SpiderPi objecten
    DEFAULT_IP: str = "192.168.1.100"
    LEG_COUNT: int = 6

    # ... (rest van de klasse)

Stap 2: Gebruiken

Je kunt deze variabelen aanroepen via de klassenaam. 

# In main.py
from spiderpi_core.robot import SpiderPi

# Je kunt ze aanroepen ZONDER een object te maken:
print(f"Connecting to default IP: {SpiderPi.DEFAULT_IP}")
print(f"A SpiderPi has {SpiderPi.LEG_COUNT} legs.")
