M5.6: Unit Testing (Pytest)

Uitleg: Code Automatisch Testen

Hoe weten we zeker dat onze code werkt? Moeten we main.py elke keer handmatig aanpassen en runnen? Dat is traag en foutgevoelig.

We gebruiken Unit Tests. Dit zijn kleine scriptjes die automatisch controleren of je code werkt. We gebruiken de pytest library.

Stap 1: Code voorbereiden

Om goed te kunnen testen, moet onze Servo.set_angle methode een echte fout gooien (Exception) als de hoek fout is, in plaats van alleen een print(). 

# In spiderpi_core/servo.py

    def set_angle(self, new_angle: float) -> None:
        if not (self.MIN_ANGLE <= new_angle <= self.MAX_ANGLE):
            # GOOI een echte fout (Exception)
            raise ValueError(f"Angle {new_angle} is invalid")
        self._current_angle = new_angle

Stap 2: De Test Schrijven

Maak een map tests/ en daarin een bestand test_servo.py. 

# In tests/test_servo.py
import pytest
from spiderpi_core.servo import Servo

def test_set_angle_valid():
    """Test of een *geldige* hoek correct wordt ingesteld."""
    s = Servo(start_id=1, start_angle=90.0)
    s.set_angle(120.0)
    # De 'assert' controleert of het waar is. Zo niet -> Test FAILED.
    assert s.current_angle == 120.0

def test_set_angle_invalid_too_high():
    """Test of een *te hoge* hoek een ValueError gooit."""
    s = Servo(start_id=2, start_angle=90.0)

    # Beweer dat de code HIERBINNEN een ValueError 'gooit'
    with pytest.raises(ValueError):
        s.set_angle(200.0) # Dit MOET een fout geven!

Stap 3: Testen Draaien

Installeer pytest en draai het in je terminal. 

# 1. Installeren
(venv) C:\...> pip install pytest

# 2. Draaien
(venv) C:\...> pytest

# Output:
# tests/test_servo.py ..  [100%]
# 2 passed in 0.01s
