M5.6: Unit Testing (Pytest)

Theorie: Code Automatisch Testen

Probleem: We hebben set_angle(9000) (M1.4) [cite: 58-59] opgelost. Maar hoe weten we zeker dat het nog werkt na al onze aanpassingen? Moeten we main.py *elke keer* handmatig aanpassen en runnen? Dat is traag en foutgevoelig.

Oplossing: Unit Tests. Een "Unit Test" is een klein, automatisch script dat één "unit" (één methode) van je code test. We gebruiken de pytest library.

De kern is het assert (beweren) statement: assert motor.current_angle == 100. Als de bewering onwaar is, faalt de test.

Om fouten te testen, refactoren we de methode zodat deze een Exception (fout) "gooit" (raise), en we vangen deze met pytest.raises.

Python Voorbeeld

1. Code Refactor (in servo.py)

We moeten set_angle aanpassen zodat het een *testbare* fout gooit.

# In spiderpi_core/servo.py
def set_angle(self, new_angle: float) -> None:
    if not (self.MIN_ANGLE <= new_angle <= self.MAX_ANGLE):
        # OUD: print("FOUT...")
        # NIEUW:
        raise ValueError(f"Hoek {new_angle} is ongeldig")
    self._current_angle = new_angle

2. De Test (in tests/test_servo.py)

Maak een tests/ map (met __init__.py) en daarin test_servo.py.

import pytest
from spiderpi_core.servo import Servo

def test_set_angle_valid():
    """Test of een *geldige* hoek correct wordt ingesteld."""
    s = Servo(start_id=1, start_angle=90.0)
    s.set_angle(120.0)
    assert s.current_angle == 120.0 # Bewering

def test_set_angle_invalid_too_high():
    """Test of een *te hoge* hoek een ValueError gooit."""
    s = Servo(start_id=2, start_angle=90.0)

    # Beweer dat de code HIERBINNEN een ValueError 'gooit'
    with pytest.raises(ValueError):
        s.set_angle(200.0) # Dit MOET een ValueError gooien

def test_set_angle_invalid_too_low():
    """Test of een *te lage* hoek ook faalt."""
    s = Servo(start_id=3, start_angle=90.0)
    with pytest.raises(ValueError):
        s.set_angle(-10.0)
