M5.7: Static Methoden

Uitleg: Hulpfuncties

Tot nu toe was alles van het *object* (de *instance*). Alle methoden begonnen met self.

Soms heb je een functie nodig die wel bij de klasse hoort, maar geen object-data nodig heeft.

Dit is een Static Method. Je herkent hem aan @staticmethod en hij heeft GEEN self.

Vergelijking (Wiskunde): Je hebt geen 'wiskunde-object' nodig om wortel te trekken.

Stap 1: Utils Klasse Maken

We maken een bestand spiderpi_core/utils.py voor handige rekenfuncties. 

# In spiderpi_core/utils.py

class RobotUtils:
    """Een 'hulp-klasse' die geen objecten (instances) nodig heeft."""

    # Static Method (GEEN 'self' parameter!)
    @staticmethod
    def cm_to_inches(cm: float) -> float:
        """Zet centimeters om naar inches."""
        return cm * 0.393701

Stap 2: Gebruiken

Je roept een statische methode aan op de Klasse, niet op een object. 

# In main.py
from spiderpi_core.utils import RobotUtils

# Je hoeft GEEN object te maken (geen haakjes):
# utils = RobotUtils() # NIET NODIG

# Roep direct aan op de Klasse:
inches = RobotUtils.cm_to_inches(20.5)
print(f"20.5 cm is {inches:.2f} inches")
