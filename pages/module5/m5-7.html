M5.7: Static Methoden

Theorie: 'Hulpfuncties' van de Klasse

Tot nu toe was alles van het *object* (de *instance*). Alle methoden begonnen met self omdat ze de data van het object nodig hadden (self._id, etc.).

Een Static Method is een gewone functie die "toevallig" *in* een klasse woont (omdat het daar logisch bij hoort). Het heeft geen self (object) nodig.

Je roept ze aan op de *Klasse*, niet op het *object*.

  • Vergelijking (Wiskunde): Je hebt geen 'wiskunde-object' nodig om Math.sqrt(9) (worteltrekken) te doen.
  • SpiderPi: We hebben misschien een hulpfunctie nodig: RobotUtils.cm_naar_inches(10).

Python Voorbeeld (`utils.py`)

We maken een nieuw bestand spiderpi_core/utils.py.

# In spiderpi_core/utils.py
class RobotUtils:
    """Een 'hulp-klasse' die geen objecten (instances) nodig heeft."""

    # Static Method (GEEN 'self' parameter)
    @staticmethod
    def cm_naar_inches(cm: float) -> float:
        """Zet centimeters om naar inches."""
        return cm * 0.393701

# --- In main.py ---
from spiderpi_core.utils import RobotUtils

# Je hoeft GEEN object te maken:
# utils = RobotUtils() # NIET NODIG

# Roep direct aan op de Klasse:
inches = RobotUtils.cm_naar_inches(20.5)
print(f"20.5 cm is {inches} inches")
