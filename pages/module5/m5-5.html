M5.5: Abstractie voor Sensoren

Uitleg: Een Contract voor Data

We passen hetzelfde trucje (Abstractie) nu toe op een ander onderdeel: Sensoren.

Elke sensor is anders. Een Ultrasoon-sensor meet afstand, een Temperatuur-sensor meet graden. Maar ze doen allemaal hetzelfde: ze lezen een waarde.

We maken een AbstractSensor contract (ABC) dat eist dat elke sensor een .read_value() methode heeft.

Stap 1: AbstractSensor Maken

We maken een nieuw bestand spiderpi_core/sensors.py.

# In spiderpi_core/sensors.py
from abc import ABC, abstractmethod

class AbstractSensor(ABC):
    """
    Contract voor alle sensoren.
    """

    @abstractmethod
    def read_value(self) -> float:
        """
        Leest de waarde van de sensor.
        MOET een getal (float) teruggeven.
        """
        pass

Stap 2: Een 'Mock' (Nep) Sensor Maken

Omdat we misschien nog geen echte sensor hebben, maken we een Mock (nep) sensor om te testen. 

# Ook in spiderpi_core/sensors.py

class MockUltrasonicSensor(AbstractSensor):
    """Een neppe sensor voor test-doeleinden."""

    def read_value(self) -> float:
        """Implementeert het contract. Geeft een neppe waarde terug."""
        print("Reading ultrasonic sensor...")
        return 10.5 # Gesimuleerde afstand

Stap 3: Testen

# In main.py
from spiderpi_core.sensors import MockUltrasonicSensor

sensor = MockUltrasonicSensor()
distance = sensor.read_value()
print(f"Distance: {distance} cm")
