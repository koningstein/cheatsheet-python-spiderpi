M5.3: Implementatie (Simpel)

Uitleg: Het Contract Vervullen

Een abstracte klasse is nutteloos totdat een 'concrete' (echte) Child class het contract implementeert.

Om het contract te vervullen, moet de Child class:

  1. Erven van AbstractRobotAction.
  2. Een echte methode (met code) maken voor execute().

Stap 1: WalkAction Maken

We voegen een nieuwe klasse toe aan actions.py. Deze actie laat de robot "lopen". 

# In spiderpi_core/actions.py
# ... (bovenaan de imports en AbstractRobotAction) ...

class WalkAction(AbstractRobotAction):
    """
    Een CONCRETE actie. Vervult het contract.
    """

    def execute(self) -> None:
        """
        Implementatie van het 'execute' contract.
        """
        print("Action: Walking forward...")
        # Hier zou je code komen om de poten te bewegen
        # self._robot.leg_front_left.move_to_angles(...)

Stap 2: Testen

Nu kunnen we in main.py wél een object maken. 

# In main.py
from spiderpi_core.actions import WalkAction
from spiderpi_core.robot import SpiderPi

my_robot = SpiderPi()

# Dit crasht NIET, want het contract is vervuld:
walk = WalkAction(my_robot)

# Voer de actie uit
walk.execute()

Uitleg: Resultaat

In de terminal zie je: Action: Walking forward.... Omdat WalkAction de execute methode heeft gemaakt, is hij niet meer abstract en mogen we hem gebruiken.
