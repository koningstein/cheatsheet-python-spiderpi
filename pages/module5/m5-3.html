M5.3: Implementatie (Simpel)

Theorie: Het Contract Vervullen

Een abstracte klasse (contract) is nutteloos totdat een 'concrete' (niet-abstracte) kind-klasse het implementeert.

Om het contract te vervullen, moet de kind-klasse:

  1. Erven van de abstracte klasse.
  2. Een echte methode (met code) implementeren voor elke @abstractmethod van de ouder.

Omdat WalkAction de execute() methode netjes implementeert, is het geen abstracte klasse meer, en kun je er wel objecten van maken.

Python Voorbeeld (`actions.py`)

We voegen een *concrete* klasse toe die het contract vervult.

# In spiderpi_core/actions.py
# ... (imports en AbstractRobotAction) ...

class WalkAction(AbstractRobotAction):
    """
    Een CONCRETE actie. Vervult het contract.
    (Heeft geen __init__ nodig, erft die van de ouder)
    """

    def execute(self) -> None:
        """
        Implementatie van het 'execute' contract.
        """
        print("Actie: Lopen...")
        # We kunnen de robot (die we in de __init__ kregen) besturen:
        # (We gaan ervan uit dat robot een 'leg_front_r' getter heeft)
        self._robot.leg_front_r.move_to_angles(100, 100, 100)

# --- In main.py ---
from spiderpi_core.actions import WalkAction

# Dit crasht NIET, want het contract is vervuld:
loop_actie = WalkAction(my_robot)
loop_actie.execute()

# Output:
# Actie: Lopen...
# (gevolgd door de servo-prints)
