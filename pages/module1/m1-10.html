M1.10: De Hoofd-Class (Integratie)

Leeruitkomsten

  • Ik kan een hoofd-klasse ontwerpen die het volledige systeem (de robot) modelleert.
  • Ik kan compositie op meerdere niveaus toepassen.
  • Ik kan een hoog-niveau methode schrijven die werk delegeert.

Uitleg: De Top van de Piramide

We hebben de bouwstenen voltooid: Servo (laagste niveau) en Leg (middenniveau). Nu is het tijd voor het hoogste niveau: de SpiderPi klasse. Deze klasse is de "baas" van het hele systeem.

Dit is weer Compositie:

  • SpiderPi heeft 6 Leg objecten.
  • Elke Leg heeft 3 Servo objecten.
# In een nieuw bestand: robot.py
from .leg import Leg

class SpiderPi:
    """Modelleert de complete robot."""

    # Properties voor alle 6 de poten
    leg_front_left: Leg
    leg_front_right: Leg
    leg_mid_left: Leg
    leg_mid_right: Leg
    leg_back_left: Leg
    leg_back_right: Leg

    def __init__(self):
        """Bouwt de robot door alle 6 poten aan te maken."""
        print("SpiderPi robot wordt gebouwd...")

        # Compositie op het hoogste niveau
        # (Pas de ID's aan naar je eigen robot)
        self.leg_front_left  = Leg(hip_id=10, knee_id=11, ankle_id=12)
        self.leg_front_right = Leg(hip_id=1, knee_id=2, ankle_id=3)
        self.leg_mid_left    = Leg(hip_id=13, knee_id=14, ankle_id=15)
        self.leg_mid_right   = Leg(hip_id=4, knee_id=5, ankle_id=6)
        self.leg_back_left   = Leg(hip_id=16, knee_id=17, ankle_id=18)
        self.leg_back_right  = Leg(hip_id=7, knee_id=8, ankle_id=9)

        print("Robot is klaar.")

Uitleg: Delegatie op Hoog Niveau

Net als de Leg een "gemaksmethode" had (set_all_angles), moet de SpiderPi ook "gemaksmethoden" hebben, zoals wake_up().

Deze methode delegeert het werk aan al zijn Leg objecten, die het werk vervolgens weer delegeren aan hun Servo objecten. 

# In robot.py (vervolg)
class SpiderPi:
    # ... (init van hierboven) ...

    def wake_up(self) -> None:
        """Delegeer 'wake_up' naar alle 6 de poten."""
        print("Robot is aan het opstaan...")
        # Zet alle poten in een standaard 'staande' positie (bv. 90 graden)
        self.leg_front_left.set_all_angles(90.0, 90.0, 90.0)
        self.leg_front_right.set_all_angles(90.0, 90.0, 90.0)
        self.leg_mid_left.set_all_angles(90.0, 90.0, 90.0)
        self.leg_mid_right.set_all_angles(90.0, 90.0, 90.0)
        self.leg_back_left.set_all_angles(90.0, 90.0, 90.0)
        self.leg_back_right.set_all_angles(90.0, 90.0, 90.0)
        print("Robot staat.")

    def sleep(self) -> None:
        """Delegeer 'sleep' naar alle 6 de poten."""
        print("Robot gaat slapen...")
        # Zet alle poten in een 'rust' positie
        self.leg_front_left.set_all_angles(90.0, 150.0, 150.0)
        self.leg_front_right.set_all_angles(90.0, 150.0, 150.0)
        # ... (en zo verder voor alle 6 de poten) ...
        print("Robot slaapt.")

Uitleg: De Finale Test

Nu kunnen we met één commando in main.py de hele kettingreactie starten. Eén SpiderPi object maken roept 19 constructors aan (1 SpiderPi, 6 Legs, 18 Servos). Eén wake_up() call roept 6 keer set_all_angles() aan, wat weer 18 keer set_angle() aanroept. 

# In main.py
from .robot import SpiderPi
import time

# Dit ene commando start de hele kettingreactie
my_robot = SpiderPi()

print("Robot aanroepen...")
my_robot.wake_up()

time.sleep(2) # Wacht 2 seconden

my_robot.sleep()
