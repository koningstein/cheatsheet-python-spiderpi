M1.10: Hoofd-Klasse (Integratie)

Theorie: Het Totaalplaatje (De Top van de Piramide)

We passen het Compositie-principe (M1.8) nog een laatste keer toe om de basisstructuur van onze robot compleet te maken. [cite_start]We bouwen de 'top' van de piramide: de SpiderPi-klasse[cite: 2189].

De hiërarchie (structuur) is nu:

  • De SpiderPi-robot heeft 6 Leg-objecten.
  • Elke Leg heeft 3 Servo-objecten.

De __init__ van de SpiderPi maakt 6 Leg-objecten aan. De __init__ van *elke* Leg maakt vervolgens 3 Servo-objecten aan.

Als we één SpiderPi object maken, worden er dus automatisch 1 + 6 + (6 * 3) = 25 objecten in totaal geïnitialiseerd! Dit is de kracht van Compositie.

Stap-voor-stap Voorbeeld

Stap 1: Maak `robot.py` (De Hoofd-Klasse)

We maken een nieuw bestand, robot.py (in M2 verplaatsen we dit naar spiderpi_core/robot.py).

# In robot.py
from .leg import Leg # (Uitgaande van package-structuur M2)

class SpiderPi:
    """
    Modelleert de complete robot.
    Dit is de 'Hoofd-Klasse' die alles 'bezit'.
    """
    _leg_front_r: Leg
    _leg_mid_r: Leg
    _leg_rear_r: Leg
    _leg_front_l: Leg
    _leg_mid_l: Leg
    _leg_rear_l: Leg

    def __init__(self):
        """Bouwt de robot door alle 6 poten aan te maken."""
        print("SpiderPi robot wordt geassembleerd...")

        # Compositie van Leg-objecten
        # (De ID's 1-18 zijn specifiek voor de hardware)
        self._leg_front_r = Leg(id_hip=1, id_knee=2, id_ankle=3)
        self._leg_mid_r   = Leg(id_hip=4, id_knee=5, id_ankle=6)
        self._leg_rear_r  = Leg(id_hip=7, id_knee=8, id_ankle=9)
        self._leg_front_l = Leg(id_hip=10, id_knee=11, id_ankle=12)
        self._leg_mid_l   = Leg(id_hip=13, id_knee=14, id_ankle=15)
        self._leg_rear_l  = Leg(id_hip=16, id_knee=17, id_ankle=18)

        print("Robot is klaar voor gebruik!")

    # ... (Getters voor de poten)
    @property
    def leg_front_r(self) -> Leg:
        return self._leg_front_r

    # ... (en 5 meer getters voor de andere poten) ...

Stap 2: De 'Definitieve' `main.py` (voor nu)

main.py wordt nu extreem simpel. We hoeven alleen nog maar de SpiderPi-klasse te importeren en één object te maken.

# In main.py
# Importeer alleen de 'top' van de piramide
from spiderpi_core.robot import SpiderPi

# Dit ene commando start een kettingreactie van __init__ aanroepen!
print("--- Robot wordt gebouwd ---")
my_robot = SpiderPi()
print("--- Robot is gebouwd ---")

# We kunnen nu de *hele* keten van delegatie aanroepen:
# "Robot -> Poot -> Servo's"
print("\n--- Commando wordt gegeven ---")
my_robot.leg_front_r.move_to_angles(100.0, 100.0, 100.0)

Stap 3: Resultaat

De output van main.py toont de volledige 'cascade' van object-creatie.
