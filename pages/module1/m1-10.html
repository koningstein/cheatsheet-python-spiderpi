M1.10: Hoofd-Klasse (Integratie)

Theorie: Het Totaalplaatje

We passen het Compositie-principe (M1.8) nog een laatste keer toe om de structuur compleet te maken. We bouwen de 'top' van de piramide: de SpiderPi-klasse.

  • De SpiderPi-robot heeft 6 Leg-objecten.
  • Elke Leg heeft 3 Servo-objecten.

De __init__ van de SpiderPi maakt 6 Leg-objecten aan, die op hun beurt 18 Servo-objecten aanmaken. Dit is een "cascade" van constructors.

Python Voorbeeld

We maken een nieuw bestand, robot.py (in M2 verplaatsen we dit naar spiderpi_core/robot.py).

# In robot.py
from .leg import Leg # (Uitgaande van package-structuur M2)

class SpiderPi:
    """Modelleert de complete robot."""
    _leg_front_r: Leg
    _leg_mid_r: Leg
    _leg_rear_r: Leg
    _leg_front_l: Leg
    _leg_mid_l: Leg
    _leg_rear_l: Leg

    def __init__(self):
        """Bouwt de robot door alle 6 poten aan te maken."""
        print("SpiderPi robot wordt geassembleerd...")

        # Compositie van Leg-objecten
        # (De ID's 1-18 zijn specifiek voor de hardware)
        self._leg_front_r = Leg(id_hip=1, id_knee=2, id_ankle=3)
        self._leg_mid_r = Leg(id_hip=4, id_knee=5, id_ankle=6)
        self._leg_rear_r = Leg(id_hip=7, id_knee=8, id_ankle=9)
        self._leg_front_l = Leg(id_hip=10, id_knee=11, id_ankle=12)
        self._leg_mid_l = Leg(id_hip=13, id_knee=14, id_ankle=15)
        self._leg_rear_l = Leg(id_hip=16, id_knee=17, id_ankle=18)

        print("Robot is klaar voor gebruik!")

    # ... (Getters voor de poten)
    @property
    def leg_front_r(self) -> Leg:
        return self._leg_front_r

# --- In main.py ---
from spiderpi_core.robot import SpiderPi

# Dit ene commando start een kettingreactie van __init__ aanroepen!
my_robot = SpiderPi()

# We kunnen nu de *hele* keten aanroepen (via getters):
my_robot.leg_front_r.move_to_angles(100, 100, 100)
