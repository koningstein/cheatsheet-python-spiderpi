M1.7: Class Variables (Magic Numbers)

Leeruitkomsten

  • Ik kan het probleem van "Magic Numbers" in code identificeren.
  • Ik kan een Class Variable definiëren en gebruiken.
  • Ik begrijp het verschil tussen een Class Variable (gedeeld) en een Instance Variable (uniek).

Uitleg: Het "Magic Number" Probleem

Kijk terug naar onze set_angle methode uit M1.4: if 0.0 <= new_angle <= 180.0:

De getallen 0.0 en 180.0 worden "Magic Numbers" genoemd. Ze zijn "hardcoded" in de code. Wat als we de limiet willen aanpassen? Dan moet je elke if-statement in je code opzoeken en aanpassen.

Uitleg: De Oplossing (Class Variables)

We hebben een centrale plek nodig om deze constanten op te slaan: Class Variables.

  • Instance Variable: Is uniek per object (bv. self._current_angle).
  • Class Variable: Wordt gedeeld door alle objecten van de klasse. Het "leeft" op de klasse zelf.

We definiëren ze direct onder de class regel (met HOOFDLETTERS is de afspraak). We kunnen ze nu ook gebruiken om de start_angle in de __init__ te valideren, waarmee we het lek uit M1.6 dichten. 

# In servo.py
class Servo:
    # Dit zijn CLASS VARIABLES
    MIN_ANGLE: float = 0.0
    MAX_ANGLE: float = 180.0

    def __init__(self, id_num: int, start_angle: float):
        self.id = id_num

        # VALIDATIE IN DE CONSTRUCTOR (dicht het lek uit M1.6)
        # We gebruiken hier 'self.MIN_ANGLE' om de class variable te lezen
        if not (self.MIN_ANGLE <= start_angle <= self.MAX_ANGLE):
            print(f"WAARSCHUWING: start_angle {start_angle} is ongeldig! Zet op MIN.")
            self._current_angle = self.MIN_ANGLE
        else:
            self._current_angle = start_angle

    def set_angle(self, new_angle: float) -> None:
        """Valideert en stelt de hoek in, nu met Class Variables."""

        # We gebruiken 'self.MIN_ANGLE' om de gedeelde waarde te lezen
        if self.MIN_ANGLE <= new_angle <= self.MAX_ANGLE:
            self._current_angle = new_angle
            print(f"Motor {self.id} beweegt naar {self._current_angle} graden.")
        else:
            # De foutmelding is nu ook dynamisch!
            print(f"FOUT: Hoek {new_angle} moet tussen {self.MIN_ANGLE} en {self.MAX_ANGLE} zijn.")

    @property
    def current_angle(self) -> float:
        return self._current_angle

Uitleg: Testen

De ongeldige waarde 9000.0 wordt nu correct afgevangen bij de "geboorte" (in de __init__) van het object. 

# In main.py
motor3 = Servo(id_num=3, start_angle=9000.0)
print(f"Motor 3 staat op {motor3.current_angle} graden.")

# Output:
# Nieuw Servo object (ID: 3) wordt gemaakt...
# WAARSCHUWING: start_angle 9000.0 is ongeldig! Zet op MIN.
# Motor 3 staat op 0.0 graden.
