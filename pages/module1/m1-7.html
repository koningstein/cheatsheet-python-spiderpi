M1.7: Named Arguments (Benoemde Argumenten)

Theorie: Leesbare Code Schrijven

Dit is een korte les over code-stijl die je veel tijd zal besparen.

Probleem: Wat betekent Servo(1, 90.0)? Is 1 de hoek of het id? Je moet de volgorde in servo.py onthouden om main.py te kunnen schrijven.

[cite_start]Oplossing: Met Named Arguments (Benoemde Argumenten) geef je expliciet aan welke waarde bij welke parameter hoort[cite: 2189]. Dit maakt de code veel leesbaarder en de volgorde maakt niet meer uit.

Stap-voor-stap Voorbeeld

Stap 1: De Constructor (in `servo.py`)

Onze constructor (uit M1.6) verwacht twee argumenten: start_id en start_angle.

# In servo.py
class Servo:
    # De __init__ verwacht 'start_id' en 'start_angle'
    def __init__(self, start_id: int, start_angle: float):
        self._id = start_id
        self.set_angle(start_angle)
        # ... (rest van de code)

Stap 2: Gebruik in `main.py`

We kunnen de constructor op drie manieren aanroepen. Vergelijk het verschil in leesbaarheid.

# In main.py
from .servo import Servo # (uitgaande van M2 package)

# 1. Normale aanroep (positional)
#    Werkt, maar is onduidelijk. Wat is 1? Wat is 90.0?
motor1 = Servo(1, 90.0)

# 2. Aanroep met Named Arguments (BENOEMDE ARGUMENTEN)
#    Veel leesbaarder!
motor2 = Servo(start_id=2, start_angle=100.0)

# 3. Volgorde maakt niet meer uit!
#    Dit werkt ook, omdat we de namen gebruiken.
motor3 = Servo(start_angle=110.0, start_id=3)

print(f"Motor 1 ID: {motor1.id}")
print(f"Motor 2 ID: {motor2.id}")
print(f"Motor 3 ID: {motor3.id}")

Conclusie: Gebruik altijd Named Arguments als je een object aanmaakt. Het maakt je code leesbaar en voorkomt fouten.
