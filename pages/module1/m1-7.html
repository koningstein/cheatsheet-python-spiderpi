M1.7: Named Arguments (Benoemde Argumenten)

Theorie: Leesbare Code Schrijven

Probleem: Wat betekent Servo(1, 90.0)? Is 1 de hoek of het ID? Je moet de volgorde onthouden.

Oplossing: Met Named Arguments (Benoemde Argumenten) geef je expliciet aan welke waarde bij welke parameter hoort. Dit maakt de code veel leesbaarder en de volgorde maakt niet meer uit.

Python Voorbeeld

# In servo.py
class Servo:
    # De __init__ verwacht 'start_id' en 'start_angle'
    def __init__(self, start_id, start_angle):
        self._id = start_id
        self._current_angle = start_angle
        # ... (validatie weggelaten voor eenvoud)

# In main.py
# Normale aanroep (positional)
motor1 = Servo(1, 90.0)

# Aanroep met Named Arguments (veel leesbaarder)
motor2 = Servo(start_id=2, start_angle=100.0)

# Volgorde maakt niet meer uit!
motor3 = Servo(start_angle=110.0, start_id=3)
