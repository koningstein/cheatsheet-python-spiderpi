M1.6: Constructor (__init__)

Theorie: De 'Geboorte' van een Object

Een Constructor is een speciale methode die automatisch wordt aangeroepen op het moment dat een object wordt gemaakt (geïnstantieerd).

In Python heet deze methode def __init__(self, ...): (met dubbele underscores).

Dit is de perfecte plek om de begin-properties (de 'toestand') van een object in te stellen. Het *dwingt* de programmeur om de benodigde data (zoals een id en start_angle) direct mee te geven bij het maken van het object.

Python Voorbeeld

We passen servo.py aan. De properties _id en _current_angle worden nu in de constructor ingesteld in plaats van in main.py.

# In servo.py
MIN_ANGLE = 0.0
MAX_ANGLE = 180.0

class Servo:
    _id: int
    _current_angle: float

    # De Constructor
    def __init__(self, start_id, start_angle):
        """Wordt automatisch aangeroepen bij Servo(...)"""
        print(f"Nieuw Servo object (ID: {start_id}) wordt gemaakt...")
        self._id = start_id

        # We kunnen de setter *binnen* de constructor gebruiken
        # voor validatie bij de 'geboorte'!
        self.set_angle(start_angle)
        # Let op: We stellen _current_angle niet meer dubbel in.

    def set_angle(self, new_angle):
        """SETTER: Stelt de hoek in, mét validatie."""
        if new_angle >= MIN_ANGLE and new_angle <= MAX_ANGLE:
            self._current_angle = new_angle
        else:
            # We gooien nu een 'Error' (Exception)
            raise ValueError(f"Hoek {new_angle} is ongeldig.")

    @property
    def current_angle(self):
        return self._current_angle

# In main.py
# Oude manier (werkt niet meer):
# motor = Servo() # Crasht: Mist 2 argumenten
# motor.id = 1
# motor.set_angle(90.0)

# Nieuwe manier:
motor1 = Servo(1, 90.0)
motor2 = Servo(2, 110.0)
print(f"Motor 1 staat op {motor1.current_angle} graden.")

# Crasht direct bij aanmaak (dankzij de constructor):
# motor3 = Servo(3, 9000.0) # ValueError!
