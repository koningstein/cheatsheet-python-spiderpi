M1.6: Constructor (__init__)

Theorie: De 'Geboorte' van een Object

Probleem: In main.py moeten we nu 3 regels code schrijven om één motor te maken:
motor = Servo()
motor.id = 1
motor.set_angle(90.0)
Dit is onhandig en je kunt vergeten de id in te stellen.

Oplossing: Een Constructor. [cite_start]Dit is een speciale methode die *automatisch* wordt aangeroepen op het moment dat een object wordt gemaakt (geïnstantieerd)[cite: 2189, 2288].

In Python heet deze methode def __init__(self, ...): (met dubbele underscores, "dunder init" genoemd).

Dit is de perfecte plek om de begin-properties (de 'toestand') van een object in te stellen. [cite_start]Het *dwingt* de programmeur om de benodigde data (zoals een id en start_angle) direct mee te geven bij het maken van het object [cite: 2288-2292].

Stap-voor-stap Voorbeeld

Stap 1: Vóór (Code uit M1.5)

servo.py heeft nog geen __init__. main.py stelt properties handmatig in.

# In servo.py
class Servo:
    _current_angle = 90.0
    id = 0

    def set_angle(self, new_angle):
        # ...

    @property
    def current_angle(self):
        # ...

# In main.py
motor = Servo()
motor.id = 1
motor.set_angle(90.0)

Stap 2: Na (Refactor met `__init__`)

We voegen __init__ toe aan servo.py. We verplaatsen het instellen van id en _current_angle naar de constructor. We hernoemen ook id naar _id om het 'protected' te maken.

# In servo.py
MIN_ANGLE = 0.0
MAX_ANGLE = 180.0

class Servo:
    # We definiëren de properties nu hier (zie M3.1)
    _id: int
    _current_angle: float

    # De Constructor
    def __init__(self, start_id: int, start_angle: float):
        """Wordt automatisch aangeroepen bij Servo(...)"""
        print(f"Nieuw Servo object (ID: {start_id}) wordt gemaakt...")

        # We stellen de 'protected' properties in
        self._id = start_id

        # We kunnen de setter *binnen* de constructor gebruiken
        # voor validatie bij de 'geboorte'!
        self.set_angle(start_angle)

    def set_angle(self, new_angle: float):
        """SETTER: Stelt de hoek in, mét validatie."""
        if new_angle >= MIN_ANGLE and new_angle <= MAX_ANGLE:
            self._current_angle = new_angle
        else:
            # Gooi een 'Error' (Exception)
            raise ValueError(f"Hoek {new_angle} is ongeldig.")

    @property
    def current_angle(self) -> float:
        return self._current_angle

    @property
    def id(self) -> int:
        return self._id

Stap 3: Testen (in `main.py`)

Onze oude main.py code *crasht* nu, omdat Servo() parameters vereist. Dat is goed! We passen het aan.

# In main.py

# Oude manier (werkt niet meer):
# motor = Servo() # Crasht: Mist 2 argumenten
# motor.id = 1
# motor.set_angle(90.0)

# Nieuwe manier:
motor1 = Servo(1, 90.0)
motor2 = Servo(2, 110.0)

print(f"Motor 1 (ID: {motor1.id}) staat op {motor1.current_angle} graden.")
print(f"Motor 2 (ID: {motor2.id}) staat op {motor2.current_angle} graden.")

# Crasht direct bij aanmaak (dankzij de constructor):
try:
    motor3 = Servo(3, 9000.0) # ValueError!
except ValueError as e:
    print(f"Fout bij aanmaken motor 3: {e}")

Output:

Nieuw Servo object (ID: 1) wordt gemaakt...
Nieuw Servo object (ID: 2) wordt gemaakt...
Motor 1 (ID: 1) staat op 90.0 graden.
Motor 2 (ID: 2) staat op 110.0 graden.
Nieuw Servo object (ID: 3) wordt gemaakt...
Fout bij aanmaken motor 3: Hoek 9000.0 is ongeldig
