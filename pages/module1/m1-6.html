M1.6: De Constructor (__init__)

Leeruitkomsten

  • Ik begrijp het probleem van objecten die in een "ongeldige staat" worden aangemaakt.
  • Ik kan de Constructor (__init__) methode implementeren.
  • Ik begrijp dat de constructor automatisch wordt aangeroepen bij het aanmaken van een object.

Uitleg: Het Probleem van "Lege" Objecten

We hebben onze data redelijk beschermd (M1.5). Maar we hebben nog steeds het "opstart" probleem: 

# In main.py
motor = Servo()
motor.id = 1
motor.set_angle(90.0)

Dit zijn 3 regels code om één object correct op te zetten. Wat als je motor.id = 1 vergeet? Dan wordt het object "leeg" en in een ongeldige toestand geboren.

Uitleg: De Constructor Oplossing

De Constructor is een speciale methode die automatisch wordt aangeroepen op het moment dat je het object aanmaakt. In Python heet deze __init__.

Dit is de perfecte plek om alle essentiële properties in te stellen. De klasse dwingt je nu om de data mee te geven. 

# In servo.py
# (Constanten MIN_ANGLE/MAX_ANGLE staan hierboven, buiten de class)

class Servo:
    # We kunnen de types hier alvast aangeven (optioneel, maar netjes)
    id: int
    _current_angle: float

    # De Constructor
    def __init__(self, id_num: int, start_angle: float):
        """
        Wordt automatisch aangeroepen bij 'Servo(1, 90.0)'
        """
        print(f"Nieuw Servo object (ID: {id_num}) wordt gemaakt...")

        # We stellen de properties *direct* in
        self.id = id_num  # 'id' is nog steeds public
        self._current_angle = start_angle # Stel de 'verborgen' property in

    def set_angle(self, new_angle: float):
        """SETTER: Stelt de hoek in, mét validatie."""
        # (Hier komt de validatie-logica uit M1.4)
        if new_angle >= MIN_ANGLE and new_angle <= MAX_ANGLE:
            self._current_angle = new_angle
            print(f"Motor {self.id} beweegt naar {self._current_angle} gr.")
        else:
            print(f"FOUT: Hoek {new_angle} is ongeldig.")

    @property
    def current_angle(self):
        """GETTER: Leest de *protected* property 'read-only' uit."""
        return self._current_angle

Uitleg: De Grote Verbetering

Onze main.py code wordt nu veel schoner en veiliger. We kunnen geen "lege" Servo() meer maken. Het object is gegarandeerd compleet na één regel code. 

# In main.py
from servo import Servo

# Oude manier (werkt niet meer):
# motor = Servo() # Crasht: Mist 2 argumenten
# motor.id = 1
# motor.set_angle(90.0)

# Nieuwe manier:
motor1 = Servo(id_num=1, start_angle=90.0)
motor2 = Servo(id_num=2, start_angle=110.0)
print(f"Motor 1 staat op {motor1.current_angle} graden.")

# LET OP: We hebben nog steeds een klein lek!
# De constructor zelf valideert de 'start_angle' nog niet.
motor3 = Servo(id_num=3, start_angle=9000.0)
print(f"Motor 3 staat op {motor3.current_angle} graden.") # Output: 9000.0
# Dit lossen we in de volgende les op.
