M1.1: Classes en Objecten

Theorie: De Blauwdruk vs. het Gebouw

Welkom bij OOP! We gaan de echte wereld nabootsen in code. We beginnen met het belangrijkste concept: het verschil tussen een Klasse en een Object.

Wat is een Klasse (Class)?

[cite_start]Een Klasse is een blauwdruk, een sjabloon of een bouwplan[cite: 2215]. Het beschrijft *hoe* iets gemaakt moet worden, maar het *is* nog niet het ding zelf.

  • Analogie: Het bouwplan van een huis. Je kunt niet in het bouwplan wonen.
  • SpiderPi: We maken een bouwplan voor één motor. [cite_start]Dat bouwplan noemen we Servo[cite: 2189, 2213].

Wat is een Object (Instance)?

Een Object is het echte ding dat je hebt gemaakt met de blauwdruk. [cite_start]Dit wordt ook wel een 'instantie' genoemd[cite: 2226].

    [cite_start]
  • Analogie: Het echte huis dat je hebt gebouwd op basis van het bouwplan[cite: 2228]. Je kunt *meerdere* huizen (objecten) bouwen met *één* bouwplan (klasse).
    • [cite_start]
  • SpiderPi: De 18 echte, fysieke motortjes op de robot zijn de Objecten[cite: 2189, 2228].

Stap-voor-stap Voorbeeld

We hebben twee bestanden nodig: de blauwdruk (`servo.py`) en het script dat de objecten maakt (`main.py`).

Stap 1: De Blauwdruk (`servo.py`)

Maak een nieuw bestand servo.py. Hier definiëren we de Servo klasse. Omdat we nog geen details hebben, gebruiken we pass.

# In servo.py

class Servo:
    """
    De 'blauwdruk' voor een enkele motor (servo).
    (Opmerking: 'PascalCase' (hoofdletters) is de standaard voor klassen.)
    """
    pass # 'pass' betekent 'hier komt later code'.

Stap 2: De Objecten (`main.py`)

Maak een tweede bestand main.py. Dit is ons hoofdscript.

  1. We importeren de blauwdruk.
  2. We bouwen twee 'echte' objecten (twee motoren) op basis van die blauwdruk.
# In main.py

# 1. Importeer de 'Servo' blauwdruk uit het 'servo.py' bestand.
from servo import Servo

# 2. Maak 'echte' objecten (instanties) van de blauwdruk
motor_voor_rechts = Servo()
motor_achter_links = Servo()

# 3. Verifieer: dit zijn twee unieke, aparte objecten
print("Object 1 (motor_voor_rechts):")
print(motor_voor_rechts)

print("\nObject 2 (motor_achter_links):")
print(motor_achter_links)

Stap 3: Testen

Voer main.py uit in je terminal:

python main.py

De output laat zien dat het twee verschillende objecten zijn op twee unieke geheugenlocaties:

Object 1 (motor_voor_rechts):
<servo.Servo object at 0x10f2a4f10>

Object 2 (motor_achter_links):
<servo.Servo object at 0x10f2a4e50>
