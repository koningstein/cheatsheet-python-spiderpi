M1.1: Classes en Objecten

Leeruitkomsten

  • Ik begrijp het concept van een Klasse als een blauwdruk in OOP.
  • Ik kan een simpele Klasse definiëren in Python.
  • Ik begrijp wat een Object is en kan een Object aanmaken op basis van een Klasse.

Uitleg: De Klasse (Blauwdruk)

Een Klasse is een blauwdruk, een sjabloon of een bouwplan. Het beschrijft hoe iets gemaakt moet worden, maar het is nog niet het ding zelf.

Vergelijking: Een architect tekent een bouwplan voor een huis. Dat bouwplan is de Klasse. Je kunt niet in het bouwplan wonen.

We maken een bouwplan voor één motor. Dat bouwplan noemen we Servo. We definiëren een klasse met het class keyword, met de naam in PascalCase. 

# In een nieuw bestand: servo.py
# We definiëren de klasse (de blauwdruk)
class Servo:
    """Modelleert een enkele motor (servo)."""
    # 'pass' is een placeholder en betekent 'doe (nog) niets'
    pass

Uitleg: Het Object (Het Echte Ding)

Een Object (of Instantie) is het echte ding dat je hebt gemaakt met de blauwdruk. Elk object is uniek en heeft zijn eigen specifieke toestand.

Vergelijking: Het echte huis dat je hebt gebouwd op basis van het bouwplan, is het Object. De 18 echte, fysieke motortjes op de robot zijn de Objecten.

Je maakt een object door de klassenaam aan te roepen alsof het een functie is. 

# In een nieuw bestand: main.py
# We importeren de blauwdruk (de Servo klasse)
from servo import Servo

# We 'bouwen' twee echte, unieke objecten op basis van de blauwdruk
motor_heup_links = Servo()
motor_knie_links = Servo()

# Dit zijn twee aparte objecten in het geheugen
print(motor_heup_links)
print(motor_knie_links)

# Output:
# <__main__.Servo object at 0x10f2a4f10>
# <__main__.Servo object at 0x10f2a4e50>
