M1.1: Classes en Objecten

Theorie: De Blauwdruk vs. het Gebouw

In OOP proberen we de echte wereld na te bootsen. We maken 'dingen' (objecten) die data (eigenschappen) en gedrag (methoden) hebben.

Wat is een Klasse (Class)?

Een Klasse is een blauwdruk, een sjabloon of een bouwplan. Het beschrijft hoe iets gemaakt moet worden, maar het is nog niet het ding zelf.

  • Vergelijking: Een architect tekent een bouwplan voor een huis. Dat bouwplan is de Klasse. Je kunt niet in het bouwplan wonen.
  • SpiderPi: We maken een bouwplan voor één motor. [cite_start]Dat bouwplan noemen we Servo. [cite: 58-59]

Wat is een Object (Instance)?

Een Object is het echte ding dat je hebt gemaakt met de blauwdruk.

  • Vergelijking: Het echte huis dat je hebt gebouwd op basis van het bouwplan, is het Object.
    • [cite_start]
  • SpiderPi: De 18 echte, fysieke motortjes op de robot zijn de Objecten. [cite: 58-59]

Python Voorbeeld

# servo.py (De Blauwdruk)
# We definiëren de klasse met PascalCase
class Servo:
    """Modelleert een enkele motor (servo)."""
    pass

# main.py (Objecten Maken)
# We importeren de blauwdruk
from servo import Servo

# We maken 'echte' objecten van de blauwdruk
motor1 = Servo()
motor2 = Servo()

# Dit zijn twee unieke, aparte objecten
print(motor1)
print(motor2)
# Output:
# <__main__.Servo object at 0x10f2a4f10>
# <__main__.Servo object at 0x10f2a4e50>
