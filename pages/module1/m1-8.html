M1.8: Compositie (Basis)

Theorie: 'Heeft een...' Relatie

Objecten in de echte wereld zijn vaak opgebouwd uit andere objecten. [cite_start]Dit heet Compositie (samenstelling), de "Heeft een..." (HAS-A) relatie[cite: 2189].

  • Analogie: Een Auto-object heeft een Motor-object en vier Wiel-objecten.
    • [cite_start]
  • SpiderPi: Een Leg-object (poot) heeft drie Servo-objecten (heup, knie, enkel)[cite: 2189].

We implementeren dit door in de __init__ van de 'container'-klasse (Leg) objecten aan te maken van de 'inhoud'-klasse (Servo) en die op te slaan als properties.

Stap-voor-stap Voorbeeld

Stap 1: Maak een nieuw bestand `leg.py`

Dit bestand bevat de blauwdruk voor een complete poot.

# In leg.py
# (We gaan ervan uit dat we in een package 'spiderpi_core' zitten, zie M2)
from .servo import Servo

class Leg:
    """Modelleert een poot, opgebouwd uit 3 servo's."""

    # We definiëren de 'protected' properties die de servo-objecten
    # gaan vasthouden.
    _hip_servo: Servo
    _knee_servo: Servo
    _ankle_servo: Servo

    def __init__(self, id_hip: int, id_knee: int, id_ankle: int):
        """
        Maakt de 3 servo-objecten aan die deze poot *bevat*.
        Dit is COMPOSITIE.
        """
        self._hip_servo = Servo(start_id=id_hip, start_angle=90.0)
        self._knee_servo = Servo(start_id=id_knee, start_angle=90.0)
        self._ankle_servo = Servo(start_id=id_ankle, start_angle=90.0)

        print(f"Leg aangemaakt met servo's: {id_hip}, {id_knee}, {id_ankle}")

    # We voegen getters toe (M1.5) zodat we de servo's
    # van buitenaf kunnen lezen.
    @property
    def hip_servo(self) -> Servo:
        return self._hip_servo

    @property
    def knee_servo(self) -> Servo:
        return self._knee_servo

    @property
    def ankle_servo(self) -> Servo:
        return self._ankle_servo

Stap 2: Testen (in `main.py`)

We maken nu geen losse Servos meer aan, maar één Leg.

# In main.py
# Importeer de NIEUWE Leg klasse
from spiderpi_core.leg import Leg

print("--- Start Compositie Test ---")

# Maak één 'Leg' object.
# De __init__ van Leg zal AUTOMATISCH 3 Servo-objecten aanmaken.
front_leg = Leg(id_hip=1, id_knee=2, id_ankle=3)

print("--- Testen voltooid ---")

# We kunnen nu bij de 'sub-objecten' via de getters:
print(f"De ID van de heup-servo is: {front_leg.hip_servo.id}")
print(f"De hoek van de knie-servo is: {front_leg.knee_servo.current_angle}")

Stap 3: Resultaat

De output van main.py toont de "cascade" van constructors:

Nieuw Servo object (ID: 1) wordt gemaakt...
Nieuw Servo object (ID: 2) wordt gemaakt...
Nieuw Servo object (ID: 3) wordt gemaakt...
Leg aangemaakt met servo's: 1, 2, 3
--- Testen voltooid ---
De ID van de heup-servo is: 1
De hoek van de knie-servo is: 90.0
