M1.8: Compositie (Basis)

Leeruitkomsten

  • Ik begrijp het OOP-concept van Compositie (een "Heeft-Een" relatie).
  • Ik kan een "container" klasse maken die andere objecten bevat.
  • Ik kan objecten binnen andere objecten aanmaken in de __init__.

Uitleg: Grotere Objecten Bouwen

We hebben een perfecte Servo klasse. Maar een poot (Leg) van de robot bestaat uit drie servo's: heup, knie en enkel.

De relatie is: Een Leg-object heeft servo's. Dit heet Compositie.

  • Een Leg heeft-een Servo (voor de heup).
  • Een Leg heeft-een Servo (voor de knie).
  • Een Leg heeft-een Servo (voor de enkel).

We maken een nieuwe "container" klasse, leg.py. In de __init__ van de Leg gaan we daadwerkelijk drie Servo-objecten aanmaken en opslaan als properties. 

# In een nieuw bestand: leg.py
# We importeren onze eigen Servo klasse
# (De '.' gaat ervan uit dat we in een package zitten, zie Module 2)
from .servo import Servo

class Leg:
    """Modelleert een poot, opgebouwd uit 3 servo's."""

    # We slaan de servo-objecten op in properties
    hip_servo: Servo
    knee_servo: Servo
    ankle_servo: Servo

    def __init__(self, hip_id: int, knee_id: int, ankle_id: int):
        """
        Constructor van de 'container' klasse.
        Maakt zelf de 'onderdeel'-objecten aan.
        """
        print(f"Nieuwe Leg wordt gemaakt met IDs {hip_id}, {knee_id}, {ankle_id}")

        # COMPOSITIE:
        # De Leg maakt zijn eigen Servo-objecten aan en 'bezit' ze.
        self.hip_servo = Servo(id_num=hip_id, start_angle=90.0)
        self.knee_servo = Servo(id_num=knee_id, start_angle=90.0)
        self.ankle_servo = Servo(id_num=ankle_id, start_angle=90.0)

Uitleg: Compositie Testen

In main.py hoeven we nu alleen nog maar de Leg aan te maken. De Leg regelt het aanmaken van de servo's zelf.

Dit aanmaken roept een "cascade" (kettingreactie) van __init__ calls aan: de Leg constructor roept 3 keer de Servo constructor aan. 

# In main.py
from .leg import Leg # Importeer de nieuwe Leg klasse

# Maak 1 poot.
front_left_leg = Leg(hip_id=1, knee_id=2, ankle_id=3)

# We kunnen nu door de 'lagen' van objecten heen:
print(f"De hoek van de knie is: {front_left_leg.knee_servo.current_angle}")
print(f"Het ID van de heup is: {front_left_leg.hip_servo.id}")

# Output:
# Nieuwe Leg wordt gemaakt met IDs 1, 2, 3
# Nieuw Servo object (ID: 1) wordt gemaakt...
# Nieuw Servo object (ID: 2) wordt gemaakt...
# Nieuw Servo object (ID: 3) wordt gemaakt...
# De hoek van de knie is: 90.0
# Het ID van de heup is: 1
