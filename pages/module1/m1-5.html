M1.5: Getters (Read-Only)

Theorie: Data Veilig Lezen (Encapsulatie)

Probleem: Onze set_angle (Setter) is nu veilig, maar een gebruiker kan de validatie nog steeds omzeilen! In main.py kan iemand nog steeds dit doen:
motor.current_angle = 9000
Dit stelt de property *direct* in, zonder onze if/else te gebruiken.

Oplossing: Encapsulatie (Afschermen). We 'verstoppen' de echte data-property en geven de gebruiker alleen toegang via onze veilige methoden.

  1. We hernoemen de 'echte' data naar self._current_angle (met een underscore _). Dit is de Python-conventie voor "protected": "blijf hier af, dit is intern".
  2. We maken een Getter met @property. Dit is een speciale methode die eruitziet als een property (je roept hem aan zonder haakjes) maar alleen kan *lezen*.

Stap-voor-stap Voorbeeld (in `servo.py`)

Stap 1: Vóór (Code uit M1.4)

# In servo.py
class Servo:
    # Onveilig! Iedereen kan dit direct aanpassen.
    current_angle = 90.0
    id = 0

    def set_angle(self, new_angle):
        if ...:
            self.current_angle = new_angle # Past de publieke var aan
        # ...

Stap 2: Na (Refactor naar Protected + Getter)

We hernoemen current_angle naar _current_angle in de *hele* klasse. Daarna voegen we de @property getter toe.

# In servo.py
MIN_ANGLE = 0.0
MAX_ANGLE = 180.0

class Servo:
    # De 'echte' data is nu 'protected' (verstopt)
    _current_angle = 90.0 # We geven een default waarde
    id = 0 # 'id' is nog wel public (fixen we later)

    def set_angle(self, new_angle):
        """SETTER: Past de *protected* property aan."""
        if new_angle >= MIN_ANGLE and new_angle <= MAX_ANGLE:
            self._current_angle = new_angle # Past _current_angle aan
            print(f"Motor {self.id} beweegt naar {self._current_angle} gr.")
        else:
            print(f"FOUT: Hoek {new_angle} is ongeldig.")

    # De GETTER
    @property
    def current_angle(self):
        """GETTER: Leest de *protected* property 'read-only' uit."""
        return self._current_angle

Stap 3: Testen (in `main.py`)

Probeer nu de waarde te lezen en direct te schrijven.

# In main.py
motor = Servo()
motor.id = 1
motor.set_angle(120.0)

# 1. Lezen (dit werkt, het gebruikt de getter)
print(f"Hoek is: {motor.current_angle}")

# 2. Schrijven (dit crasht nu!)
print("Probeer de hoek direct op 200.0 te zetten...")
try:
    motor.current_angle = 200.0
except AttributeError as e:
    print(f"GELUKT: De code crashte met: {e}")

# 3. De 'verstopte' property (niet doen, maar het kan)
print(f"De 'echte' interne waarde is: {motor._current_angle}")

Stap 4: Resultaat

Onze data is nu veilig! De enige manier om de hoek aan te passen is via de set_angle methode, die onze validatie uitvoert.

Motor 1 beweegt naar 120.0 gr.
Hoek is: 120.0
Probeer de hoek direct op 200.0 te zetten...
GELUKT: De code crashte met: can't set attribute 'current_angle'
De 'echte' interne waarde is: 120.0
