M1.3: Methoden (Gedrag)

Theorie: Gedrag Toevoegen

We hebben data (Properties). Nu hebben we gedrag nodig. [cite_start]Methoden zijn functies die *in* een klasse leven en het gedrag van objecten van die klasse definiëren[cite: 2189].

  • Analogie: Een Auto-object heeft data (kleur). Het heeft ook gedrag: .start_motor() of .toeteren().
  • SpiderPi: Ons Servo-object heeft data (current_angle). [cite_start]Het heeft gedrag nodig, zoals .set_angle(hoek)[cite: 2189].

Het self Keyword

Methoden binnen een klasse hebben altijd self als hun eerste parameter. Het self keyword verwijst naar het *specifieke object zelf* (bv. motor_voor_rechts) dat de methode aanroept. Hiermee kan de methode de eigen properties van dat object lezen of aanpassen.

Stap-voor-stap Voorbeeld

Stap 1: Vóór (in `servo.py`)

Onze klasse was leeg en deed niets.

# In servo.py
class Servo:
    pass

Stap 2: Na (Methode toevoegen in `servo.py`)

We voegen de methode set_angle toe. Deze methode ontvangt self (het object zelf) en new_angle (de input).

# In servo.py
class Servo:
    """Modelleert een enkele motor (servo)."""

    # Dit is een methode (een functie binnen een klasse)
    def set_angle(self, new_angle):
        """
        Stelt de hoek van deze specifieke servo in.
        'self' verwijst naar het object dat deze methode aanroept.
        """

        # Gebruik 'self' om de property van DIT object aan te passen
        self.current_angle = new_angle

        # We gebruiken 'self.id' (aangemaakt in main.py)
        print(f"Motor {self.id} beweegt nu naar {self.current_angle} graden.")

Stap 3: De Methode Aanroepen (in `main.py`)

We passen main.py aan om de nieuwe methode aan te roepen (te "callen").

# In main.py
from servo import Servo

motor = Servo()
motor.id = 1
motor.current_angle = 90.0
print(f"Beginhoek: {motor.current_angle}")

# Roep de methode aan op het object
motor.set_angle(110.0)

# De property is nu aangepast
print(f"Nieuwe hoek: {motor.current_angle}")

Stap 4: Testen

python main.py

De output laat zien dat de methode *binnen* het object de data van *datzelfde* object heeft aangepast:

Beginhoek: 90.0
Motor 1 beweegt nu naar 110.0 graden.
Nieuwe hoek: 110.0
