M1.3: Methoden (Gedrag)

Theorie: Gedrag Toevoegen

We hebben data (Properties). Nu hebben we gedrag nodig. Methoden zijn functies die in een klasse leven en het gedrag van objecten van die klasse definiëren.

  • Vergelijking (Auto): Een Auto-object heeft data (kleur). Het heeft ook gedrag: .start_motor() of .toeteren().
  • SpiderPi: Ons Servo-object heeft data (current_angle). Het heeft gedrag nodig, zoals .set_angle(hoek).

Het self Keyword

Methoden binnen een klasse hebben altijd self als hun eerste parameter. Het self keyword verwijst naar het *specifieke object zelf* dat de methode aanroept. Hiermee kan de methode de eigen properties van dat object lezen of aanpassen.

Python Voorbeeld

We passen servo.py aan om gedrag toe te voegen.

# In servo.py
class Servo:
    """Modelleert een enkele motor (servo)."""

    # Dit is een methode (een functie binnen een klasse)
    def set_angle(self, new_angle):
        """
        Stelt de hoek van deze specifieke servo in.
        'self' verwijst naar het object dat deze methode aanroept.
        """

        # Gebruik 'self' om de property van DIT object aan te passen
        self.current_angle = new_angle

        # We gebruiken 'self.id' (aangemaakt in main.py)
        print(f"Motor {self.id} beweegt nu naar {self.current_angle} graden.")

# In main.py
from servo import Servo

motor = Servo()
motor.id = 1
motor.current_angle = 90.0
print(f"Beginhoek: {motor.current_angle}")

# Roep de methode aan op het object
motor.set_angle(110.0)

# De property is nu aangepast
print(f"Nieuwe hoek: {motor.current_angle}")
