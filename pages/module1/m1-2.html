M1.2: Properties (Eigenschappen)

Leeruitkomsten

  • Ik begrijp het concept van Properties als data die de toestand van een object definiëren.
  • Ik kan properties toewijzen en uitlezen op een object-instantie met de punt-notatie.

Uitleg: Properties Toewijzen

Een object is pas nuttig als het data kan opslaan. Deze data, die de unieke toestand van een object beschrijft, noemen we Properties (eigenschappen).

Vergelijking (Auto): Een Auto-object kan een kleur-property hebben. mijn_auto.kleur = "blauw".

De makkelijkste manier om een property toe te wijzen, is door de punt-notatie (de .) te gebruiken nadat je het object hebt gemaakt. Het servo.py bestand blijft leeg (pass). 

# In main.py
from servo import Servo

# Maak de 'lege' objecten
right_hip_motor = Servo()
left_knee_motor = Servo()

# Stel de unieke properties (toestand) in
right_hip_motor.id = 3
right_hip_motor.current_angle = 90.0

left_knee_motor.id = 11
left_knee_motor.current_angle = 100.5

Uitleg: Properties Lezen

Op dezelfde manier kun je de data uitlezen met de punt-notatie. 

# In main.py (vervolg)

# Lees de properties uit
print(f"Motor {right_hip_motor.id} heeft hoek: {right_hip_motor.current_angle}")
print(f"Motor {left_knee_motor.id} heeft hoek: {left_knee_motor.current_angle}")

# Output:
# Motor 3 heeft hoek: 90.0
# Motor 11 heeft hoek: 100.5

Belangrijk

Dit is een snelle manier om te leren wat properties zijn. In een latere les (M1.6) zullen we ontdekken waarom dit een slechte gewoonte is (wat als je een property vergeet in te stellen?) en leren we een professionelere manier.
