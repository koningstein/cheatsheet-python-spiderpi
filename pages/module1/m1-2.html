M1.2: Properties (Eigenschappen)

Theorie: De Toestand van een Object

Een object (ons 'huis') is pas nuttig als het *data* kan opslaan. [cite_start]Deze data, die de unieke toestand van een object beschrijft, noemen we Properties (eigenschappen)[cite: 2277].

  • Analogie: Een Auto-object kan een kleur-property hebben. mijn_auto.kleur = "blauw" en buurman_auto.kleur = "rood".
    • [cite_start]
  • SpiderPi: Onze Servo-objecten hebben een id en een current_angle (huidige hoek) nodig[cite: 2189, 2283, 2284, 2285].

In Python gebruiken we de punt-notatie (.) om een property in te stellen of uit te lezen.

(Opmerking: We leren dit nu 'dynamisch' toe te voegen in main.py. In Les M1.6 leren we de professionele manier om dit *in* de klasse te doen met een __init__ constructor.)

Stap-voor-stap Voorbeeld

We passen main.py aan. servo.py blijft leeg (pass).

Stap 1: Vóór (Code uit M1.1)

Dit is wat we hadden. De objecten zijn leeg.

# In main.py
from servo import Servo

motor_voor_rechts = Servo()
motor_achter_links = Servo()

Stap 2: Na (Properties Toevoegen)

We voegen data (toestand) toe aan de objecten *nadat* ze zijn gemaakt.

# In main.py
from servo import Servo

# Maak de objecten
motor_voor_rechts = Servo()
motor_achter_links = Servo()

# Stel de unieke properties (toestand) in
motor_voor_rechts.id = 3
motor_voor_rechts.current_angle = 90.0

motor_achter_links.id = 16
motor_achter_links.current_angle = 100.5

# Lees de properties uit
print(f"Motor {motor_voor_rechts.id} heeft hoek: {motor_voor_rechts.current_angle}")
print(f"Motor {motor_achter_links.id} heeft hoek: {motor_achter_links.current_angle}")

Stap 3: Testen

Voer main.py opnieuw uit.

python main.py

De output laat zien dat elk object zijn eigen, unieke data heeft opgeslagen:

Motor 3 heeft hoek: 90.0
Motor 16 heeft hoek: 100.5
