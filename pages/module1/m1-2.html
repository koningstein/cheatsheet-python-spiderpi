M1.2: Properties (Eigenschappen)

Theorie: De Toestand van een Object

Een object (zoals het Servo-object dat we in les 1.1 hebben gemaakt) is pas nuttig als het *data* kan opslaan. Deze data, die de unieke toestand van een object beschrijft, noemen we Properties (eigenschappen).

  • Vergelijking (Auto): Een Auto-object kan een kleur-property hebben. mijn_auto.kleur = "blauw" en buurman_auto.kleur = "rood".
  • SpiderPi: Onze Servo-objecten hebben een id en een current_angle nodig. [cite: 58-59]

In Python gebruiken we de punt-notatie (.) om een property in te stellen of uit te lezen.

Python Voorbeeld

We passen main.py aan om properties *toe te voegen* aan de objecten nadat we ze hebben gemaakt. servo.py blijft leeg.

# In main.py
from servo import Servo

# Maak de objecten
right_hip_motor = Servo()
left_knee_motor = Servo()

# Stel de unieke properties (toestand) in
right_hip_motor.id = 3
right_hip_motor.current_angle = 90.0

left_knee_motor.id = 11
left_knee_motor.current_angle = 100.5

# Lees de properties uit
print(f"Motor {right_hip_motor.id} heeft hoek: {right_hip_motor.current_angle}")
print(f"Motor {left_knee_motor.id} heeft hoek: {left_knee_motor.current_angle}")

# Output:
# Motor 3 heeft hoek: 90.0
# Motor 11 heeft hoek: 100.5
