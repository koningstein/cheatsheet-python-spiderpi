M1.9: Compositie Methoden (Delegatie)

Theorie: Werk Delegeren

Het is onhandig om poot.hip_servo.set_angle(90) te moeten schrijven (we gaan er even vanuit dat hip_servo een getter is die het object teruggeeft). De 'buitenwereld' wil niet weten dat een poot servo's *heeft*. De buitenwereld wil gewoon zeggen: "Poot, ga naar positie X".

We maken een *nieuwe methode* in de 'container'-klasse (Leg). Deze methode roept *zelf* de methoden van zijn eigen Servo-objecten aan. Dit heet Delegatie: de Leg-klasse delegeert het 'zet hoek'-werk aan de Servo-klassen die hij bezit.

Python Voorbeeld

# In leg.py
from .servo import Servo

class Leg:
    # ... (init met _hip_servo, etc.) ...
    # ... (getters voor de servo's) ...

    # Een nieuwe, slimmere methode
    def move_to_angles(self, hip: float, knee: float, ankle: float) -> None:
        """
        Beweegt de hele poot in één keer.
        DELEGEERT het werk aan de individuele servo-objecten.
        """
        print(f"Poot (ID {self._hip_servo.id}) beweegt...")

        # Delegatie aan de methoden van de sub-objecten
        self._hip_servo.set_angle(hip)
        self._knee_servo.set_angle(knee)
        self._ankle_servo.set_angle(ankle)

# --- In main.py ---
from spiderpi_core.leg import Leg

front_leg = Leg(id_hip=1, id_knee=2, id_ankle=3)

# De nieuwe, schone aanroep:
front_leg.move_to_angles(hip=100.0, knee=110.0, ankle=120.0)
