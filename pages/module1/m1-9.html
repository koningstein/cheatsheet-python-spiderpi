M1.9: Compositie Methoden (Delegatie)

Theorie: Werk Delegeren

Probleem: In main.py moeten we nu dit schrijven om een poot te bewegen:
front_leg.hip_servo.set_angle(100.0)
front_leg.knee_servo.set_angle(110.0)
front_leg.ankle_servo.set_angle(120.0)
Dit is "micromanagement". De 'buitenwereld' (main.py) moet te veel weten over de *interne* onderdelen van een Leg.

Oplossing: Delegatie. We maken een *nieuwe, slimmere methode* in de 'container'-klasse (Leg), bijvoorbeeld move_to_angles(). Deze methode roept *zelf* de methoden van zijn eigen Servo-objecten aan.

[cite_start]

De Leg-klasse delegeert het 'zet hoek'-werk aan de Servo-klassen die hij bezit[cite: 2189].

Stap-voor-stap Voorbeeld

Stap 1: De Methode toevoegen (in `leg.py`)

We voegen move_to_angles toe aan onze Leg klasse.

# In leg.py
from .servo import Servo

class Leg:
    # ... (init en de 3 getters) ...

    # Een nieuwe, slimmere methode
    def move_to_angles(self, hip: float, knee: float, ankle: float) -> None:
        """
        Beweegt de hele poot in één keer.
        DELEGEERT het werk aan de individuele servo-objecten.
        """
        print(f"Poot (start-ID {self._hip_servo.id}) beweegt...")

        try:
            # Delegatie aan de methoden van de sub-objecten
            self._hip_servo.set_angle(hip)
            self._knee_servo.set_angle(knee)
            self._ankle_servo.set_angle(ankle)
        except ValueError as e:
            print(f"FOUT: Ongeldige hoek voor poot: {e}")

Stap 2: Testen (in `main.py`)

Ons main.py script wordt nu veel schoner en makkelijker te lezen.

# In main.py
from spiderpi_core.leg import Leg

front_leg = Leg(id_hip=1, id_knee=2, id_ankle=3)

# Oude manier (micromanagement, niet meer doen):
# print("Oude manier:")
# front_leg.hip_servo.set_angle(100.0)
# front_leg.knee_servo.set_angle(110.0)
# front_leg.ankle_servo.set_angle(120.0)

# De nieuwe, schone aanroep:
print("\nNieuwe manier (Delegatie):")
front_leg.move_to_angles(hip=100.0, knee=110.0, ankle=120.0)

# Test ook de validatie
print("\nValidatie Test:")
front_leg.move_to_angles(hip=90.0, knee=9000.0, ankle=90.0)
