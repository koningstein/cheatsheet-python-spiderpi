M1.9: Compositie Methoden (Delegatie)

Leeruitkomsten

  • Ik kan methoden maken in een 'container' class die acties doorgeven aan sub-objecten.
  • Ik begrijp het principe van Delegatie: de "baas" laat de "medewerkers" het werk doen.
  • Ik kan de interactie met complexe objecten vereenvoudigen (Abstraction).

1. Het Probleem: Micromanagement

In de vorige les (M1.8) moesten we in main.py diep graven om een servo te bewegen:
front_left_leg.knee_servo.set_angle(90).

Dit is "micromanagement". De code in main.py moet precies weten hoe een poot in elkaar zit (dat hij een knie heeft, en dat die knie een servo is). Als we de poot later veranderen, breekt onze code in main.

De Oplossing: We geven de Leg class zijn eigen commando's. We willen gewoon kunnen zeggen: "Poot, ga naar stand X". De poot regelt intern wel hoe de servo's moeten bewegen. Dit heet Delegatie.

2. Code: De Methode Toevoegen

We voegen een methode set_all_angles toe aan de Leg klasse in leg.py. Deze methode neemt drie hoeken aan (voor heup, knie, enkel) en geeft ze door aan de juiste servo's. 

# In leg.py
from .servo import Servo

class Leg:
    # ... (properties en __init__ uit M1.8) ...

    def set_all_angles(self, hip_angle: float, knee_angle: float, ankle_angle: float) -> None:
        """
        Zet de hoeken van alle drie de servo's in deze poot tegelijk.
        De Leg DELEGEERT het echte werk naar zijn Servo-objecten.
        """
        print(f"Poot (met heup-ID {self.hip_servo.id}) beweegt naar posities...")

        # We roepen de methoden van de interne objecten aan
        self.hip_servo.set_angle(hip_angle)
        self.knee_servo.set_angle(knee_angle)
        self.ankle_servo.set_angle(ankle_angle)

3. Uitleg: Wat gebeurt hier?

De Leg klasse fungeert nu als een interface (tussenpersoon).

  • De buitenwereld roept 1 methode aan op de Poot.
  • De Poot roept 3 methoden aan op de Servo's.

Dit maakt onze code in main.py veel schoner en leesbaarder. We hoeven niet meer te weten dat er servo-objecten in de poot zitten; we praten alleen met de poot.

4. Code: De Nieuwe Aanroep

Laten we dit testen in main.py. We vervangen de oude, ingewikkelde aanroepen door de nieuwe, simpele methode. 

# In main.py
from .leg import Leg

# 1. Maak de poot aan (Compositie)
front_leg = Leg(hip_id=1, knee_id=2, ankle_id=3)

# 2. Beweeg de hele poot in één keer (Delegatie)
#    We hoeven niet meer 'front_leg.hip_servo.set_angle' te typen.
print("\n--- Beweging Start ---")
front_leg.set_all_angles(90.0, 110.0, 15.5)

# Output verwachting:
# Poot (met heup-ID 1) beweegt naar posities...
# Motor 1 beweegt naar 90.0 graden.
# Motor 2 beweegt naar 110.0 graden.
# Motor 3 beweegt naar 15.5 graden.
