M1.4: Setters met Validatie

Theorie: Data Beschermen

Een Setter is een methode die bedoeld is om een property *veilig* in te stellen. [cite_start]Het grote voordeel hiervan is dat we validatie (controles) kunnen inbouwen[cite: 2189].

Probleem: Wat als een gebruiker motor.set_angle(9000) aanroept? De echte servo kan maar tot 180 graden en zal kapot gaan.

Oplossing: We voegen een if/else-statement toe in de setter. Deze controleert de waarde *voordat* deze wordt ingesteld.

Stap-voor-stap Voorbeeld

Stap 1: Vóór (in `servo.py`)

Onze methode uit M1.3 was 'dom'. Het accepteerde elke waarde.

# In servo.py
class Servo:
    def set_angle(self, new_angle):
        self.current_angle = new_angle # Onveilig!
        print(f"Motor {self.id} beweegt nu naar {self.current_angle} gr.")

Stap 2: Na (Validatie toevoegen in `servo.py`)

We voegen Constanten (MIN_ANGLE, MAX_ANGLE) toe bovenaan ons bestand. Dit zijn variabelen die nooit veranderen. Daarna voegen we de if/else check toe in de setter.

# In servo.py

# Constanten (bovenaan het bestand, in HOOFDLETTERS)
MIN_ANGLE = 0.0
MAX_ANGLE = 180.0

class Servo:
    def set_angle(self, new_angle):
        """Stelt de hoek in, MAAR alleen als deze geldig is."""

        # De VALIDATIE-check
        if new_angle >= MIN_ANGLE and new_angle <= MAX_ANGLE:
            # Alleen als het veilig is, stellen we de property in
            self.current_angle = new_angle
            print(f"Motor {self.id} beweegt naar {self.current_angle} gr.")
        else:
            # Weiger de ongeldige waarde
            print(f"FOUT: Hoek {new_angle} is ongeldig en wordt genegeerd.")

Stap 3: Testen (in `main.py`)

Nu testen we onze beveiliging in main.py.

# In main.py
from servo import Servo

motor = Servo()
motor.id = 1
motor.current_angle = 90.0 # Stel de beginwaarde in
print(f"Beginhoek: {motor.current_angle}")

# Test 1: Ongeldige waarde (te hoog)
print("Test 1: Zet hoek naar 200.0")
motor.set_angle(200.0)
print(f"Huidige hoek is nog steeds: {motor.current_angle}")

# Test 2: Geldige waarde
print("\nTest 2: Zet hoek naar 120.0")
motor.set_angle(120.0)
print(f"Huidige hoek is nu: {motor.current_angle}")

Stap 4: Resultaat

De output van main.py laat zien dat onze validatie werkt. De ongeldige waarde wordt geweigerd en de property wordt niet aangepast.

Beginhoek: 90.0
Test 1: Zet hoek naar 200.0
FOUT: Hoek 200.0 is ongeldig en wordt genegeerd.
Huidige hoek is nog steeds: 90.0

Test 2: Zet hoek naar 120.0
Motor 1 beweegt naar 120.0 gr.
Huidige hoek is nu: 120.0
