M1.4: Setters met Validatie

Theorie: Data Beschermen

Een Setter is een methode die bedoeld is om een property *veilig* in te stellen. Het grote voordeel hiervan is dat we validatie (controles) kunnen inbouwen.

We willen niet dat iemand motor.set_angle(9000) kan instellen. Een setter-methode kan dit controleren met een if/else-statement en de ongeldige waarde weigeren.

  • Vergelijking (Bankrekening): Een .opnemen(bedrag) methode (een setter voor je saldo) moet controleren: if bedrag > self.saldo: print("Dat kan niet!").
  • SpiderPi: We controleren of de hoek binnen een veilige grens ligt (bv. 0-180 graden).

Python Voorbeeld

# In servo.py

# Constanten (bovenaan het bestand)
MIN_ANGLE = 0.0
MAX_ANGLE = 180.0

class Servo:
    # ...
    def set_angle(self, new_angle):
        """Stelt de hoek in, MAAR alleen als deze geldig is."""

        # De VALIDATIE-check
        if new_angle >= MIN_ANGLE and new_angle <= MAX_ANGLE:
            self.current_angle = new_angle
            print(f"Motor {self.id} beweegt naar {self.current_angle} gr.")
        else:
            # Weiger de ongeldige waarde
            print(f"FOUT: Hoek {new_angle} is ongeldig.")

# In main.py
from servo import Servo

motor = Servo()
motor.id = 1
motor.current_angle = 90.0

motor.set_angle(200.0)  # Output: FOUT: Hoek 200.0 is ongeldig.
motor.set_angle(120.0)  # Output: Motor 1 beweegt naar 120.0 gr.
