M7.2: Implementatie (Kleurdetector)

Uitleg: De Eerste Implementatie

Nu we het contract (het Protocol) hebben, gaan we onze eerste echte machine bouwen die zich aan dat contract houdt: de ColorDetector.

Deze klasse doet precies wat we in Module 6 hebben geleerd: hij zoekt naar een specifieke kleur (met HSV) en maakt daar een zwart-wit masker van.

Het verschil is dat deze code nu netjes in zijn eigen klasse zit, los van de camera en los van de robot.

Stap 1: De Klasse en Instellingen

We werken verder in spiderpi_core/vision.py. Voeg bovenaan import cv2 toe.

De ColorDetector heeft instellingen nodig: naar welke kleur moet hij zoeken? Deze grenzen (lower en upper) geven we mee als we de detector aanmaken. 

# In spiderpi_core/vision.py
import cv2
import numpy as np
# ... (VisionProcessorProtocol staat hierboven) ...

class ColorDetector:
    """
    Een Vision Processor die zoekt naar een specifieke kleur.
    """
    _lower_bound: np.ndarray
    _upper_bound: np.ndarray

    def __init__(self, lower_bound: np.ndarray, upper_bound: np.ndarray) -> None:
        """
        Sla de kleur-grenzen op zodat we ze later kunnen gebruiken.
        """
        self._lower_bound = lower_bound
        self._upper_bound = upper_bound

Stap 2: Het Contract Uitvoeren

Nu komt het belangrijkste deel. Om aan het protocol te voldoen, MOETEN we een methode hebben die precies analyze_frame(self, frame) heet.

In deze methode zetten we de logica uit Module 6.6. 

    def analyze_frame(self, frame: np.ndarray) -> np.ndarray:
        """
        Implementeert het protocol.
        Vindt de kleur en geeft een 'mask' (zwart-wit) beeld terug.
        """
        # 1. Converteer het beeld naar HSV-kleuren
        hsv_frame = cv2.cvtColor(frame, cv2.COLOR_BGR2HSV)

        # 2. Filter de kleur eruit (maak het masker)
        #    Alles binnen de grenzen wordt wit, de rest zwart.
        mask = cv2.inRange(hsv_frame, self._lower_bound, self._upper_bound)

        # Geef het masker terug. Dit is ook een 'frame' (plaatje), dus dat mag.
        return mask

Uitleg: Klaar voor Gebruik

We hebben nu een los onderdeel gemaakt: de ColorDetector. Je kunt hem aanmaken, instellen op "Rood", en vervolgens elk plaatje dat je hem geeft laten analyseren. Hij weet niets van de robot, en dat maakt hem heel flexibel.
