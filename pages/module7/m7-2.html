M7.2: Implementatie (Kleurdetector)

Theorie: Het Contract Vervullen (Deel 1)

In Les 7.1 hebben we het *contract* (het 'stopcontact') gemaakt. Nu maken we de *implementatie* (de 'stekker').

We maken een klasse ColorDetector. In Python hoef je niet expliciet implements te schrijven. Als jouw klasse een methode heeft die *exact* analyze_frame(self, frame) heet, "implementeert" het automatisch het protocol. Dit heet Duck Typing.

We verplaatsen de logica uit Module 6 (HSV, inRange) [cite: 251-252] *uit* de Camera / Robot klassen en *in* deze nieuwe, gespecialiseerde klasse.

Python Voorbeeld (`vision.py`)

We voegen de ColorDetector klasse toe aan spiderpi_core/vision.py.

# In spiderpi_core/vision.py
from typing import Protocol
import numpy as np
import cv2

# ... (VisionProcessorProtocol van Les 7.1) ...

class ColorDetector: # Erft *niet* (voor nu)
    """
    Een concrete implementatie van een vision processor.
    Vindt een specifieke kleur.
    Deze klasse 'past' op het VisionProcessorProtocol.
    """
    _lower_bound: np.ndarray
    _upper_bound: np.ndarray

    def __init__(self, lower_bound: np.ndarray, upper_bound: np.ndarray) -> None:
        """Slaat de te zoeken kleurgrenzen op."""
        self._lower_bound = lower_bound
        self._upper_bound = upper_bound

    def analyze_frame(self, frame: np.ndarray) -> np.ndarray:
        """
        Implementeert het protocol.
        Vindt de kleur en geeft een 'mask' (zwart-wit) beeld terug.
        """
        # 1. Converteer naar HSV (Logica uit M6.6)
        hsv_frame = cv2.cvtColor(frame, cv2.COLOR_BGR2HSV)

        # 2. Maak de 'mask'
        mask = cv2.inRange(hsv_frame, self._lower_bound, self._upper_bound)

        return mask # Geeft het zwart-wit masker terug

Testen: Je kunt main.py tijdelijk aanpassen om deze processor te gebruiken en cv2.imshow("Mask", mask) te tonen.
