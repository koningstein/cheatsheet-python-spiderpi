M7.5: Implementatie (Gebarenherkenning)

Theorie: Vormen Vinden (Contours)

Probleem: Hoe detecteer je een "open hand"? Het heeft geen vaste kleur (zoals de lijn) of vaste vorm (zoals een gezicht).

Oplossing: We zoeken naar *vormen* (contouren). We implementeren een *vierde* processor die het analyze_frame contract volgt.

Logica (Simpel):

  1. Maak het beeld *extreem* contrastrijk (binair: alleen zwart of wit). Dit heet Thresholding.
  2. Vraag OpenCV om *alle* vormen (omtrekken) te vinden: cv2.findContours().
  3. Vind de *grootste* vorm (contour) in de lijst.
  4. Kijk naar de *oppervlakte* (cv2.contourArea()). Als de oppervlakte > 5000 (een 'magic number'), gaan we ervan uit dat het een gebaar is.
  5. Teken die grootste vorm op het *originele* beeld.
  6. Geef het *originele* beeld terug.

Python Voorbeeld (`vision.py`)

We voegen een *vierde* implementatie toe aan vision.py.

# In spiderpi_core/vision.py
# ... (FaceDetector) ...

class GestureDetector:
    """Een vierde 'stekker'. Detecteert grote vormen/gebaren."""

    _min_area: int

    def __init__(self, min_area: int = 5000):
        self._min_area = min_area

    def analyze_frame(self, frame: np.ndarray) -> np.ndarray:
        """
        Implementeert het protocol.
        Vindt grote 'contouren' (bv. een hand).
        """
        # 1. Converteer en filter (Threshold)
        gray = cv2.cvtColor(frame, cv2.COLOR_BGR2GRAY)
        blur = cv2.GaussianBlur(gray, (5, 5), 0)
        # 'Threshold' zet alles < 70 op Zwart (0), alles > 70 op Wit (255)
        _, thresh = cv2.threshold(blur, 70, 255, cv2.THRESH_BINARY_INV)

        # 2. Vind vormen
        contours, _ = cv2.findContours(thresh, cv2.RETR_EXTERNAL, cv2.CHAIN_APPROX_SIMPLE)

        if contours: # Als er vormen zijn gevonden
            # 3. Vind de grootste
            biggest_contour = max(contours, key=cv2.contourArea)

            # 4. Check oppervlakte
            if cv2.contourArea(biggest_contour) > self._min_area:
                # 5. Teken de vorm
                cv2.drawContours(frame, [biggest_contour], -1, (0, 255, 0), 3) # Groen

        # 6. Geef frame terug
        return frame
