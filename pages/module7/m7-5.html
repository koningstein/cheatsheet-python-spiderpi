M7.5: Implementatie (Gebarenherkenning)

Uitleg: Vormen Vinden

De laatste processor is de GestureDetector. We willen een simpel gebaar herkennen, bijvoorbeeld iemand die zijn hand voor de lens houdt.

Een hand heeft geen vaste kleur en vorm. Daarom gebruiken we een andere techniek: 1. Maak het beeld extreem contrastrijk (alles is zwart of wit). Dit heet Thresholding. 2. Zoek de omtreklijnen van alle witte vlakken. Dit heten Contours. 3. Als een vlak heel groot is, tekenen we er een lijn omheen.

Stap 1: Thresholding (Contrast)

Eerst maken we het beeld grijswaarden. Daarna gebruiken we cv2.threshold om alles wat donkerder is dan een bepaalde waarde zwart te maken, en de rest wit. 

class GestureDetector:
    """Detecteert grote vormen/gebaren."""
    _min_area: int

    def __init__(self, min_area: int = 5000):
        # We zoeken alleen vormen die groter zijn dan 5000 pixels
        self._min_area = min_area

    def analyze_frame(self, frame: np.ndarray) -> np.ndarray:
        # 1. Maak zwart-wit en vervaag een beetje (tegen ruis)
        gray = cv2.cvtColor(frame, cv2.COLOR_BGR2GRAY)
        blur = cv2.GaussianBlur(gray, (5, 5), 0)

        # 2. Threshold: Maak extreem contrast
        # Alles lichter dan 70 wordt zwart, de rest wit (Inverse)
        _, thresh = cv2.threshold(blur, 70, 255, cv2.THRESH_BINARY_INV)

Stap 2: Contouren Vinden en Tekenen

Nu vragen we OpenCV om alle vormen in dat zwart-wit beeld te vinden. We zoeken de grootste uit en kijken of hij groot genoeg is. 

        # 3. Vind alle vormen (contours)
        contours, _ = cv2.findContours(thresh, cv2.RETR_EXTERNAL, cv2.CHAIN_APPROX_SIMPLE)

        if contours: # Als er überhaupt iets gevonden is
            # Zoek de allergrootste vorm
            biggest = max(contours, key=cv2.contourArea)

            # 4. Check of hij groot genoeg is (is het een hand?)
            if cv2.contourArea(biggest) > self._min_area:
                # 5. Teken de vorm in groen op het originele beeld
                cv2.drawContours(frame, [biggest], -1, (0, 255, 0), 3)

        return frame
