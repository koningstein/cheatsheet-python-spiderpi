M7.8: Testing (Detectors)

Uitleg: Vision Testen zonder Camera

Hoe test je of de ColorDetector werkt? Je kunt niet van een computer verwachten dat hij een echte camera heeft en dat jij er met een rood papiertje voor gaat staan.

We gebruiken Mocking (namaken). We maken met code een nep-plaatje.

We gaan twee tests schrijven: 1. Een test met een zwart plaatje. De detector moet 0 pixels vinden. 2. Een test met een rood plaatje. De detector moet alle pixels vinden.

Stap 1: De Test Setup

Maak een nieuw testbestand tests/test_vision.py. We definiëren eerst wat we onder "rood" verstaan. 

# In tests/test_vision.py
import pytest
import numpy as np
import cv2
from spiderpi_core.vision import ColorDetector

# Definieer de test-kleur (Rood in HSV)
LOWER = np.array([0, 120, 70])
UPPER = np.array([10, 255, 255])

# De kleur rood in BGR (voor het maken van het nep-plaatje)
TEST_RED_BGR = (50, 42, 200)

Stap 2: Test Zwart Beeld

We maken een plaatje met alleen maar nullen (zwart). 

def test_detector_finds_nothing_in_black_image():
    """Test of de detector een zwart beeld negeert."""
    detector = ColorDetector(LOWER, UPPER)

    # Maak een nep-beeld (100x100 pixels, zwart)
    test_img = np.zeros((100, 100, 3), dtype=np.uint8)

    # Analyseer
    mask = detector.analyze_frame(test_img)

    # Tel pixels (moet 0 zijn)
    count = cv2.countNonZero(mask)
    assert count == 0

Stap 3: Test Rood Beeld

We maken een plaatje en vullen het volledig met de rode kleur. 

def test_detector_finds_red_in_red_image():
    """Test of de detector een rood beeld vindt."""
    detector = ColorDetector(LOWER, UPPER)

    # Maak een nep-beeld (100x100), gevuld met onze rode kleur
    test_img = np.full((100, 100, 3), TEST_RED_BGR, dtype=np.uint8)

    mask = detector.analyze_frame(test_img)
    count = cv2.countNonZero(mask)

    # Omdat het hele plaatje rood is, moet de count gelijk zijn aan
    # het totaal aantal pixels (100 * 100 = 10000)
    assert count == 10000

Stap 4: Draaien

Draai de test in je terminal. 

(venv) C:\...> pytest
