M7.8: Testing (Detectors)

Theorie: Vision Testen (Mocking)

Dit is een *herhaling* van het pytest concept (M5.6) [cite: 249-250].

Probleem: Hoe test je ColorDetector automatisch? Je kunt niet *eisen* dat de build-server (of de docent) een *live camera* en een *rode stift* heeft.

Oplossing: Mocking (Test-Data Maken). We *maken* een nep-frame (een NumPy array) waarvan we het antwoord *weten*.

  • We maken een *volledig zwart* plaatje met np.zeros().
  • We maken een *gekleurd* plaatje met np.full().

We *geven* deze nep-plaatjes aan de detector en *beweren* (assert) dat het antwoord klopt.

Python Voorbeeld (`tests/test_vision.py`)

We maken een nieuw testbestand in de tests/ map.

# In tests/test_vision.py
import pytest
import numpy as np
import cv2
from spiderpi_core.vision import ColorDetector

# Definieer de test-kleur
LOWER_RED = np.array([0, 120, 70])
UPPER_RED = np.array([10, 255, 255])
# Een BGR-kleur die binnen de HSV-range valt
# (HSV(5, 200, 200) -> BGR(50, 42, 200))
TEST_RED_BGR = (50, 42, 200)

def test_color_detector_finds_nothing():
    """Test of de detector een zwart beeld negeert."""
    # 1. Maak de detector
    detector = ColorDetector(LOWER_RED, UPPER_RED)

    # 2. Maak een nep-beeld (100x100, zwart)
    test_img = np.zeros((100, 100, 3), dtype=np.uint8)

    # 3. Voer de analyse uit
    mask = detector.analyze_frame(test_img)
    count = cv2.countNonZero(mask)

    # 4. Beweer (Assert)
    assert count == 0

def test_color_detector_finds_red():
    """Test of de detector een 100% rood beeld volledig detecteert."""
    detector = ColorDetector(LOWER_RED, UPPER_RED)

    # 2. Maak een nep-beeld (100x100, rood)
    test_img = np.full((100, 100, 3), TEST_RED_BGR, dtype=np.uint8)

    # 3. Voer de analyse uit
    mask = detector.analyze_frame(test_img)
    count = cv2.countNonZero(mask)

    # 4. Beweer (Assert)
    assert count == 10000 # 100 * 100 pixels

# --- Terminal ---
# (venv) C:\...> pytest
