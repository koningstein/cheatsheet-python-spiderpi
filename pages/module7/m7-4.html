M7.4: Implementatie (Gezichtsherkenning)

Theorie: AI-Model (Haar Cascades)

We hoeven niet *alle* logica zelf te schrijven. OpenCV komt met kant-en-klare, getrainde modellen voor o.a. gezichtsherkenning. De klassieke (en snelste) heet Haar Cascade.

Het is een .xml bestand dat je moet downloaden. We maken een *derde* processor, FaceDetector, die dit model gebruikt en ook het analyze_frame contract volgt.

Logica:

  1. __init__: Je *laadt* het model: cv2.CascadeClassifier('haar_cascade_file.xml').
  2. analyze_frame:
    • Converteer het beeld naar Grayscale (zwart-wit), want dat werkt beter.
    • Vraag het model: "Vind alle gezichten": self._cascade.detectMultiScale(gray_frame).
    • Dit geeft een lijst van rechthoeken: (x, y, breedte, hoogte).
    • Loop door de lijst en teken de rechthoeken op het *originele* frame.
    • Geef het *originele* frame terug.

Python Voorbeeld (`vision.py`)

We voegen een *derde* implementatie toe aan vision.py. (Het .xml bestand moet je in de hoofdmap van je project zetten).

# In spiderpi_core/vision.py
# ... (LineFollowProcessor) ...

class FaceDetector:
    """Een derde 'stekker'. Gebruikt een pre-trained AI-model."""
    _cascade: cv2.CascadeClassifier

    def __init__(self, cascade_xml_path: str):
        self._cascade = cv2.CascadeClassifier(cascade_xml_path)
        if self._cascade.empty():
            raise IOError(f"Kan cascade model niet laden: {cascade_xml_path}")

    def analyze_frame(self, frame: np.ndarray) -> np.ndarray:
        """
        Implementeert het protocol.
        Vindt gezichten en tekent er een rechthoek omheen.
        """
        # 1. Converteer naar Grayscale
        gray_frame = cv2.cvtColor(frame, cv2.COLOR_BGR2GRAY)

        # 2. Detecteer gezichten
        faces = self._cascade.detectMultiScale(gray_frame, 1.1, 4)

        # 3. Teken rechthoeken
        for (x, y, w, h) in faces:
            cv2.rectangle(frame, (x, y), (x+w, y+h), (255, 0, 0), 2) # Blauw

        # 4. Geef originele frame terug
        return frame
