M7.4: Implementatie (Gezichtsherkenning)

Uitleg: AI Gebruiken

We gaan nog een stap verder. We maken een FaceDetector die AI gebruikt om gezichten te herkennen.

Hiervoor gebruiken we een techniek die Haar Cascades heet. Dit is een kant-en-klaar AI-model dat in OpenCV zit. Je hebt alleen een bestandje nodig met de "kennis" van het model (een XML-bestand).

Stap 1: Het Model Laden

In de __init__ moeten we het AI-bestand laden. Dit kan soms fout gaan (bijvoorbeeld als het bestand niet bestaat), dus we bouwen een check in. 

class FaceDetector:
    """Gebruikt AI om gezichten te vinden."""

    # Een variabele voor het AI-model
    _cascade: cv2.CascadeClassifier

    def __init__(self, xml_path: str):
        # Probeer het AI-bestand te laden
        self._cascade = cv2.CascadeClassifier(xml_path)

        # Check of het gelukt is (is het model niet leeg?)
        if self._cascade.empty():
            raise IOError(f"Kan AI-model niet laden: {xml_path}")

Stap 2: Gezichten Zoeken en Tekenen

De AI werkt het beste op zwart-wit beelden (dat is sneller). We gebruiken detectMultiScale om te zoeken.

Als de AI iets vindt, krijgen we een lijst met coördinaten: x, y (linksboven) en w, h (breedte en hoogte). Daar tekenen we een rechthoek omheen. 

    def analyze_frame(self, frame: np.ndarray) -> np.ndarray:
        # 1. Maak een tijdelijke zwart-wit kopie (voor de AI)
        gray = cv2.cvtColor(frame, cv2.COLOR_BGR2GRAY)

        # 2. Vraag de AI om te zoeken
        # Dit geeft een lijst van gezichten terug
        faces = self._cascade.detectMultiScale(gray, scaleFactor=1.1, minNeighbors=4)

        # 3. Loop door alle gevonden gezichten
        for (x, y, w, h) in faces:
            # Teken een blauw vierkant op het originele kleurenbeeld
            # (255, 0, 0) is Blauw in OpenCV
            cv2.rectangle(frame, (x, y), (x+w, y+h), (255, 0, 0), 2)

        # 4. Geef het beeld (met vierkantjes) terug
        return frame
