M7.7: Sensor Integratie

Uitleg: Vision IS een Sensor

Soms willen we geen plaatje zien in een venster, maar willen we gewoon een getal. Bijvoorbeeld: "Hoeveel rood zie je?"

In Module 5.5 hebben we een contract gemaakt voor sensoren: AbstractSensor. Dat contract eist een methode read_value() die een getal teruggeeft.

Onze Vision Processors geven een plaatje terug. Dat past dus niet op de sensor-aansluiting.

We kunnen een Adapter maken. Dit is een klasse die zich gedraagt als een Sensor (hij geeft een getal), maar stiekem Vision gebruikt om dat getal te berekenen.

Stap 1: De Adapter Maken

We maken ColorVisionSensor in sensors.py. Hij moet erven van AbstractSensor (zodat de robot denkt dat het een gewone sensor is). Maar hij moet een Camera en een Detector bezitten (zodat hij kan kijken). 

# In spiderpi_core/sensors.py
from .camera import Camera
from .vision import ColorDetector
import cv2
import numpy as np
# ... (AbstractSensor) ...

class ColorVisionSensor(AbstractSensor):
    """
    Gedraagt zich als een sensor (geeft een getal),
    maar gebruikt de camera om rode pixels te tellen.
    """
    _camera: Camera
    _detector: ColorDetector

    def __init__(self, camera: Camera, lower: np.ndarray, upper: np.ndarray):
        self._camera = camera
        # We maken hier intern een detector aan
        self._detector = ColorDetector(lower, upper)

Stap 2: De Vertaling

Nu implementeren we de read_value methode. Hier vindt de vertaling plaats van "Plaatje" naar "Getal". 

    def read_value(self) -> float:
        """Leest de sensor: telt de gekleurde pixels."""

        # 1. Haal het plaatje op
        frame = self._camera.get_frame()
        if frame is None:
            return 0.0

        # 2. Vraag de detector om het masker (het zwart-wit plaatje)
        mask = self._detector.analyze_frame(frame)

        # 3. Tel de witte pixels
        count = cv2.countNonZero(mask)

        # 4. Geef het aantal terug als float (zoals het contract eist)
        return float(count)

Stap 3: Testen

Nu kunnen we de camera uitlezen alsof het een afstandssensor is. 

# In main.py
from spiderpi_core.sensors import ColorVisionSensor
from spiderpi_core.camera import Camera
import numpy as np

cam = Camera()
# Rood filter
L = np.array([0, 120, 70])
U = np.array([10, 255, 255])

# Maak de 'slimme' sensor
red_sensor = ColorVisionSensor(cam, L, U)

# Lees hem uit
waarde = red_sensor.read_value()
print(f"Aantal rode pixels: {waarde}")
