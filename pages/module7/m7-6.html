M7.6: Polymorfische Koppeling

Theorie: De 'Slimme' Robot

Probleem: main.py is nu onze 'router' en testbank. De *robot* (SpiderPi) weet niet eens dat er 'processors' bestaan.

Oplossing (De 'Payoff'): We maken de robot *slimmer*.

  1. De SpiderPi krijgt een *nieuwe* property: self._processor, die het Protocol (het 'stopcontact') als type hint heeft.
  2. De SpiderPi krijgt een *nieuwe* methode: set_vision_processor(processor).
  3. De SpiderPi.stream() methode stopt met zelf-detecteren. Het *delegeert* al het analyse-werk aan self._processor.analyze_frame().

main.py wordt nu heel simpel: het kiest (via CLI) welke 'stekker' (FaceDetector, ColorDetector) het in het 'stopcontact' van de robot stopt.

Python Voorbeeld

1. De 'slimme' Robot (in robot.py)

# In spiderpi_core/robot.py
# Importeer het CONTRACT (Interface)
from .vision import VisionProcessorProtocol

class SpiderPi(RobotComponent):
    _processor: VisionProcessorProtocol | None = None # Het 'stopcontact'
    # ...

    def set_vision_processor(self, processor: VisionProcessorProtocol) -> None:
        """Stelt de actieve 'vision brain' (de 'stekker') in."""
        self._processor = processor

    def stream(self) -> None:
        """De 'slimme' stream loop."""
        # ... (camera check)
        while True:
            frame = self._camera.get_frame()
            if frame is None: break

            # --- POLYMORFISME ---
            if self._processor:
                # We weten niet welke het is, en het boeit niet!
                processed_frame = self._processor.analyze_frame(frame)
            else:
                processed_frame = frame # Geen processor? Toon origineel.

            cv2.imshow("SpiderPi Stream", processed_frame)
            if cv2.waitKey(1) & 0xFF == ord('q'):
                break
        cv2.destroyAllWindows()

2. De 'Router' (in main.py)

# In main.py
from spiderpi_core.robot import SpiderPi
from spiderpi_core.vision import (
    FaceDetector, ColorDetector, LineFollowProcessor
)

# ... (argparse setup voor --detector) ...
args = parser.parse_args()
my_robot = SpiderPi()
processor = None # Default

# --- De 'Processor Factory' ---
if args.detector == "face":
    processor = FaceDetector("haarcascade_frontalface_default.xml")
elif args.detector == "color":
    processor = ColorDetector(LOWER_RED, UPPER_RED)
elif args.detector == "line":
    processor = LineFollowProcessor(LOWER_LINE, UPPER_LINE)

# --- De Koppeling ---
if processor:
    my_robot.set_vision_processor(processor)  # Stop de 'stekker' erin

# --- De Actie ---
if args.action == "stream":
    my_robot.stream() # De robot regelt de rest!
