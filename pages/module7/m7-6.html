M7.6: Polymorfische Koppeling

Uitleg: Het Stopcontact Maken

We hebben nu 4 verschillende "stekkers" (processors) gebouwd: Kleur, Lijn, Gezicht, Gebaar. Ze doen allemaal iets anders, maar ze passen op dezelfde aansluiting.

Nu moeten we het "stopcontact" in de robot maken.

De robot hoeft niet te weten welke processor hij heeft. Hij hoeft alleen maar te weten dat hij analyze_frame kan aanroepen. Dit heet Polymorfisme.

Stap 1: Robot Voorbereiden

Open spiderpi_core/robot.py. We importeren het Protocol. Daarna maken we een plekje (variabele) in de robot waar we de processor kunnen opslaan. 

# In spiderpi_core/robot.py
from .vision import VisionProcessorProtocol

class SpiderPi(RobotComponent):
    # ... (andere properties) ...

    # Nieuw: Het 'stopcontact'. Kan leeg zijn (None).
    _processor: VisionProcessorProtocol | None = None

    def set_vision_processor(self, processor: VisionProcessorProtocol) -> None:
        """Stopt een 'stekker' (processor) in de robot."""
        self._processor = processor
        print("Vision processor ingesteld.")

Stap 2: De Stream Aanpassen

In de stream() methode (die we in M6.5 maakten) gaan we nu de processor gebruiken.

We kijken eerst of er een processor is ingesteld. Zo ja, dan laten we die het beeld bewerken. 

    def stream(self) -> None:
        # ... (camera check en loop) ...
        while True:
            frame = self._camera.get_frame()
            if frame is None: break

            # --- HIER GEBEURT DE MAGIE ---
            if self._processor:
                # De robot vraagt de processor om het beeld te bewerken.
                # Het maakt de robot niet uit WAT voor processor het is!
                processed_frame = self._processor.analyze_frame(frame)
            else:
                # Geen processor? Toon gewoon het origineel
                processed_frame = frame

            cv2.imshow("SpiderPi Stream", processed_frame)
            # ... (waitKey en break)

Stap 3: Kiezen in Main

Nu kunnen we in main.py heel makkelijk wisselen van functionaliteit. We kiezen een processor en geven die aan de robot. 

# In main.py
from spiderpi_core.vision import FaceDetector

my_robot = SpiderPi()

# We kiezen vandaag voor de FaceDetector
# (Zorg dat je het XML bestand hebt!)
processor = FaceDetector("haarcascade_frontalface_default.xml")

# Koppel hem aan de robot
my_robot.set_vision_processor(processor)

# Start de stream. Je ziet nu vierkantjes om gezichten!
my_robot.stream()
