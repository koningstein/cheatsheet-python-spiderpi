M7.3: Implementatie (Lijnvolg Processor)

Theorie: Het 'Aha!' Moment

Dit is de les waar het concept 'Interface' klikt. We maken een *tweede* klasse, LineFollowProcessor, die *ook* het VisionProcessorProtocol volgt. Hij *moet* dus ook een analyze_frame methode hebben, maar de *inhoud* (logica) is totaal anders.

Lijnvolg-logica (Simpel):

  1. Filter op de lijnkleur (bv. zwart) -> Krijg een mask.
  2. Vind het *midden* van de lijn in dat mask. (Hiervoor gebruiken we cv2.moments).
  3. Teken een stip op het *originele* beeld op dat middenpunt.
  4. Geef het *originele* beeld (met stip) terug.

De 'buitenwereld' roept .analyze_frame() aan en weet niet (en hoeft niet te weten) welke complexe logica erin zit.

Python Voorbeeld (`vision.py`)

We voegen een *tweede* implementatie toe aan vision.py.

# In spiderpi_core/vision.py
# ... (imports en ColorDetector) ...

class LineFollowProcessor:
    """Een tweede 'stekker' die ook in het 'stopcontact' past."""

    def __init__(self, lower_line_hsv: np.ndarray, upper_line_hsv: np.ndarray):
        self._lower_line = lower_line_hsv
        self._upper_line = upper_line_hsv

    def analyze_frame(self, frame: np.ndarray) -> np.ndarray:
        """
        Implementeert het protocol.
        Vindt het midden van de lijn en tekent een stip.
        """
        # 1. Filter op lijnkleur (mask)
        hsv = cv2.cvtColor(frame, cv2.COLOR_BGR2HSV)
        mask = cv2.inRange(hsv, self._lower_line, self._upper_line)

        # 2. Vind midden (cv2.moments is een 'recept' om dit te doen)
        M = cv2.moments(mask)
        if M["m00"] > 0: # Zeker weten dat we niet delen door 0
            # Bereken X en Y van het midden
            cX = int(M["m10"] / M["m00"])
            cY = int(M["m01"] / M["m00"])

            # 3. Teken stip op origineel beeld
            cv2.circle(frame, (cX, cY), 7, (0, 0, 255), -1) # Rode stip

        # 4. Geef originele frame terug
        return frame
