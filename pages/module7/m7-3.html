M7.3: Implementatie (Lijnvolger)

Uitleg: Een Tweede Soort Detector

Om te bewijzen dat ons systeem flexibel is, maken we een tweede detector die iets heel anders doet: de LineFollowProcessor.

Deze detector moet een lijn (bijvoorbeeld zwart plakband op een witte vloer) vinden. Hij doet meer dan alleen kleuren filteren; hij berekent ook waar het midden van die lijn is en tekent daar een stip.

Maar voor de buitenwereld (de robot) ziet hij er precies hetzelfde uit als de ColorDetector, want hij heeft dezelfde analyze_frame methode.

Stap 1: Setup

We voegen deze klasse toe aan spiderpi_core/vision.py. Ook hier slaan we de kleur van de lijn (zwart of wit) op in de __init__. 

class LineFollowProcessor:
    """Zoekt het midden van een lijn en tekent een stip."""

    _lower_line: np.ndarray
    _upper_line: np.ndarray

    def __init__(self, lower_line_hsv: np.ndarray, upper_line_hsv: np.ndarray):
        self._lower_line = lower_line_hsv
        self._upper_line = upper_line_hsv

Stap 2: Filteren en Rekenen

In analyze_frame doen we eerst hetzelfde als bij de kleurdetector: filteren. Daarna gebruiken we een wiskundige functie van OpenCV, moments, om het zwaartepunt van de witte pixels te berekenen. 

    def analyze_frame(self, frame: np.ndarray) -> np.ndarray:
        # 1. Maak een masker van de lijn
        hsv = cv2.cvtColor(frame, cv2.COLOR_BGR2HSV)
        mask = cv2.inRange(hsv, self._lower_line, self._upper_line)

        # 2. Bereken het zwaartepunt (M) van de witte vlek
        M = cv2.moments(mask)

        if M["m00"] > 0: # Check om delen door 0 te voorkomen
            # Bereken de X en Y coördinaten van het midden
            cX = int(M["m10"] / M["m00"])
            cY = int(M["m01"] / M["m00"])

            # 3. Teken een rode stip op die plek in het ORIGINELE beeld
            # (argument -1 betekent: gevulde cirkel)
            cv2.circle(frame, (cX, cY), 7, (0, 0, 255), -1)

        # 4. Geef het bewerkte plaatje (met stip) terug
        return frame

Uitleg: Het Verschil

De ColorDetector gaf een zwart-wit masker terug. Deze LineFollowProcessor geeft het originele kleurenbeeld terug, maar dan met een rode stip erop getekend.
