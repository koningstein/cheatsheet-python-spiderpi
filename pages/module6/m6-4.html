M6.4: Integratie (SpiderPi Compositie)

Uitleg: De Ogen in de Robot Zetten

We hebben nu een Camera klasse. Maar de camera zweeft nog los rond. De camera is onderdeel van de robot.

De relatie is: Een SpiderPi HEEFT EEN Camera.

Dit is weer Compositie (zoals de poten). We passen de SpiderPi klasse aan zodat hij automatisch een camera aanmaakt bij het opstarten.

Stap 1: Robot aanpassen

Open spiderpi_core/robot.py. We importeren de Camera en voegen hem toe aan de __init__. 

# In spiderpi_core/robot.py
from .leg import Leg
from .component import RobotComponent
from .camera import Camera # IMPORTEREN
import cv2

class SpiderPi(RobotComponent):
    # ... (andere properties)
    _camera: Camera | None # Type Hint (kan None zijn als hij stuk is)

    def __init__(self) -> None:
        super().__init__(name="SpiderPi_Robot")
        # ... (poten aanmaken) ...

        # COMPOSITIE: Maak de Camera
        try:
            self._camera = Camera()
        except (IOError, cv2.error) as e:
            print(f"WAARSCHUWING: Kon camera niet starten: {e}")
            self._camera = None # We gaan door zonder camera

    # Een getter om erbij te kunnen
    @property
    def camera(self) -> Camera | None:
        return self._camera

Uitleg: Wat hebben we nu?

Als we nu my_robot = SpiderPi() doen, wordt automatisch de camera gestart. Als de camera niet werkt (bijvoorbeeld niet aangesloten), crasht de robot niet, maar geeft hij een waarschuwing.
