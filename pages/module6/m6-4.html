M6.4: Integratie (SpiderPi Compositie)

Theorie: De Ogen in de Robot Zetten

We hebben nu twee losse "hoofd-objecten": my_robot = SpiderPi() en cam = Camera().

Dit is niet logisch. De camera is onderdeel van de robot. De relatie is: Een SpiderPi HEEFT EEN Camera.

Dit is Compositie (herhaling van M1.8 en M1.10). [cite: 247-248] We passen de __init__ van SpiderPi aan zodat deze *automatisch* een Camera-object aanmaakt en beheert.

Python Voorbeeld (`robot.py`)

We passen robot.py aan om de Camera te 'bevatten'.

# In spiderpi_core/robot.py
from .leg import Leg
from .component import RobotComponent
from .camera import Camera # Stap 1: Importeer de Camera
import cv2 # Nodig voor de IOError

class SpiderPi(RobotComponent):
    # ... (alle _leg... properties)
    _camera: Camera | None # Stap 2: Voeg de property type hint toe

    def __init__(self) -> None:
        super().__init__(name="SpiderPi_Robot")
        # ... (alle 6 de poten aanmaken) ...

        # Stap 3: Maak het Camera object (met foutafhandeling)
        try:
            self._camera = Camera()
        except (IOError, cv2.error) as e:
            print(f"WAARSCHUWING: Kon camera niet starten: {e}")
            self._camera = None # Robot werkt door, maar zonder camera

    # Stap 4: Maak een 'getter'
    @property
    def camera(self) -> Camera | None:
        return self._camera
