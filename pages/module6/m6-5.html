M6.5: Videostream CLI

Uitleg: Een Video is Veel Foto's

.get_frame() haalt één foto. Een video is simpelweg heel veel foto's achter elkaar (bijvoorbeeld 30 per seconde).

We hebben een Loop (herhaling) nodig die continu: 1. Een frame ophaalt. 2. Het frame op het scherm toont.

We gebruiken hiervoor cv2.imshow (toon venster) en cv2.waitKey.

Stap 1: De Stream Methode

We voegen een methode stream() toe aan de SpiderPi klasse. 

# In spiderpi_core/robot.py

    def stream(self) -> None:
        """Start een live videostream naar het scherm."""
        if not self._camera:
            print("Geen camera, kan niet streamen.")
            return

        print("Stream gestart. Druk op 'q' om te stoppen.")
        while True:
            # 1. Haal frame
            frame = self._camera.get_frame()
            if frame is None:
                break

            # 2. Toon frame op scherm
            cv2.imshow("SpiderPi Stream", frame)

            # 3. Wacht 1ms. Stop als 'q' wordt ingedrukt.
            if cv2.waitKey(1) & 0xFF == ord('q'):
                break

        # Sluit het venster netjes af
        cv2.destroyAllWindows()

Stap 2: De CLI Koppeling

We willen dit starten met een commando in de terminal. We voegen stream toe aan onze 'router' in main.py. 

# In main.py

# ... (in de if/else blok) ...
elif args.action == "stream":
    my_robot.stream()

Stap 3: Testen

Voer het commando uit in je terminal: 

(venv) C:\...> python main.py --action stream

Er moet nu een venster openen waarin je jezelf ziet! Druk op 'q' om te stoppen.
