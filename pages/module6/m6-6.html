M6.6: Kleurbereik Functie (HSV)

Uitleg: Hoe ziet een computer kleur?

Wij zien "rood". Een computer ziet RGB: Rood, Groen, Blauw. Maar "rood" in de schaduw heeft hele andere RGB-waardes dan "rood" in de zon. Dat is lastig te programmeren.

Daarom gebruiken we HSV (Hue, Saturation, Value).

  • H (Hue): De kleur zelf (0-179). Rood zit altijd rond 0.
  • S (Saturation): Hoe fel de kleur is.
  • V (Value): Hoe licht/donker het is.

Met HSV kunnen we makkelijk zeggen: "Ik wil alles wat Rood (H) is, ongeacht hoe donker (V) het is."

Stap 1: De Hulpfunctie

We voegen een methode toe aan camera.py die een kleuren-filter toepast. Hij maakt een "masker": een zwart-wit plaatje waarin alles wat rood is wit wordt, en de rest zwart. 

# In spiderpi_core/camera.py

    def _check_hsv_range(self, frame: np.ndarray, lower_bound: np.ndarray, upper_bound: np.ndarray) -> np.ndarray:
        """
        Filtert het beeld op kleur.
        Geeft een zwart-wit 'masker' terug.
        """

        # 1. Converteer van BGR (standaard) naar HSV
        hsv_frame = cv2.cvtColor(frame, cv2.COLOR_BGR2HSV)

        # 2. Maak het masker (filter)
        #    Zoekt alle pixels die TUSSEN de grenzen vallen.
        mask = cv2.inRange(hsv_frame, lower_bound, upper_bound)

        return mask

Uitleg: Wat hebben we nu?

We hebben nu een functie die de 'rode' pixels kan isoleren. In de volgende les gaan we tellen hoeveel het er zijn.
