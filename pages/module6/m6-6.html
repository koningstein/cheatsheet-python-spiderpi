M6.6: Kleurbereik Functie (HSV)

Theorie: Hoe 'Ziet' een Computer Kleur?

Probleem: We willen "rood" detecteren. Maar wat is "rood" in RGB (Rood, Groen, Blauw)?

  • (255, 0, 0) is felrood.
  • (180, 0, 0) is donkerrood.
  • (255, 100, 100) is lichtrood.

Dit is heel moeilijk te vangen in if-statements, omdat je met *lichtinval* te maken hebt (een schaduw maakt rood donkerder).

Oplossing: HSV (Hue, Saturation, Value)
We gebruiken een ander kleurmodel (een andere 'taal') om kleur te beschrijven:

  • H (Hue): De kleurtoon (0-179 in OpenCV). Rood zit *altijd* rond 0-10 en 170-179.
  • S (Saturation): De intensiteit/verzadiging (0-255). 0 = grijs, 255 = volle kleur.
  • V (Value): De helderheid (0-255). 0 = zwart, 255 = helder.

Het Voordeel: In HSV kunnen we zeggen: "Ik wil *alle* soorten rood, ongeacht de schaduw":
Hue moet tussen 0-10 liggen, Saturation moet feller zijn dan 100, en Value moet helderder zijn dan 100.

Dit vangen we in twee *grenzen*: een lower_bound (ondergrens) en een upper_bound (bovengrens).

Python Voorbeeld (`camera.py`)

We voegen een 'hulpfunctie' toe die een frame omzet naar HSV en filtert met cv2.inRange.

# In spiderpi_core/camera.py
import cv2
import numpy as np

class Camera:
    # ... (init, get_frame) ...

    def _check_hsv_range(self, frame: np.ndarray, lower_bound: np.ndarray, upper_bound: np.ndarray) -> np.ndarray:
        """
        Controleert een heel frame tegen HSV-grenzen.
        Dit is de basis voor kleurdetectie.

        Returns:
            np.ndarray: Een 'mask' (zwart-wit beeld) waar wit
                        is 'ja, kleur gevonden' en zwart is 'nee'.
        """

        # 1. Converteer het beeld van BGR (standaard OpenCV) naar HSV
        hsv_frame = cv2.cvtColor(frame, cv2.COLOR_BGR2HSV)

        # 2. Maak de 'mask' (het filter)
        #    Zoekt alle pixels die TUSSEN de grenzen vallen.
        mask = cv2.inRange(hsv_frame, lower_bound, upper_bound)

        return mask

Testen: Deze methode is lastig los te testen. De "win" van deze les is het begrijpen van HSV en het correct *definiëren* van de methode. We *gebruiken* hem in de volgende les.
