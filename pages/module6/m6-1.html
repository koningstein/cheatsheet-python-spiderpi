M6.1: De Camera Klasse

Uitleg: De Robot 'Ogen' Geven

We hebben een werkend model van de robot (M1-M5). Nu gaan we de robot zintuigen geven. We beginnen met 'zien'.

Om met een camera te praten in Python, gebruiken we de bibliotheek OpenCV (Open Computer Vision). Dit is de wereldwijde standaard voor alles wat met beelden te maken heeft. In de code heet deze library cv2.

Stap 1: Installeren

Eerst moeten we de software installeren in onze virtuele omgeving (venv). 

# Zorg dat je venv actief is
(venv) C:\...> pip install opencv-python

# Update je 'boodschappenlijst'
(venv) C:\...> pip freeze > requirements.txt
