M6.3: De .get_frame() Methode

Theorie: Een Foto Nemen (Een Frame Lezen)

Probleem: De camera is *aan* (dankzij __init__), maar we 'kijken' nog niet.

Oplossing: We hebben een methode nodig om één 'foto' op te vragen. In video heet een foto een Frame. Het VideoCapture object (dat in self._capture zit) heeft hiervoor een methode: .read().

succes, frame = self._capture.read() geeft twee dingen terug:

  1. succes: Een boolean (True / False). True als het gelukt is om een frame te lezen.
  2. frame: Het beeld zelf. Dit is een groot 'rooster' met getallen (een NumPy array) dat alle pixelkleuren bevat.

Onze eigen .get_frame() methode moet deze aanroep 'wrappen' (inpakken), controleren of het gelukt is, en alleen het frame teruggeven.

Python Voorbeeld (`camera.py`)

We voegen numpy toe voor de type hints en bouwen de methode.

1. Installeren (Terminal)

(venv) C:\...> pip install numpy
(venv) C:\...> pip freeze > requirements.txt

2. Methode toevoegen (in camera.py)

# ... (imports bovenaan)
import numpy as np

class Camera:
    # ... (__init__ van Les 6.2) ...

    def get_frame(self) -> np.ndarray | None:
        """
        Leest één frame van de camera.

        Returns:
            np.ndarray: Het frame (beeld) als een NumPy array.
            None: Als het lezen van het frame mislukt is.
        """
        # Vraag het frame op bij het OpenCV object
        success, frame = self._capture.read()

        if not success:
            print("FOUT: Kon geen frame lezen van camera.")
            return None

        return frame
