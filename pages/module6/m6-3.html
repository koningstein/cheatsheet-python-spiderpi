M6.3: De .get_frame() Methode

Uitleg: Een Foto Nemen

De camera staat aan, maar we zien niks. We moeten een Frame (een foto) opvragen.

Het OpenCV-object heeft hiervoor de methode .read(). Deze geeft twee dingen terug:

  1. success: Een True of False. Is het gelukt?
  2. frame: Het plaatje zelf (een lijst met pixels).

We maken onze eigen methode get_frame() die dit netjes voor ons regelt.

Stap 1: NumPy Installeren

Een "plaatje" is voor een computer een gigantische tabel met getallen (pixels). Python gebruikt hiervoor de bibliotheek NumPy. 

(venv) C:\...> pip install numpy
(venv) C:\...> pip freeze > requirements.txt

Stap 2: De Methode Bouwen

In camera.py voegen we de methode toe. We gebruiken np.ndarray als Type Hint voor "een plaatje". 

# ... (imports bovenaan) ...

class Camera:
    # ... (__init__ van Les 6.2) ...

    def get_frame(self) -> np.ndarray | None:
        """
        Leest één frame van de camera.
        Geeft None terug als het mislukt.
        """
        # Vraag het frame op bij het OpenCV object
        success, frame = self._capture.read()

        if not success:
            print("FOUT: Kon geen frame lezen van camera.")
            return None

        return frame

Uitleg: Resultaat

We kunnen nu camera.get_frame() aanroepen. We krijgen dan een plaatje terug waar we iets mee kunnen doen (opslaan, tonen, analyseren).
