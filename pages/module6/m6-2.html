M6.2: Compositie (VideoCapture)

Theorie: De Camera 'Connectie'

Probleem: Onze Camera klasse (M6.1) is leeg. Het is een 'doos' zonder inhoud.

Oplossing: We moeten *in* de __init__ de *echte* verbinding met de camera-hardware maken. In OpenCV is het object dat de *fysieke camera* vertegenwoordigt: cv2.VideoCapture(0).

Het getal 0 betekent "pak de eerste camera die je kunt vinden" (meestal de ingebouwde webcam of de Pi-camera).

Onze Camera klasse (de 'doos') *bevat* (heeft een) dit VideoCapture object. Dit is Compositie (herhaling van M1.8). [cite: 247-248]

Python Voorbeeld (`camera.py`)

We vullen de __init__ van onze Camera klasse.

# In spiderpi_core/camera.py
import cv2
import numpy as np

class Camera:
    """Vertegenwoordigt de hardware camera."""

    # We slaan het OpenCV object op in een 'protected' property
    _capture: cv2.VideoCapture

    def __init__(self) -> None:
        """Initialiseert de camera en 'grijpt' de hardware."""

        # Maak het OpenCV object
        self._capture = cv2.VideoCapture(0)

        if not self._capture.isOpened():
            # Een check of de camera wel echt gevonden is
            raise IOError("Kan de camera niet openen op index 0.")

        print("Camera succesvol geïnitialiseerd.")
