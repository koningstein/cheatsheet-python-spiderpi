M6.2: Compositie (VideoCapture)

Uitleg: De Verbinding Maken

Onze Camera klasse is nu nog een lege doos. We moeten verbinding maken met de echte hardware.

In OpenCV heet het object dat de camera bestuurt: cv2.VideoCapture.

We gebruiken Compositie (M1.8). Onze Camera klasse heeft een VideoCapture object. We maken dit object aan in de __init__.

Het getal 0 betekent "de eerste camera die je vindt" (meestal je webcam).

Stap 1: De __init__ vullen

Pas spiderpi_core/camera.py aan. We slaan de verbinding op in een _protected variabele. 

# In spiderpi_core/camera.py
import cv2
import numpy as np

class Camera:
    """Vertegenwoordigt de hardware camera."""

    # We slaan het OpenCV object op in een 'protected' property
    _capture: cv2.VideoCapture

    def __init__(self) -> None:
        """Initialiseert de camera en 'grijpt' de hardware."""

        # Maak het OpenCV object (0 = standaard webcam)
        self._capture = cv2.VideoCapture(0)

        # Check of het gelukt is
        if not self._capture.isOpened():
            raise IOError("Kan de camera niet openen op index 0.")

        print("Camera succesvol geïnitialiseerd.")

Uitleg: Wat gebeurt er?

Als je nu een Camera() object zou maken, gaat het lampje van je webcam aan. De verbinding is open. Maar... we zien nog geen beeld. We moeten de camera nog vragen om een foto te maken.
