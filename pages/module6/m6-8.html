M6.8: Debuggen Vision (NumPy Arrays)

Theorie: Kijken *in* de Data

Dit is een *herhaling* van de Debugger (M3.5) [cite: 245-246], maar nu toegepast op de complexe datatypen van Computer Vision.

Probleem: We gebruiken frame en mask als 'zwarte dozen'. Maar wat *zijn* het? print(frame) is nutteloos (duizenden getallen).

Oplossing: De Debugger. We zetten een Breakpoint en inspecteren de variabelen in het "Variables" paneel. Bij NumPy arrays (zoals frame en mask) letten we op 2 dingen:

  1. shape (Vorm):
    • frame.shape = (480, 640, 3)
    • Betekent: 480 rijen (hoogte), 640 kolommen (breedte), 3 kanalen (Blauw, Groen, Rood).
  2. mask.shape (Vorm):
    • mask.shape = (480, 640)
    • Betekent: 480 rijen, 640 kolommen. Het heeft maar 1 kanaal (het is zwart-wit).

Dit helpt ons te *zien* dat cvtColor en inRange de data daadwerkelijk transformeren.

Python Voorbeeld (Debugger Stappen)

Dit is een opdracht *zonder* nieuwe code. De opdracht is om de debugger te *gebruiken*.

# 1. Stel je Debugger in (bv. in VS Code 'launch.json')
#    om met de juiste argumenten te draaien:
#    "args": ["--action", "stream"]

# 2. Zet een Breakpoint in 'robot.py'
#    in de 'stream' methode, op de regel NA:
#    frame = self._camera.get_frame()

# 3. Zet een Breakpoint in 'camera.py'
#    in de 'get_color_amount' methode, op de regel NA:
#    mask = self._check_hsv_range(...)

# 4. Start Debugging (F5)
# 5. Inspecteer 'frame' bij Breakpoint 1:
#    - VARIABLES -> frame -> shape: (480, 640, 3)

# 6. Druk 'Continue' (F5)
# 7. Inspecteer 'mask' bij Breakpoint 2:
#    - VARIABLES -> mask -> shape: (480, 640)
