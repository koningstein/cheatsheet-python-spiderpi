M6.7: Basale Detectie (Pixels Tellen)

Theorie: Het Masker Tellen

In Les 6.6 hebben we een "mask" (masker) gemaakt.

  • Mask: Een zwart-wit plaatje.
  • Wit (waarde 255): De pixels die *wel* voldeden aan ons HSV-kleurbereik.
  • Zwart (waarde 0): De pixels die *niet* voldeden.

Probleem: We hebben een plaatje, maar we willen een *getal*. Hoeveel rood *is* er?

Oplossing: cv2.countNonZero(). Deze OpenCV functie telt simpelweg alle pixels die *niet nul* (dus wit) zijn in een masker.

  • Als cv2.countNonZero(mask) 0 teruggeeft -> Geen rood gezien.
  • Als cv2.countNonZero(mask) 5000 teruggeeft -> 5000 rode pixels gezien.

Python Voorbeeld (`robot.py` en `main.py`)

We maken een get_color_amount() methode en tonen het getal in onze stream.

1. De methode (in camera.py)

# In spiderpi_core/camera.py
class Camera:
    # ... (init, get_frame, _check_hsv_range) ...

    def get_color_amount(self, frame: np.ndarray, lower_bound: np.ndarray, upper_bound: np.ndarray) -> int:
        """
        Detecteert en telt pixels van een specifieke kleur.

        Returns:
            int: Het aantal pixels dat de kleur matcht.
        """
        # Stap 1: Krijg het masker (herhaling Les 6.6)
        mask = self._check_hsv_range(frame, lower_bound, upper_bound)

        # Stap 2: Tel de witte pixels
        pixel_count = cv2.countNonZero(mask)

        return pixel_count

2. De stream (in robot.py)

# In spiderpi_core/robot.py
import numpy as np
import cv2

# Definieer 'rood' als class variable
LOWER_RED = np.array([0, 120, 70])
UPPER_RED = np.array([10, 255, 255])

class SpiderPi(RobotComponent):
    # ...
    def stream(self) -> None:
        # ... (while True loop)
        frame = self._camera.get_frame()
        if frame is None: break

        # --- NIEUW ---
        pixel_aantal = self._camera.get_color_amount(frame, LOWER_RED, UPPER_RED)

        # Zet dit aantal op het scherm
        cv2.putText(frame, f"Rode Pixels: {pixel_aantal}", (10, 30),
                    cv2.FONT_HERSHEY_SIMPLEX, 1, (0, 255, 0), 2)
        # --- EINDE NIEUW ---

        cv2.imshow("SpiderPi Stream", frame)
        # ... (waitKey)

Testen: python main.py --action stream. Houd iets roods voor de camera en het getal moet omhoog schieten.
