M3.1: Type Hints (De Spelregels)

Theorie: Zeggen Wat Je Verwacht

Probleem: Python is 'dynamisch'. Dat betekent dat je dit kan doen: mijn_motor.set_angle("honderd"). Je code crasht pas *tijdens het uitvoeren* (run-time), diep in je if-statement.

Oplossing: Met Type Hints vertel je *vooraf* (als 'spelregel') wat voor type data je verwacht. Een moderne IDE (zoals VS Code) zal de student nu **direct waarschuwen** met een rood lijntje onder "honderd", nog *voordat* de code draait.

We gaan onze servo.py stap-voor-stap 'refactoren' (verbeteren).

Stap 1: Properties 'Hinten'

We vertellen de klasse welke properties een object zal hebben en welk type ze zijn. We voegen dit bovenaan de klasse-definitie toe.

# VOOR:
class Servo(RobotComponent):
    MIN_ANGLE = 0.0
    # ...

# NA:
class Servo(RobotComponent):
    _id: int
    _current_angle: float
    MIN_ANGLE: float = 0.0
    # ...

Stap 2: Constructor (`__init__`) 'Hinten'

We 'hinten' de parameters die binnenkomen (: int) en wat de methode teruggeeft (-> None, want een constructor geeft nooit iets terug).

# VOOR:
def __init__(self, start_id, start_angle):

# NA:
def __init__(self, start_id: int, start_angle: float) -> None:

Stap 3: Methoden 'Hinten'

Hetzelfde doen we voor alle methoden. set_angle verwacht een float en geeft niets (None) terug.

# VOOR:
def set_angle(self, new_angle):

# NA:
def set_angle(self, new_angle: float) -> None:

Stap 4: Getters 'Hinten'

Een @property getter geeft wél iets terug. We specificeren het return type (-> float).

# VOOR:
@property
def current_angle(self):

# NA:
@property
def current_angle(self) -> float:

Python Voorbeeld (Eindresultaat in `servo.py`)

Nadat je alle stappen hebt doorlopen, ziet je servo.py er zo uit:

# In spiderpi_core/servo.py

# Importeer de Ouder-klasse voor type hinting
from .component import RobotComponent

class Servo(RobotComponent):
    # Class-level type hints
    _id: int
    _current_angle: float
    MIN_ANGLE: float = 0.0
    MAX_ANGLE: float = 180.0

    # Method-level type hints
    def __init__(self, start_id: int, start_angle: float) -> None:
        super().__init__(name=f"Servo_{start_id}")
        self._id = start_id
        # We negeren de return value van set_angle hier
        self.set_angle(start_angle)

    def set_angle(self, new_angle: float) -> None:
        """Stelt de hoek in."""
        if not (self.MIN_ANGLE <= new_angle <= self.MAX_ANGLE):
            raise ValueError("Ongeldige hoek")
        self._current_angle = new_angle

    @property
    def current_angle(self) -> float:
        return self._current_angle

    @property
    def id(self) -> int:
        return self._id
