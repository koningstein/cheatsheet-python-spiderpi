M3.3: Encapsulatie (Conventie '_')

Theorie: Data Afschermen (Protected)

Encapsulatie (afschermen) is het idee dat een object zijn interne data moet beschermen. In plaats van public properties, geven we de 'buitenwereld' alleen toegang via veilige methoden (Getters en Setters).

In Python hebben we geen protected keyword. We gebruiken een conventie (afspraak): een enkele underscore (_) aan het begin van een property-naam.

self._current_angle betekent: "Hé, andere programmeur! Dit is interne data. Blijf hier af. Gebruik de .set_angle() of .current_angle getter."

We hebben dit in M1.5 al toegepast, maar we gaan het nu consequent voor *alle* interne properties doen.

Python Voorbeeld

We passen servo.py en leg.py aan. Alle properties worden nu 'protected' (beginnen met _) en krijgen een 'read-only' @property getter.

# In spiderpi_core/servo.py
class Servo(RobotComponent):
    _id: int # Was al _id in M1.6
    _current_angle: float # Was al _current_angle in M1.5
    # ...

    @property
    def id(self) -> int:
        return self._id

    @property
    def current_angle(self) -> float:
        return self._current_angle

    # ...

# In spiderpi_core/leg.py
from .servo import Servo

class Leg(RobotComponent):
    # Alle properties zijn nu _protected
    _hip_servo: Servo
    _knee_servo: Servo
    _ankle_servo: Servo

    def __init__(self, id_hip: int, id_knee: int, id_ankle: int) -> None:
        super().__init__(name=f"Leg_{id_hip}_{id_knee}_{id_ankle}")
        self._hip_servo = Servo(start_id=id_hip, start_angle=90.0)
        self._knee_servo = Servo(start_id=id_knee, start_angle=90.0)
        self._ankle_servo = Servo(start_id=id_ankle, start_angle=90.0)

    def move_to_angles(self, hip: float, knee: float, ankle: float) -> None:
        # Intern gebruiken we de _protected properties
        self._hip_servo.set_angle(hip)
        self._knee_servo.set_angle(knee)
        self._ankle_servo.set_angle(ankle)

    # Getters voor de buitenwereld (read-only)
    @property
    def hip_servo(self) -> Servo:
        return self._hip_servo

    @property
    def knee_servo(self) -> Servo:
        return self._knee_servo

    @property
    def ankle_servo(self) -> Servo:
        return self._ankle_servo

# In main.py
# my_robot.leg_front_r._hip_servo # FOUT! (Conventie geschonden)
# my_robot.leg_front_r.hip_servo # GOED! (Gebruikt de getter)
