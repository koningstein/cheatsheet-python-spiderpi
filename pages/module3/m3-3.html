M3.3: Encapsulatie (Conventie '_')

Uitleg: Data Afschermen (Protected)

Encapsulatie (afschermen) is een kernprincipe van OOP. Het idee is dat een object zijn interne data moet beschermen. In M1.5 zagen we al dat motor.current_angle = 9000 een probleem is.

In Python hebben we geen protected woord. We gebruiken een conventie (afspraak): een enkele underscore (_) aan het begin van een property-naam.

self._current_angle betekent: "Hé, andere programmeur! Dit is interne data. Blijf hier af. Gebruik de .set_angle() (setter) of .current_angle (getter)."

We gaan dit nu *consequent* toepassen op al onze interne properties in `servo.py` en `leg.py`.

Stap 1: Refactor `servo.py` (Herhaling M1.5)

Zorg dat in servo.py alle interne data met een _ begint en 'read-only' toegang heeft via een @property getter.

# In spiderpi_core/servo.py
class Servo(RobotComponent):
    _id: int
    _current_angle: float
    # ... (__init__ en set_angle gebruiken self._id en self._current_angle) ...

    @property
    def id(self) -> int:
        """GETTER voor het read-only ID."""
        return self._id

    @property
    def current_angle(self) -> float:
        """GETTER voor de read-only hoek."""
        return self._current_angle

Stap 2: Refactor `leg.py`

Nu passen we hetzelfde principe toe op leg.py. De Leg klasse 'bezit' drie servo-objecten. Dit zijn interne onderdelen, dus die moeten _protected zijn.

# In spiderpi_core/leg.py
from .servo import Servo
from .component import RobotComponent

class Leg(RobotComponent):
    # De properties zijn nu _protected
    _hip_servo: Servo
    _knee_servo: Servo
    _ankle_servo: Servo

    def __init__(self, id_hip: int, id_knee: int, id_ankle: int) -> None:
        super().__init__(name=f"Leg_{id_hip}_{id_knee}_{id_ankle}")
        # Sla op in _protected variabelen
        self._hip_servo = Servo(start_id=id_hip, start_angle=90.0)
        self._knee_servo = Servo(start_id=id_knee, start_angle=90.0)
        self._ankle_servo = Servo(start_id=id_ankle, start_angle=90.0)

    def move_to_angles(self, hip: float, knee: float, ankle: float) -> None:
        # Intern gebruiken we de _protected properties
        self._hip_servo.set_angle(hip)
        self._knee_servo.set_angle(knee)
        self._ankle_servo.set_angle(ankle)

    # Getters toevoegen voor 'read-only' toegang
    @property
    def hip_servo(self) -> Servo:
        return self._hip_servo

    @property
    def knee_servo(self) -> Servo:
        return self._knee_servo

    @property
    def ankle_servo(self) -> Servo:
        return self._ankle_servo
