M3.5: Debuggen (Basis)

Theorie: Stoppen met print()

Probleem: Fouten zoeken met print("DEBUG: waarde is", x) is traag, rommelig en je vergeet ze weg te halen.

Oplossing: Een Visuele Debugger. Dit is een tool in je IDE (zoals VS Code of PyCharm) waarmee je:

  • Breakpoints kunt zetten: Rode stippen naast de code die zeggen "Pauzeer hier!".
  • Stap-voor-stap door je code kunt lopen (Step Over, Step Into).
  • Live alle Variabelen (zoals self of new_angle) kunt bekijken.

Python Voorbeeld (Debugger Stappen)

Dit is een opdracht *zonder* nieuwe code. De opdracht is om de debugger te *gebruiken*.

# In main.py
from spiderpi_core.robot import SpiderPi

# 1. Zet een Breakpoint op de volgende regel:
my_robot = SpiderPi()

# 2. Start de Debugger (F5 in VS Code)
# 3. Code pauzeert. Druk Step Into (F11).
# 4. Je springt nu IN de __init__ van SpiderPi (in robot.py).
# 5. Druk op Step Over (F10) om regel voor regel te gaan.
# 6. Ga naar het 'VARIABLES' / 'VARIABLES' venster om 'self' te inspecteren.
# 7. Druk nogmaals Step Into als je op self._leg_front_r = Leg(...) staat.
# 8. Je springt nu IN de __init__ van Leg (in leg.py).
# 9. Druk nogmaals Step Into als je op self._hip_servo = Servo(...) staat.
# 10. Je springt nu IN de __init__ van Servo (in servo.py).

print("Debuggen voltooid.")
