M3.5: Debuggen (Basis)

Uitleg: Stoppen met print()

Probleem: Fouten zoeken met print("DEBUG: waarde is", x) is traag, rommelig en je vergeet ze weg te halen.

Oplossing: Een Visuele Debugger. Dit is een tool in je editor (zoals VS Code) die veel slimmer is. We leren 3 knoppen:

  1. Breakpoint (Rode Stip): Een "Stop!"-bord voor je code. Je klikt links naast het regelnummer.
  2. Step Over (F10): Voer de huidige (gele) regel uit en ga naar de *volgende* regel.
  3. Step Into (F11): Als de gele regel een functie of methode aanroept (bv. SpiderPi()), *spring* dan *in* die methode om te kijken wat daar gebeurt.

Terwijl de code pauzeert, kun je in het "Variables" venster *live* de inhoud van alle variabelen zien.

Opdracht: De 'Geboorte' van de Robot Volgen

Dit is een *doe*-opdracht. Je hoeft geen code te schrijven, alleen de debugger te gebruiken om de "kettingreactie" van constructors (uit M1.10) te volgen.

Stap 1: Het Breakpoint Zetten

Open main.py. Klik in de 'goot' (de ruimte links van het regelnummer) naast de regel my_robot = SpiderPi(). Er verschijnt een rode stip.

# In main.py
from spiderpi_core.robot import SpiderPi
import time

# 🔴 <-- Zet je Breakpoint (rode stip) hier
my_robot = SpiderPi()

my_robot.wake_up()
time.sleep(1)
my_robot.sleep()

Stap 2: De Eerste Sprong (Step Into)

Start de Debugger (meestal met F5). Je code start en pauzeert meteen op de gele regel.

Druk nu op Step Into (F11).

Je springt nu automatisch naar het bestand robot.py en landt in de __init__ methode. Je ziet nu deze code:

# In spiderpi_core/robot.py
class SpiderPi(RobotComponent):

    def __init__(self) -> None:
        # 🟨 <-- Je landt hier
        super().__init__(name="SpiderPi_Robot")
        print("SpiderPi robot wordt geassembleerd...")

        self._leg_front_r = Leg(id_hip=1, id_knee=2, id_ankle=3)
        # ...

Stap 3: Regels Uitvoeren (Step Over)

Je staat nu *in* robot.py. Druk een paar keer op Step Over (F10).

Kijk in het "Variables" venster aan de linkerkant. Je ziet dat self (de robot die gemaakt wordt) langzaam wordt opgebouwd. Je ziet de print()-regel in je terminal verschijnen.

Blijf op F10 drukken tot je op de regel staat waar de eerste poot (Leg) wordt gemaakt.

# In spiderpi_core/robot.py
class SpiderPi(RobotComponent):

    def __init__(self) -> None:
        super().__init__(name="SpiderPi_Robot")
        print("SpiderPi robot wordt geassembleerd...")

        # 🟨 <-- Druk op F10 tot je hier bent
        self._leg_front_r = Leg(id_hip=1, id_knee=2, id_ankle=3)
        # ...

Stap 4: De Tweede Sprong (De Kettingreactie)

Terwijl je op de Leg-regel staat, druk je *opnieuw* op Step Into (F11).

Je springt nu weer een bestand dieper, naar leg.py, en landt in de __init__ van de Leg klasse.

# In spiderpi_core/leg.py
class Leg(RobotComponent):

    def __init__(self, id_hip: int, id_knee: int, id_ankle: int) -> None:
        # 🟨 <-- Je landt hier
        super().__init__(name=f"Leg_{id_hip}_{id_knee}_{id_ankle}")

        self._hip_servo = Servo(start_id=id_hip, start_angle=90.0)
        # ...

Stap 5: De Laatste Sprong

Druk weer een paar keer op Step Over (F10) tot je op de regel staat waar de Servo wordt gemaakt.

Druk nog één keer op Step Into (F11).

Je springt nu naar servo.py en landt in de __init__ van de Servo. Je hebt de hele kettingreactie gevolgd!

# In spiderpi_core/servo.py
class Servo(RobotComponent):

    def __init__(self, start_id: int, start_angle: float) -> None:
        # 🟨 <-- Je landt hier
        super().__init__(name=f"Servo_{start_id}")
        self._id = start_id
        # ...

Je kunt nu op Continue (F5) drukken om de code af te laten spelen tot het einde.
