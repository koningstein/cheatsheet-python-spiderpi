M3.6: Simple CLI (argparse)

Theorie: De Terminal als Interface

Probleem: Onze main.py is *statisch*. Het doet altijd *exact* hetzelfde (de robot initialiseren). Als we de robot willen laten zwaaien, moeten we de code in main.py *aanpassen* (bv. my_robot.wave() toevoegen).

Oplossing: Een Command-Line Interface (CLI). We willen de robot *commando's* geven als we het script starten vanaf de terminal:
python main.py --action wave
python main.py --action stand --speed 100

De argparse module (standaard in Python) is de professionele manier om deze "argumenten" (de -- vlaggen) te lezen.

Python Stappen (in `main.py`)

We bouwen een 'parser' in main.py die luistert naar commando's.

# In main.py
import argparse
# We importeren de robot nog niet, we printen alleen de args

# 1. Importeer de library
import argparse

# 2. Maak een 'parser' object
parser = argparse.ArgumentParser(description="SpiderPi Robot Controller")

# 3. Vertel de parser welke argumenten je verwacht
parser.add_argument(
    "--action",                     # De naam van de 'vlag'
    type=str,                       # Welk type data verwachten we?
    default="stand",                # Wat is de waarde als men niks invult?
    help="De actie (bv: 'wave', 'stand')" # Help-tekst
)
parser.add_argument(
    "--speed",
    type=int,
    default=50,
    help="Snelheid (0-100)"
)

# 4. Laat de parser de terminal 'lezen'
args = parser.parse_args()

# 5. Gebruik de resultaten (opgeslagen in 'args')
print(f"--- CLI Input Ontvangen ---")
print(f"De gekozen actie is: {args.action}")
print(f"De snelheid is: {args.speed}")

Testen in de terminal:

Sla main.py op en voer deze commando's uit in je terminal (zorg dat je venv actief is).

# Test 1: Zonder argumenten (gebruikt de defaults)
(venv) C:\...> python main.py
--- CLI Input Ontvangen ---
De gekozen actie is: stand
De snelheid is: 50

# Test 2: Met aangepaste argumenten
(venv) C:\...> python main.py --action wave --speed 90
--- CLI Input Ontvangen ---
De gekozen actie is: wave
De snelheid is: 90

# Test 3: De volgorde maakt niet uit
(venv) C:\...> python main.py --speed 75 --action walk
--- CLI Input Ontvangen ---
De gekozen actie is: walk
De snelheid is: 75

# Test 4: De ingebouwde help-functie
(venv) C:\...> python main.py --help
# Output:
# usage: main.py [-h] [--action ACTION] [--speed SPEED]
#
# SpiderPi Robot Controller
#
# options:
#   -h, --help       show this help message and exit
#   --action ACTION  De actie (bv: 'wave', 'stand')
#   --speed SPEED    Snelheid (0-100)
