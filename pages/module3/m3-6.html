M3.6: Simple CLI (argparse)

Theorie: De Terminal als Interface

Probleem: Onze main.py is *statisch*. Het doet altijd *exact* hetzelfde. Als we de robot willen laten zwaaien, moeten we de code in main.py *aanpassen*.

Oplossing: Een Command-Line Interface (CLI). We willen de robot *commando's* geven als we het script starten:
python main.py --action wave --speed 100

De argparse module (standaard in Python) is de professionele manier om deze "argumenten" (de -- vlaggen) te lezen.

Python Voorbeeld (in `main.py`)

We bouwen een 'parser' die luistert naar commando's.

# In main.py
import argparse
from spiderpi_core.robot import SpiderPi

# 1. Maak een 'parser'
parser = argparse.ArgumentParser(description="SpiderPi Robot Controller")

# 2. Vertel welke argumenten je verwacht
parser.add_argument(
    "--action",
    type=str,
    default="stand",
    help="De actie (bv: 'wave', 'stand')"
)
parser.add_argument(
    "--speed",
    type=int,
    default=50,
    help="Snelheid (0-100)"
)

# 3. Laat de parser de terminal 'lezen'
args = parser.parse_args()

# 4. Gebruik de resultaten
print(f"De gekozen actie is: {args.action}")
print(f"De snelheid is: {args.speed}")

De snelheid is: 90

# Test 3 (Help)
(venv) C:\...> python main.py --help
