M3.6: Simple CLI (argparse)

Uitleg: De Terminal als Interface

Probleem: Onze main.py is *statisch*. Het doet altijd *exact* hetzelfde. Als we de robot willen laten zwaaien, moeten we de code in main.py *aanpassen*.

Oplossing: Een Command-Line Interface (CLI). We willen de robot *commando's* geven als we het script starten vanaf de terminal, zoals:
python main.py --action wave

De argparse module (standaard in Python) is de professionele manier om deze "argumenten" (de -- vlaggen) te lezen.

Stap 1: Importeren en de Parser Maken

We beginnen in main.py. We importeren de argparse library en maken een "parser". Dit is het object dat de commando's gaat lezen.

# In main.py
import argparse

# (We importeren de robot nog niet, we printen alleen de commando's)

# 1. Maak een 'parser' object
parser = argparse.ArgumentParser(description="SpiderPi Robot Controller")

Stap 2: Argumenten Definiëren

Nu vertellen we de parser welke "vlaggen" (commando's) we verwachten. We voegen twee argumenten toe: --action en --speed.

# 2. Vertel de parser welke argumenten je verwacht
parser.add_argument(
    "--action",                     # De naam van de 'vlag'
    type=str,                       # Welk type data verwachten we? (tekst)
    default="stand",                # Wat is de waarde als men niks invult?
    help="De actie (bv: 'wave', 'stand')" # Help-tekst
)
parser.add_argument(
    "--speed",
    type=int,                       # Welk type data verwachten we? (getal)
    default=50,
    help="Snelheid (0-100)"
)

Stap 3: Lezen en Printen

Nu geven we de parser de opdracht om de terminal te "lezen" en slaan we het resultaat op in een variabele genaamd args. Daarna printen we wat we hebben ontvangen.

# 3. Laat de parser de terminal 'lezen'
args = parser.parse_args()

# 4. Gebruik de resultaten (opgeslagen in 'args')
print(f"--- CLI Input Ontvangen ---")
print(f"De gekozen actie is: {args.action}")
print(f"De snelheid is: {args.speed}")

# In de volgende les (M3.7) gaan we deze 'args'
# koppelen aan de echte robot-methoden.

Stap 4: Testen in de Terminal

Sla main.py op en voer deze commando's uit in je terminal (zorg dat je venv actief is).

# Test 1: Zonder argumenten (gebruikt de defaults)
(venv) C:\...> python main.py
--- CLI Input Ontvangen ---
De gekozen actie is: stand
De snelheid is: 50

# Test 2: Met aangepaste argumenten
(venv) C:\...> python main.py --action wave --speed 90
--- CLI Input Ontvangen ---
De gekozen actie is: wave
De snelheid is: 90

# Test 3: De ingebouwde help-functie
(venv) C:\...> python main.py --help
# Output:
# usage: main.py [-h] [--action ACTION] [--speed SPEED]
# ... (toont een automatisch help-menu)
