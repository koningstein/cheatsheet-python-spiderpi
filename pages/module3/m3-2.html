M3.2: Docstrings (Documentatie)

Theorie: Documentatie voor Mensen

In Les 3.1 waren Type Hints voor de computer. Docstrings zijn voor mensen (je collega's, je docent, en jezelf over 3 weken).

Een docstring is een string (tussen drie dubbele aanhalingstekens """...""") die je op de allereerste regel binnen een klasse, module of methode plaatst. Het beschrijft wat iets doet.

Het grote voordeel: Je IDE (zoals VS Code) toont deze docstring automatisch als een pop-up helptekst wanneer je de methode probeert te gebruiken.

Stap 1: Module Docstring

Open servo.py. Voeg *bovenaan* het bestand een docstring toe die de hele *module* beschrijft.

"""
Module voor de Servo-klasse.
Bevat de blauwdruk voor een enkele motor.
"""
from .component import RobotComponent
# ... rest van de code

Stap 2: Klasse Docstring

Voeg een docstring toe direct *onder* de class Servo... regel. Het beschrijft wat de klasse doet en welke attributen het heeft.

class Servo(RobotComponent):
    """
    Modelleert een enkele motor (servo) van de SpiderPi.

    Attributen:
        _id (int): Het unieke hardware-ID (1-18).
        _current_angle (float): De interne, afgeschermde hoek.
    """
    _id: int
    # ...

Stap 3: Methode Docstrings (met Args en Returns)

Voeg docstrings toe aan je methoden. We gebruiken speciale keywords (Args:, Returns:, Raises:) die de IDE begrijpt.

def __init__(self, start_id: int, start_angle: float) -> None:
    """
    Initialiseert het Servo object met zijn begin-toestand.

    Args:
        start_id (int): Het hardware-ID van de servo.
        start_angle (float): De beginhoek (wordt gevalideerd).
    """
    super().__init__(name=f"Servo_{start_id}")
    # ...

def set_angle(self, new_angle: float) -> None:
    """
    Stelt de hoek van de servo in, inclusief validatie.

    Args:
        new_angle (float): De gewenste hoek (0.0 tot 180.0).

    Returns:
        None

    Raises:
        ValueError: Als de hoek buiten bereik is.
    """
    if not (self.MIN_ANGLE <= new_angle <= self.MAX_ANGLE):
        # ...

Opdracht: Voeg nu zelf ook docstrings toe aan je @property getters (current_angle en id).

Python Voorbeeld (Eindresultaat in `servo.py`)

Als je klaar bent, is je servo.py nu professioneel gedocumenteerd.

# In spiderpi_core/servo.py

"""
Module voor de Servo-klasse.
Bevat de blauwdruk voor een enkele motor.
"""
from .component import RobotComponent

class Servo(RobotComponent):
    """
    Modelleert een enkele motor (servo) van de SpiderPi.

    Attributen:
        _id (int): Het unieke hardware-ID (1-18).
        _current_angle (float): De interne, afgeschermde hoek.
    """
    _id: int
    _current_angle: float
    MIN_ANGLE: float = 0.0
    MAX_ANGLE: float = 180.0

    def __init__(self, start_id: int, start_angle: float) -> None:
        """
        Initialiseert het Servo object met zijn begin-toestand.

        Args:
            start_id (int): Het hardware-ID van de servo.
            start_angle (float): De beginhoek (wordt gevalideerd).
        """
        super().__init__(name=f"Servo_{start_id}")
        self._id = start_id
        self.set_angle(start_angle)

    def set_angle(self, new_angle: float) -> None:
        """
        Stelt de hoek van de servo in, inclusief validatie.

        Args:
            new_angle (float): De gewenste hoek (0.0 tot 180.0).

        Returns:
            None

        Raises:
            ValueError: Als de hoek buiten bereik is.
        """
        if not (self.MIN_ANGLE <= new_angle <= self.MAX_ANGLE):
            raise ValueError(f"Hoek {new_angle} is ongeldig")
        self._current_angle = new_angle
