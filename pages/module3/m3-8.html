M3.8: Linting (Kwaliteit)

Uitleg: De Spellingscontrole voor Code

Probleem: Onze code werkt, maar is het goede code? Volgen we de professionele standaarden? Hebben we ongebruikte imports? Te lange regels?

Oplossing: Een Linter (zoals pylint). Dit is een tool die je code *leest* en functioneert als een strenge, automatische docent die je code een *cijfer* geeft (op 10).

Het controleert op Fouten (Errors), Waarschuwingen (Warnings, bv. ongebruikte variabele), en Stijl-Afspraken (Conventions, bv. te veel witregels).

Dit is de laatste stap in Module 3 om onze code 'af' te maken: Kwaliteit.

Stap 1: Installeren

We installeren pylint in onze venv en voegen het toe aan onze "boodschappenlijst" (requirements).

# 1. Installeren (in je venv)
(venv) C:\...> pip install pylint

# 2. Toevoegen aan je 'recept' (M2.2)
(venv) C:\...> pip freeze > requirements.txt

Stap 2: De Eerste Analyse (Het Slechte Cijfer)

Draai pylint vanuit je hoofdmap en wijs het naar je spiderpi_core package. Je zult waarschijnlijk een lage score krijgen.

# 3. Analyseren
(venv) C:\...> pylint spiderpi_core

# 4. Voorbeeld Output (je krijgt een 'muur van tekst'):
# ************* Module spiderpi_core.robot
# spiderpi_core\robot.py:3:0: W0611: Unused import time (unused-import)
#
# ************* Module spiderpi_core.leg
# spiderpi_core\leg.py:1:0: C0114: Missing module docstring (missing-module-docstring)
#
# ************* Module spiderpi_core.robot
# spiderpi_core\robot.py:1:0: C0114: Missing module docstring (missing-module-docstring)
#
# -------------------------------------
# Your code has been rated at 3.45/10

De output vertelt ons precies wat er mis is:

  • W0611: Unused import time: In robot.py importeren we time, maar we gebruiken het niet (omdat time.sleep is uitgecommentarieerd).
  • C0114: Missing module docstring: We zijn vergeten bovenaan leg.py en robot.py een docstring te zetten (zoals we in M3.2 wel voor servo.py hebben gedaan).

Stap 4: De Tweede Analyse (Het Resultaat)

Nu we de bestanden hebben opgeslagen, draaien we het commando opnieuw in de terminal.

(venv) C:\...> pylint spiderpi_core

# Nieuwe Output:
#
# -------------------------------------
# Your code has been rated at 8.50/10 (previous run: 3.45/10, +5.05)

Perfect! De "Warning" en "Convention" fouten zijn weg en ons cijfer is flink gestegen. Een 10/10 is niet altijd het doel (soms ben je het niet eens met pylint), maar dit helpt enorm om je code schoon en professioneel te houden.
