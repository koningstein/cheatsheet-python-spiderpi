M3.8: Linting (Kwaliteit)

Theorie: De Spellingscontrole voor Code

Probleem: Onze code werkt, maar is het goede code? Volgen we de professionele standaarden? Hebben we ongebruikte imports? Te lange regels? Verkeerde naamgeving (mijnKlasse i.p.v. MijnKlasse)?

Oplossing: Een Linter (zoals pylint). Dit is een tool die je code *leest* (zonder het uit te voeren) en functioneert als een strenge, automatische docent die je code een *cijfer* geeft (op 10).

Het controleert op Fouten (Errors), Waarschuwingen (Warnings, bv. ongebruikte variabele), en Stijl-Conventies (Conventions, bv. te veel witregels).

Dit is de laatste stap in Module 3 om onze code 'af' te maken: Kwaliteit.

Python Stappen (Terminal)

pylint is een tool die je installeert en draait vanuit de terminal (met je venv actief).

# 1. Installeren (in je venv)
(venv) C:\...> pip install pylint

# 2. Toevoegen aan je 'recept' (M2.2)
(venv) C:\...> pip freeze > requirements.txt

# 3. Analyseren
#    Draai dit commando in de hoofdmap van je project.
#    We wijzen het naar onze 'source' map: de spiderpi_core package.
(venv) C:\...> pylint spiderpi_core

# 4. Voorbeeld Output (je krijgt een 'muur van tekst'):
# ************* Module spiderpi_core.servo
# spiderpi_core\servo.py:1:0: C0114: Missing module docstring (missing-module-docstring)
#    (Oeps! Dit hebben we in M3.2 opgelost, maar misschien was je het
#     vergeten in leg.py?)
#
# spiderpi_core\robot.py:3:0: W0611: Unused import time (unused-import)
#    (In M3.7 hebben we 'import time' toegevoegd, maar daarna
#     hebben we de 'time.sleep()' regels uitgecommentarieerd.
#     De import is nu dus overbodig!)
#
# -------------------------------------
# Your code has been rated at 3.45/10

# 5. De Opdracht:
#    Probeer de makkelijke fouten (C0114, W0611) op te lossen.
#    - Voeg de module docstring toe aan robot.py en leg.py.
#    - Verwijder de 'import time' regel uit robot.py.
#    Draai 'pylint spiderpi_core' opnieuw en kijk hoe je score stijgt!
