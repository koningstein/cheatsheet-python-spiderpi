M3.7: CLI Acties Koppelen (De 'Router')

Uitleg: De 'Router' Bouwen

In de vorige les (M3.6) hebben we de 'input' (args.action) opgevangen. Nu moeten we die input *omzetten* in een *echte robot-actie*.

We hebben: if args.action == "wave": print("Doet niks...")
We *willen*: if args.action == "wave": my_robot.wave()

Dit is de 'controller'-logica. We koppelen de input (de "view") aan ons 'model' (de SpiderPi klasse).

Stap 1: De Actie Methode Maken (in robot.py)

Voordat we de actie kunnen aanroepen, moet de SpiderPi-klasse weten *hoe* hij moet zwaaien. We voegen een wave()-methode toe aan spiderpi_core/robot.py. Deze methode *delegeert* (M1.9) het werk aan de poot rechts-voor. 

# In spiderpi_core/robot.py
# (Zorg dat 'from .leg import Leg' bovenaan staat)

class SpiderPi(RobotComponent):
    # ... (init en andere methoden) ...

    def wave(self) -> None:
        """Laat de robot zwaaien met de poot rechts-voor."""
        print("--- ACTIE: Zwaaien! ---")

        # We gebruiken de 'protected' property _leg_front_r
        # (of de getter 'leg_front_r' als je die hebt)
        poot = self._leg_front_r

        # We delegeren het werk aan de poot
        poot.move_to_angles(hip=90, knee=45, ankle=45)
        poot.move_to_angles(hip=90, knee=90, ankle=90)
        poot.move_to_angles(hip=90, knee=45, ankle=45)
        poot.move_to_angles(hip=90, knee=90, ankle=90)

Stap 2: De Router Bouwen (in main.py)

Nu passen we main.py aan. We importeren de SpiderPi, maken een *echt* robot-object, en bouwen de if/elif-structuur (de 'router') om de args.action te koppelen aan de my_robot.wave() methode.

# In main.py
import argparse
from spiderpi_core.robot import SpiderPi # Importeer de robot

# --- Setup ---
# 1. Maak het robot-object ECHT aan
my_robot = SpiderPi()

# 2. Maak de parser (van M3.6)
parser = argparse.ArgumentParser(description="SpiderPi Robot Controller")
parser.add_argument("--action", default="stand", help="De actie (bv: 'wave', 'stand')")
args = parser.parse_args()


# --- De 'Router' ---
# 3. Koppel de CLI-input aan de robot-methoden
print(f"Actie '{args.action}' wordt uitgevoerd...")

if args.action == "wave":
    my_robot.wave()
elif args.action == "stand":
    print("Actie: Staan... (nog niet geïmplementeerd)")
    # my_robot.stand_up() # (Nog te bouwen)
else:
    print(f"Actie '{args.action}' niet herkend.")
