M3.7: CLI Acties Koppelen

Theorie: De 'Router' Bouwen

In de vorige les (M3.6) hebben we de 'input' (args.action) opgevangen. Nu moeten we die input *omzetten* in een *actie*.

We hebben: if args.action == "wave": print("Doet niks...")
We *willen*: if args.action == "wave": my_robot.wave()

Dit is de 'controller'-logica die de gebruikers-input (de CLI) koppelt aan ons 'model' (de SpiderPi klasse). We moeten hiervoor een wave() methode in onze SpiderPi klasse (robot.py) bouwen.

Python Voorbeeld

1. De Actie bouwen (in robot.py)

# In spiderpi_core/robot.py
from .leg import Leg
import time # Nodig voor de pauzes

class SpiderPi(RobotComponent):
    # ... (init en andere methoden) ...

    def wave(self) -> None:
        """Laat de robot zwaaien met de poot rechts-voor."""
        print("--- ACTIE: Zwaaien! ---")
        # (We gaan ervan uit dat 'leg_front_r' een getter heeft)
        poot = self.leg_front_r

        poot.move_to_angles(hip=90, knee=45, ankle=45)
        # time.sleep(0.5)
        poot.move_to_angles(hip=90, knee=90, ankle=90)
        # time.sleep(0.5)
        poot.move_to_angles(hip=90, knee=45, ankle=45)
        # time.sleep(0.5)
        poot.move_to_angles(hip=90, knee=90, ankle=90)

2. De Router bouwen (in main.py)

# In main.py
import argparse
from spiderpi_core.robot import SpiderPi

# --- Setup ---
my_robot = SpiderPi() # Maak de robot ECHT aan
parser = argparse.ArgumentParser()
parser.add_argument("--action", default="stand")
args = parser.parse_args()

# --- De 'Router' ---
if args.action == "wave":
    # Input ('wave') wordt gekoppeld aan een Methode
    my_robot.wave()
elif args.action == "stand":
    print("Actie: Staan...")
    # my_robot.stand_up() # (Nog te bouwen)
else:
    print(f"Actie '{args.action}' niet herkend.")

Testen in de terminal:

(venv) C:\...> python main.py --action wave
# Output:
# --- ACTIE: Zwaaien! ---
# Poot (ID 1) beweegt...
# Motor 1 beweegt naar 90 gr.
# Motor 2 beweegt naar 45 gr.
# ... (etc)
