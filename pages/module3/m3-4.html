M3.4: Private Properties ('__')

Theorie: Extreem Afschermen (Private)

Dit is het strengste niveau van afschermen. In Python gebruiken we een dubbele underscore (__).

Dit is geen conventie (afspraak) zoals de enkele _, maar een technische ingreep. Python doet aan "Name Mangling" (Naam Verhaspeling).

Python hernoemt de property self.__max_temp achter de schermen naar self._Servo__max_temp. Hierdoor is de property *echt* onzichtbaar voor de buitenwereld én voor 'kind'-klassen (subklassen, zien we in M4).

Wanneer gebruik je dit? Bijna nooit. Alleen voor interne details die je *absoluut* wilt verbergen en waarvan je zeker weet dat niemand (zelfs een kind-klasse) ze mag aanpassen.

Stap 1: Toevoegen aan `servo.py`

We voegen een *nieuwe* interne property __max_temp toe aan de __init__ van Servo.

# In spiderpi_core/servo.py
class Servo(RobotComponent):
    _id: int
    _current_angle: float
    __max_temp: int # Private property

    def __init__(self, start_id: int, start_angle: float) -> None:
        super().__init__(name=f"Servo_{start_id}")
        self._id = start_id
        self._current_angle = start_angle
        self.__max_temp = 80 # Private property (bv. max veilige temp)

    def get_max_temp(self) -> int:
        # Een getter kan er wel bij
        return self.__max_temp

    # ... rest van de klasse

Stap 2: Testen in `main.py`

We proberen de waarde te lezen. De getter *werkt*, maar directe toegang *crasht*.

# In main.py
motor = Servo(1, 90)

# Dit werkt (via de publieke getter):
print(motor.get_max_temp())
# Output: 80

# Dit crasht (de "win" van de les):
print(motor.__max_temp)
# Fout: 'Servo' object has no attribute '__max_temp'

Python Voorbeeld (Volledig)

Hier is de code die je kunt gebruiken om te testen.

# In spiderpi_core/servo.py
class Servo(RobotComponent):
    _id: int
    _current_angle: float
    __max_temp: int # Private property

    def __init__(self, start_id: int, start_angle: float) -> None:
        super().__init__(name=f"Servo_{start_id}")
        self._id = start_id
        self._current_angle = start_angle
        self.__max_temp = 80 # Private property

    def get_max_temp(self) -> int:
        # Een getter kan er wel bij
        return self.__max_temp

# In main.py
motor = Servo(1, 90)

# Dit werkt:
print(motor.get_max_temp()) # Output: 80

# Dit crasht:
# print(motor.__max_temp)
# Fout: 'Servo' object has no attribute '__max_temp'
