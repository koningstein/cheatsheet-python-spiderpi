M2.6: Hoofdprogramma (Absolute Imports)

Theorie: De 'Hoofdingang' Adresboek

Probleem: De imports *binnen* het package zijn gerepareerd (Les 2.5), maar main.py (die *buiten* het package staat) kan robot.py nog steeds niet vinden.

Oplossing: We moeten een Absolute Import gebruiken. We vertellen main.py het *volledige pad* vanaf de hoofdmap: "Kijk in de spiderpi_core package, zoek daarin de robot module, en importeer de SpiderPi klasse."

Python Voorbeeld

We passen main.py aan om de nieuwe package-structuur te gebruiken.

In main.py (in de hoofdmap):

# OUD (crasht):
# from robot import SpiderPi

# NIEUW (werkt):
# Volledig pad: Package.Module
from spiderpi_core.robot import SpiderPi

# --- De rest van de code werkt nu weer ---
my_robot = SpiderPi()
my_robot.leg_front_r.move_to_angles(100, 100, 100)

Als je nu python main.py draait (met je `venv` actief), werkt het project weer volledig. De structuur is nu professioneel.
