M2.5: Relative Imports (Import binnen het package)

Uitleg: Het Probleem (Pakket-intern)

We hebben een spiderpi_core package (map) gemaakt. Daarin zitten nu leg.py en servo.py.

Het bestand leg.py probeert servo.py te importeren met: from servo import Servo. Maar dit crasht.

Uitleg: De Oplossing (Relatief Adres)

Omdat ze samen in een package zitten, moeten we een "relatief adres" gebruiken. We moeten leg.py vertellen: "zoek naar servo.py in de map waar je zelf al in staat."

Dit doen we met een punt (.) voor de bestandsnaam. Dit heet een Relative Import. 

# In spiderpi_core/leg.py

# OUD (crasht):
# from servo import Servo

# NIEUW (werkt):
# De '.' betekent: "zoek servo.py in mijn EIGEN map"
from .servo import Servo

class Leg:
    # ...
    hip_servo: Servo
    # ...

Uitleg: Nog een keer...

Hetzelfde probleem geldt voor robot.py, die leg.py wil importeren. We moeten ook dáár het adres aanpassen. 

# In spiderpi_core/robot.py

# OUD (crasht):
# from leg import Leg

# NIEUW (werkt):
from .leg import Leg

class SpiderPi:
    # ...
    leg_front_right: Leg
    # ...

Uitleg: Status

Super! Nu werkt alle code binnen het spiderpi_core package weer.

MAAR: main.py (die *buiten* de map staat) is nog steeds kapot. Die kan de robot module nog steeds niet vinden. Dat lossen we in de laatste les op.
