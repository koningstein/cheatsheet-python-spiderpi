M2.5: Relative Imports

Theorie: De 'Binnenhuis' Adresboek

Probleem: Nadat we onze modules in de spiderpi_core map (Package) hebben gezet, werkt de code niet meer. leg.py (in de package) kan servo.py (in dezelfde package) niet vinden.

Oplossing: We moeten de imports *binnen* het package "relatief" maken. We gebruiken een punt (.) om te zeggen: "kijk in de map (package) waar ik *zelf* al in sta".

Python Voorbeeld

We passen de import-regels aan in onze package-bestanden.

In spiderpi_core/leg.py:

# OUD (crasht):
# from servo import Servo

# NIEUW (werkt):
# De '.' betekent: "zoek servo.py in mijn EIGEN map"
from .servo import Servo

class Leg:
    _hip_servo: Servo
    # ...

In spiderpi_core/robot.py:

# OUD (crasht):
# from leg import Leg

# NIEUW (werkt):
from .leg import Leg

class SpiderPi:
    _leg_front_r: Leg
    # ...

Let op: main.py zal *nog steeds* crashen. Die repareren we in de volgende les.
