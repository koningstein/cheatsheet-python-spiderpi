M2.3: Modules (Bestanden)

Uitleg: Het Probleem (Chaos)

We kunnen alle code (de Servo klasse, de Leg klasse, de SpiderPi klasse) in één gigantisch main.py bestand schrijven. Het zou werken, maar het is een chaos. Niemand kan dat lezen of onderhouden.

Uitleg: De Oplossing (Modules)

Een Module in Python is simpelweg een .py bestand. Het idee is dat elk bestand (elke module) **één duidelijke taak** heeft.

  • servo.py: Weet alles over één motor.
  • leg.py: Weet alles over één poot.
  • robot.py: Weet alles over de hele robot.
  • main.py: *Gebruikt* de robot (start het programma).

Dit is de projectstructuur die we in Module 1 hebben opgebouwd. 

# Projectstructuur (simpel):
# ├── servo.py
# ├── leg.py
# ├── robot.py
# └── main.py

Uitleg: Modules Gebruiken (Importeren)

Om de Servo klasse (uit servo.py) te kunnen gebruiken in leg.py, moeten we Python vertellen waar hij die blauwdruk kan vinden. Dit doen we met from ... import .... 

# Inhoud van leg.py:

# Vertel Python: "Uit het bestand 'servo', haal de klasse 'Servo'"
from servo import Servo

class Leg:
    # Nu kent Python 'Servo' en kunnen we het hier gebruiken
    hip_servo: Servo
    # ...

Hetzelfde geldt voor main.py, die de SpiderPi klasse uit robot.py moet importeren. 

# Inhoud van main.py:

# "Uit het bestand 'robot', haal de klasse 'SpiderPi'"
from robot import SpiderPi

my_robot = SpiderPi()
my_robot.wake_up()
