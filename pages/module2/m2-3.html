M2.3: Modules (Bestanden)

Theorie: Code Organiseren in Bestanden

Probleem: We kunnen alle code (Servo, Leg, SpiderPi) in één gigantisch main.py bestand schrijven. Het zou werken, maar het is een chaos. Niemand kan dat lezen of onderhouden.

Oplossing: Een Module. In Python is een Module simpelweg een .py bestand. Het idee is dat elk bestand (elke module) **één duidelijke taak** (Single Responsibility) heeft.

  • servo.py weet alles over *één motor*.
  • leg.py weet alles over *één poot*.
  • main.py *gebruikt* de robot.

We 'importeren' de code van de ene module in de andere met from ... import ....

Python Voorbeeld (Structuur)

De structuur die we in Module 1 hebben opgebouwd, is een modulaire structuur.

# Projectstructuur (simpel):
# ├── servo.py
# ├── leg.py
# ├── robot.py
# └── main.py
# In servo.py:
class Servo:
    pass

# In leg.py:
from servo import Servo # Importeert de Servo klasse
class Leg:
    pass

# In main.py:
from robot import SpiderPi # Importeert de SpiderPi klasse
my_robot = SpiderPi()
