M2.2: Dependency Management (requirements.txt)

Uitleg: Het Probleem (Deel 2)

Oké, jouw venv (gereedschapskist) werkt perfect. Nu wil je collega aan hetzelfde project werken. Hoe weet hij precies welke libraries (en welke versies!) hij moet installeren in zijn venv?

Uitleg: De Oplossing (De Boodschappenlijst)

De requirements.txt is een simpele "boodschappenlijst" (of inventaris) van je project. Je maakt deze lijst automatisch met een commando.

Vergelijking (Koken): requirements.txt is het recept. Het vertelt je precies welke ingrediënten (lewansoul-servo-bus==1.0.0) je nodig hebt. 

# Zorg dat je venv actief is (je ziet (venv) vooraan)
(venv) C:\...>

# 1. Genereer de "boodschappenlijst"
(venv) C:\...> pip freeze > requirements.txt

Uitleg: Wat is er gebeurd?

Er is nu een nieuw bestand requirements.txt in je projectmap. Als je dit opent, ziet het er ongeveer zo uit: 

# Inhoud van requirements.txt
lewansoul-servo-bus==1.0.0
numpy==1.26.0
opencv-python==4.8.0
# ... (en misschien nog een paar andere)

Uitleg: De Boodschappenlijst Gebruiken

Jouw collega (of jijzelf, op een nieuwe computer) kan nu deze lijst gebruiken om met één commando exact dezelfde gereedschapskist te krijgen. 

# Op een nieuwe computer:
# 1. Maak en activeer een lege venv (zie M2.1)
(venv) C:\NieuweMap>

# 2. Installeer alles van de lijst
(venv) C:\NieuweMap> pip install -r requirements.txt

# Output:
# Collecting lewansoul-servo-bus==1.0.0
# ...
# Successfully installed lewansoul-servo-bus-1.0.0 numpy-1.26.0 ...
