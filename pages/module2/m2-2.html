M2.2: Dependency Management (requirements.txt)

Theorie: De Inventarislijst

Probleem: Je venv (gereedschapskist) is klaar en je project werkt. Nu wil je collega aan hetzelfde project werken. Hoe weet hij precies welke libraries (en welke versies!) hij moet installeren in zijn venv?

Oplossing: Het requirements.txt bestand. Dit is een simpele inventarislijst (of 'boodschappenlijst') van je project. Je collega kan deze lijst pakken en met één commando (pip install -r requirements.txt) exact dezelfde 'gereedschapskist' krijgen.

  • Vergelijking (Koken): requirements.txt is het recept. Het vertelt je precies welke ingrediënten (lewansoul-servo-bus==1.0.0) je nodig hebt.

Python Voorbeeld (Terminal)

Je maakt de lijst met pip freeze en installeert het met pip install -r.

De lijst genereren:

# Zorg dat je venv actief is
(venv) C:\...> pip install lewansoul-servo-bus

# Genereer de lijst
(venv) C:\...> pip freeze > requirements.txt

Inhoud van requirements.txt is nu:

lewansoul-servo-bus==1.0.0
# ... (en andere dependencies)

De lijst installeren (op een nieuwe computer):

# 1. Maak en activeer een lege venv
(venv) C:\NieuweMap>

# 2. Installeer alles van de lijst
(venv) C:\NieuweMap> pip install -r requirements.txt
# ... installeert lewansoul-servo-bus ...
