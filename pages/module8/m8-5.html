M8.5: AI Logica (Gezicht Deep Dive)

Theorie: De Knoppen van de AI

In M7.4 [cite: 253-254] gebruikten we self._cascade.detectMultiScale(gray_frame). We gebruikten de standaard instellingen. Maar deze methode heeft meer "knoppen" (parameters) om hem te tunen voor betere prestaties.

detectMultiScale(image, scaleFactor, minNeighbors, minSize)

  • scaleFactor (bv. 1.1): Hoeveel het beeld verkleind wordt bij elke 'zoek-pas'.
    • Dichter bij 1.0 = Langzamer, maar vindt *meer* gezichten (ook vage).
    • Groter (bv. 1.3) = Sneller, maar vindt alleen *duidelijke* gezichten.
  • minNeighbors (bv. 5): Hoeveel "stemmen" (buur-rechthoeken) een detectie nodig heeft om te tellen als "echt gezicht".
    • Hoger (8) = Minder *valse* detecties (false positives), maar mist misschien echte gezichten.
    • Lager (3) = Vindt alles, maar ook veel *valse* detecties.
  • minSize (bv. (30, 30)): Negeer alle detecties *kleiner* dan dit (in pixels).

Python Voorbeeld (`vision.py` en `main.py`)

We refactoren FaceDetector zodat we deze 'knoppen' in main.py kunnen instellen.

1. Refactor (in vision.py)

# In spiderpi_core/vision.py
class FaceDetector:
    # ...
    def __init__(self,
                 cascade_xml_path: str,
                 scaleFactor: float = 1.1,
                 minNeighbors: int = 5,
                 minSize: tuple[int, int] = (30, 30)
                 ) -> None:
        self._cascade = cv2.CascadeClassifier(cascade_xml_path)
        if self._cascade.empty():
            raise IOError(f"Kan cascade model niet laden: {cascade_xml_path}")

        # Sla de parameters op
        self._scaleFactor = scaleFactor
        self._minNeighbors = minNeighbors
        self._minSize = minSize

    def analyze_frame(self, frame: np.ndarray) -> ...:
        gray_frame = cv2.cvtColor(frame, cv2.COLOR_BGR2GRAY)

        # Gebruik de opgeslagen parameters
        faces = self._cascade.detectMultiScale(
            gray_frame,
            scaleFactor=self._scaleFactor,
            minNeighbors=self._minNeighbors,
            minSize=self._minSize
        )
