M8.3: Integratie (Gezicht Volgen)

Uitleg: De Camera Bewegen

De SpiderPi heeft een "hoofd" (twee servo's voor de camera). We gaan nu een systeem maken dat een gezicht volgt. Als jij naar links beweegt, draait de robot zijn hoofd mee.

Hiervoor moeten we eerst het hoofd (Head) programmeren.

Stap 1: De Head Klasse

Maak spiderpi_core/head.py. Deze klasse beheert twee servo's: Pan (draaien) en Tilt (knikken). 

# In spiderpi_core/head.py
from .servo import Servo
from .component import RobotComponent

class Head(RobotComponent):
    _pan: Servo
    _tilt: Servo

    def __init__(self, pan_id: int, tilt_id: int):
        super().__init__(name="RobotHead")
        self._pan = Servo(pan_id, 90.0)
        self._tilt = Servo(tilt_id, 90.0)

    def look(self, pan: float, tilt: float) -> None:
        """Beweeg het hoofd."""
        self._pan.set_angle(pan)
        self._tilt.set_angle(tilt)

Stap 2: Robot Updaten

Voeg het hoofd toe aan spiderpi_core/robot.py (in de __init__). 

# In robot.py
from .head import Head

class SpiderPi(RobotComponent):
    _head: Head
    # ...
    def __init__(self):
        # ...
        self._head = Head(19, 20) # Voorbeeld ID's

    @property
    def head(self) -> Head:
        return self._head
