M8.3: Integratie (Gezicht Volgen)

Theorie: De Camera Gimbal Besturen

Probleem: De robot *ziet* een gezicht (M7.4) [cite: 253-254], maar kijkt ernaast. We willen dat de *camera* zelf (die op 2 servos zit, de 'gimbal') beweegt om het gezicht te centreren.

Oplossing:

  1. Refactor FaceDetector: Moet het *midden* (cX, cY) van het (grootste) gezicht teruggeven. return frame, (cX, cY).
  2. Maak CameraGimbal Klasse: Een nieuwe klasse (Compositie) die de 2 camera-servos (vaak ID 19 en 20) bestuurt.
  3. Integratie: De SpiderPi *heeft een* CameraGimbal.
  4. Logica: De main loop krijgt (cX, cY) en stuurt de gimbal aan om de "error" (afstand tot het midden) te minimaliseren.

Python Voorbeeld

1. Nieuwe Klasse (in spiderpi_core/gimbal.py)

from .component import RobotComponent
from .servo import Servo

class CameraGimbal(RobotComponent):
    """Beweegt de 2-assige gimbal van de camera."""
    def __init__(self, id_x: int, id_y: int):
        super().__init__("CameraGimbal")
        self._x_servo = Servo(start_id=id_x, start_angle=90.0)
        self._y_servo = Servo(start_id=id_y, start_angle=90.0)

    def set_angles(self, x_angle: float, y_angle: float):
        try:
            self._x_servo.set_angle(x_angle)
            self._y_servo.set_angle(y_angle)
        except ValueError:
            # Negeer ongeldige hoeken (bv. buiten 0-180)
            pass

3. Refactor (in vision.py)

# In spiderpi_core/vision.py
class FaceDetector:
    # ... (init)
    def analyze_frame(self, frame: np.ndarray) -> tuple[np.ndarray, tuple | None]:
        # ... (detectMultiScale) ...
        if len(faces) > 0:
            (x, y, w, h) = faces[0] # Pak (simpelweg) de eerste
            cv2.rectangle(frame, (x, y), (x+w, y+h), (255, 0, 0), 2)
            # Bereken midden
            cX = x + w // 2
            cY = y + h // 2
            return frame, (cX, cY)
        return frame, None

4. De Loop (in main.py)

# In main.py
# ... (init robot, cam, en FaceDetector) ...
current_x_angle = 90.0
current_y_angle = 90.0

while True:
    frame = cam.get_frame()
    (frame, center) = processor.analyze_frame(frame)

    if center:
        (cX, cY) = center
        # Simpele 'Proportional Controller' (stuur-logica)
        # cX (bv. 320) is het midden van het scherm
        error_x = cX - 320
        error_y = cY - 240

        # Pas de hoek aan o.b.v. de 'error'.
        # De '0.05' is de 'gain' (hoe snel hij reageert)
        current_x_angle -= error_x * 0.05
        current_y_angle += error_y * 0.05

        my_robot.gimbal.set_angles(current_x_angle, current_y_angle)

    cv2.imshow("Face Tracker", frame)
    if cv2.waitKey(1) & 0xFF == ord('q'): break
