M8.6: AI Logica (Gebaar Deep Dive)

Theorie: De Knoppen van 'Vorm'

Net als bij de FaceDetector, heeft onze GestureDetector (M7.5) [cite: 253-254] "magic numbers" die we kunnen 'tunen'.

  1. cv2.threshold(blur, 70, ...): De drempel 70 is *globaal*. Als het lichter of donkerder wordt in de kamer, werkt deze drempel niet meer.
  2. if cv2.contourArea(...) > 5000:: Het getal 5000 is een 'magic number'.

Oplossing 1: Adaptive Thresholding
We vervangen cv2.threshold (globale drempel) door cv2.adaptiveThreshold. Deze berekent de drempel *niet* voor het hele beeld, maar *per regio*. Het past zich aan aan schaduwen en fel licht.

Oplossing 2: Parameter in __init__
We maken min_area=5000 een parameter in de constructor.

Python Voorbeeld (`vision.py`)

We refactoren GestureDetector voor tuning.

# In spiderpi_core/vision.py
class GestureDetector:
    _min_area: int

    def __init__(self, min_area: int = 5000) -> None:
        """Accepteert nu een 'magic number' als parameter."""
        self._min_area = min_area

    def analyze_frame(self, frame: np.ndarray) -> tuple[np.ndarray, bool]:
        gray = cv2.cvtColor(frame, cv2.COLOR_BGR2GRAY)
        blur = cv2.GaussianBlur(gray, (5, 5), 0)

        # OUD:
        # _, thresh = cv2.threshold(blur, 70, 255, cv2.THRESH_BINARY_INV)

        # NIEUW: Adaptive Threshold
        thresh = cv2.adaptiveThreshold(
            blur, 255, # Max waarde
            cv2.ADAPTIVE_THRESH_GAUSSIAN_C, # Methode
            cv2.THRESH_BINARY_INV, # Zwart-wit omgekeerd
            11, # Block size (moet oneven zijn)
            2   # 'C' (een fijnafstelling)
        )

        contours, _ = cv2.findContours(thresh, cv2.RETR_EXTERNAL, cv2.CHAIN_APPROX_SIMPLE)

        gesture_found = False
        if contours:
            biggest_contour = max(contours, key=cv2.contourArea)

            # Gebruik de parameter ipv 'magic number'
            if cv2.contourArea(biggest_contour) > self._min_area:
                cv2.drawContours(frame, [biggest_contour], -1, (0, 255, 0), 3)
                gesture_found = True

        return frame, gesture_found

# --- In main.py ---
