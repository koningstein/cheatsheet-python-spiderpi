M8.7: Code Kwaliteit (Refactoring)

Uitleg: Opruimen

Onze main.py bestanden zijn nu vaak een rommeltje met lange while True loops. Voordat we aan het eindproject beginnen, gaan we opruimen. Dit heet Refactoring.

Stap 1: De Controller Klasse

In plaats van losse code in main.py, maken we een klasse die het gedrag beheert. Maak spiderpi_core/controller.py. 

class RobotController:
    def __init__(self, robot):
        self.robot = robot
        self.is_running = True

    def run(self):
        """De hoofdloop van de applicatie."""
        print("Controller gestart.")
        try:
            while self.is_running:
                self.update()
        except KeyboardInterrupt:
            print("Gestopt.")

Stap 2: Schone Main

Je main.py wordt nu super simpel. 

from spiderpi_core.robot import SpiderPi
from my_smart_controller import SmartController

robot = SpiderPi()
app = SmartController(robot)
app.run()

Uitleg: Waarom?

Door de loop in een klasse te stoppen, kun je makkelijker variabelen (zoals state) bijhouden en methoden maken voor specifieke taken.
