M8.7: Code Kwaliteit (Refactoring)

Theorie: De Grote Schoonmaak

Dit is een *herhaling* van Linting (M3.8) [cite: 245-246] en de introductie van een Formatter (black).

We hebben M6 en M7 [cite: 251-254] er snel 'bijgebouwd'. Er zitten nu waarschijnlijk 'unused imports', 'lines too long', en inconsistent witgebruik in.

  • Formatter (black): Repareert automatisch alle *stijl*-fouten (witregels, komma's, regel-afbreking).
  • Linter (pylint): Klaagt over *logische* fouten (bv. W0611: Unused import cv2) en conventies.

Python Voorbeeld (Terminal)

De opdracht is om de code-score van het project te verhogen.

# 1. Installeer de Formatter (in je venv)
(venv) C:\...> pip install black

# 2. Update je 'recept'
(venv) C:\...> pip freeze > requirements.txt

# 3. Draai 'black' (de Formatter)
#    De '.' betekent 'formatteer alles in deze map'
(venv) C:\...> black .
# Output:
# reformatted spiderpi_core\vision.py
# reformatted spiderpi_core\robot.py
# All done!

# 4. Draai 'pylint' (de Linter) (herhaling M3.8)
(venv) C:\...> pylint spiderpi_core

# 5. Bekijk de output en los handmatig de 'Warnings' op.
#    BV: "W0611: Unused import time" in robot.py
#    Oplossing: Open robot.py en verwijder de 'import time' regel.

# 6. Draai 'pylint' opnieuw
(venv) C:\...> pylint spiderpi_core
# ...
# Your code has been rated at 9.50/10 (hogere score!)
