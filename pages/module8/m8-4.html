M8.4: Integratie (Gebaar Actie)

Theorie: Event-Driven Actie

Dit is een event-driven (gebeurtenis-gestuurd) systeem. We combineren M5 (Acties) [cite: 249-250] en M7 (Vision) [cite: 253-254].

  • Event (Gebeurtenis): De GestureDetector (M7.5) [cite: 253-254] vindt een grote vorm (een 'gebaar').
  • Actie: De WaveAction (M5.4) [cite: 249-250] wordt uitgevoerd.

Refactor: We passen GestureDetector.analyze_frame (M7.5) [cite: 253-254] aan zodat het een boolean (True/False) teruggeeft naast het frame.

2. De Loop (in main.py)

# In main.py
from spiderpi_core.robot import SpiderPi
from spiderpi_core.camera import Camera
from spiderpi_core.vision import GestureDetector
from spiderpi_core.actions import WaveAction
import time

my_robot = SpiderPi()
cam = Camera()
processor = GestureDetector(min_area=10000)
wave_action = WaveAction(my_robot)

is_waving = False # 'Debounce' variabele

print("Starten... Zwaai met je hand om de robot te triggeren.")

while True:
    frame = cam.get_frame()
    if frame is None: break

    # 1. Sense
    (frame, gesture_found) = processor.analyze_frame(frame)

    # 2. Think
    if gesture_found and not is_waving:
        # 3. Act
        print("GEBAAR GEDETECTEERD! Zwaaien...")
        wave_action.execute()
        is_waving = True # Zorg dat hij niet 30x p/s zwaait
        time.sleep(3) # Wacht 3 seconden
    elif not gesture_found:
        is_waving = False # Reset

    cv2.imshow("Gebaar Detector", frame)
    if cv2.waitKey(1) & 0xFF == ord('q'):
        break
cv2.destroyAllWindows()
