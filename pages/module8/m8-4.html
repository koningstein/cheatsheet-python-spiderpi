M8.4: Integratie (Gebaar Actie)

Uitleg: Actie-Reactie

We willen dat de robot wacht op een commando. Niet via het toetsenbord, maar via een visueel gebaar. "Als ik mijn hand opsteek, moet de robot zwaaien."

We gebruiken de GestureDetector uit Module 7 en koppelen die aan de WaveAction.

Stap 1: Detector Uitbreiden

De detector moet onthouden of er iets is gezien. Voeg _detected toe aan GestureDetector in vision.py. 

class GestureDetector:
    _detected: bool = False

    def analyze_frame(self, frame):
        # ... (detectie code) ...

        # Als er een grote contour is:
        if groot_genoeg:
            self._detected = True
        else:
            self._detected = False

    @property
    def detected(self) -> bool:
        return self._detected

Stap 2: De Hoofdloop

In de main loop checken we de status en vuren we de actie af. 

# In main_gesture.py
print("Wachten op gebaar...")

while True:
    frame = my_robot.camera.get_frame()
    gesture_proc.analyze_frame(frame)

    # CHECK: Is er een gebaar?
    if gesture_proc.detected:
        print("Gebaar gezien! Ik zwaai terug!")

        # ACTIE: Zwaai!
        my_robot.wave()

        # Wacht even (zodat hij niet blijft zwaaien)
        time.sleep(2)
        print("Klaar. Wachten...")
