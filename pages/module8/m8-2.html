M8.2: Sturing (Lijnvolgen)

Uitleg: Weten WAAR iets is

Bij het volgen van een lijn is alleen "ja/nee" niet genoeg. We moeten weten of de lijn links, rechts of in het midden is.

We moeten onze LineFollowProcessor (uit M7.3) aanpassen zodat hij de positie onthoudt.

Stap 1: Processor Aanpassen

Open spiderpi_core/vision.py. Voeg een variabele _last_x toe aan de LineFollowProcessor. 

class LineFollowProcessor:
    # Start in het midden (beeld is 640 breed)
    _last_x: int = 320

    # ... (__init__) ...

Stap 2: Positie Opslaan

In de analyze_frame methode berekenen we het midden (cX). Sla dit op! 

    def analyze_frame(self, frame: np.ndarray) -> np.ndarray:
        # ... (code voor mask en moments) ...

        if M["m00"] > 0:
            cX = int(M["m10"] / M["m00"])

            # SLA OP: Hier is de lijn!
            self._last_x = cX

            # ... (tekenen) ...

        return frame

Stap 3: De Getter

Maak de waarde leesbaar voor de buitenwereld. 

    @property
    def last_x(self) -> int:
        return self._last_x

Stap 4: Stuur-Logica

Maak main_line.py. We verdelen het beeld in drie zones. 

# ... (setup robot en line_processor) ...

while True:
    # 1. Haal beeld en analyseer
    frame = my_robot.camera.get_frame()
    if frame is None: break
    line_processor.analyze_frame(frame)

    # 2. Waar is de lijn?
    x = line_processor.last_x

    # 3. Beslis
    if x < 250:
        print("<< STUUR LINKS")
    elif x > 390:
        print(">> STUUR RECHTS")
    else:
        print("^^ RECHTDOOR")
