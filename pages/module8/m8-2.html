M8.2: Sturing (Lijnvolgen)

Theorie: Genuanceerde Sturing

In Les 8.1 was de output een `float` (pixel_count) en de actie `ja/nee` (stoppen). Nu willen we de *positie* van de lijn gebruiken. De LineFollowProcessor (M7.3) [cite: 253-254] vindt het midden (cX, cY) van de lijn.

Refactor: We moeten de LineFollowProcessor.analyze_frame aanpassen zodat het niet alleen het beeld teruggeeft, maar ook de data (het cX coördinaat).
return frame, cX (of return frame, None als geen lijn is gevonden).

De 'Think' Logica: (Uitgaande van een 640px breed beeld)

  • if cX is None: -> Stop!
  • elif cX < 220: -> Lijn is links, stuur links.
  • elif cX > 420: -> Lijn is rechts, stuur rechts.
  • else: -> Lijn is in het midden, ga rechtdoor.

while True:
    frame = cam.get_frame()
    if frame is None: break

    # 1. Sense
    analyzed_frame, cX = processor.analyze_frame(frame)

    # 2. Think & 3. Act
    if cX is None:
        my_robot.stop()
    elif cX < 220: # Zone links (pas 220/420 aan)
        my_robot.turn_left()
    elif cX > 420: # Zone rechts
        my_robot.turn_right()
    else: # Zone midden
        my_robot.walk_forward()

    cv2.imshow("Lijnvolger", analyzed_frame)
    if cv2.waitKey(1) & 0xFF == ord('q'):
        break
