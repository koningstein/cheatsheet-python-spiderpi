M8.8: Eindopdracht (Smart Pet)

Uitleg: Alles Samenvoegen

Je bent klaar om je meesterproef te bouwen. Je gaat een "Smart Pet" maken. De robot moet zelfstandig schakelen tussen gedragingen.

Gedrag: 1. Rust (Idle): Als hij niets ziet, kijkt hij rustig rond. 2. Volgen (Tracking): Als hij een gezicht ziet, focust hij daarop. 3. Groeten: Als hij een hand ziet, zwaait hij. 4. Angst: Als hij rood ziet, doet hij een stap achteruit.

Structuur: State Machine

Gebruik een variabele state om te onthouden wat de robot aan het doen is. 

state = "IDLE"

while True:
    # 1. Verzamel informatie (Sense)
    frame = camera.get_frame()
    face_x = face_detector.analyze(frame)
    is_gesture = gesture_detector.detected
    red_amount = red_sensor.read_value()

    # 2. Bepaal toestand (Think)
    if red_amount > 5000:
        state = "SCARED"
    elif is_gesture:
        state = "GREETING"
    elif face_x is not None:
        state = "TRACKING"
    else:
        state = "IDLE"

    # 3. Voer uit (Act)
    if state == "IDLE":
        head.look_around()
    elif state == "TRACKING":
        head.track(face_x)
    elif state == "GREETING":
        robot.wave()
    elif state == "SCARED":
        robot.step_back()

Succes! Je hebt nu een volledig object-georiënteerde, autonome robot gebouwd.
