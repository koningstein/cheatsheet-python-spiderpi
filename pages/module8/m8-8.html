M8.8: Eindopdracht (Polymorfisme Totaal)

Theorie: De Eindmontage

Dit is de eindopdracht . We bouwen de *definitieve* main.py die alle concepten (CLI, Polymorfisme, Acties, Detectors) combineert tot één flexibel besturingsscript.

De Architectuur:

  1. CLI (argparse): Leest --detector (wat te zien?) en --on-detect (wat te doen?).
  2. main.py (Router):
    • Maakt de juiste VisionProcessor (M7) [cite: 253-254] (de 'stekker').
    • Maakt de juiste AbstractRobotAction (M5) [cite: 249-250] (de 'actie').
  3. Robot (Koppeling): main.py *geeft* de processor en de actie aan de robot.
  4. Robot.run_loop(): De robot handelt de 'Sense-Think-Act' loop (M8.1) intern en polymorfisch af.

Python Voorbeeld

1. Refactor (in robot.py)

Maak een 'hoofd-loop' in de robot die de actie uitvoert.

# In spiderpi_core/robot.py
# ... (imports)
from .actions import AbstractRobotAction
from .vision import VisionProcessorProtocol

class SpiderPi(RobotComponent):
    # ... (init, set_vision_processor, etc.) ...

    def run_vision_loop(self, action_on_detect: AbstractRobotAction) -> None:
        """
        De definitieve 'Sense-Think-Act' loop.
        Voert de gegeven 'action' uit als de 'processor' iets vindt.
        """
        if not self._camera or not self._processor:
            print("Fout: Camera of Processor niet ingesteld.")
            return

        print("Vision loop gestart. Druk 'q' om te stoppen.")
        while True:
            frame = self._camera.get_frame()
            if frame is None: break

            # 1. Sense (Polymorfisch)
            processed_frame, data = self._processor.analyze_frame(frame)

            # 2. Think
            if data:
                # 3. Act (Polymorfisch)
                # We geven de data (bv. (cX, cY)) mee aan de actie
                action_on_detect.execute(data)

            cv2.imshow("SpiderPi Vision", processed_frame)
            if cv2.waitKey(1) & 0xFF == ord('q'):
                break
        cv2.destroyAllWindows()

2. Refactor (in actions.py)

Pas het execute contract (M5.2) aan zodat het data kán accepteren.

# In spiderpi_core/actions.py
class AbstractRobotAction(ABC):
    @abstractmethod
    def execute(self, data=None) -> None: # 'data=None' toegevoegd
        pass

class WaveAction(AbstractRobotAction):
    def execute(self, data=None) -> None: # 'data=None' toegevoegd
        self._robot.wave()

3. De Eindbaas (in main.py)

# In main.py
# ... (alle imports: argparse, robot, camera, vision, actions, numpy)

def main():
    # 1. CLI (argparse)
    parser = argparse.ArgumentParser()
    parser.add_argument("--detector", default="face", help="face, color, line, gesture")
    parser.add_argument("--on-detect", default="wave", help="wave, aim, ...")
    args = parser.parse_args()

    # Setup
    my_robot = SpiderPi()
    processor = None
    action = None

    # 2. Processor Factory (Stekker kiezen)
    if args.detector == "face":
        processor = FaceDetector("haarcascade_frontalface_default.xml")
    elif args.detector == "color":
        LOWER_RED = np.array([0, 120, 70])
        UPPER_RED = np.array([10, 255, 255])
        processor = ColorDetector(LOWER_RED, UPPER_RED)
    # ... (elif voor line en gesture) ...

    # 3. Action Factory (Actie kiezen)
    if args.on_detect == "wave":
        action = WaveAction(my_robot)
    # elif args.on_detect == "aim":
    #    action = AimAction(my_robot) # (Nog te bouwen)

    # 4. Koppelen & 5. Uitvoeren
    if processor and action:
        my_robot.set_vision_processor(processor)
        my_robot.run_vision_loop(action)
    else:
        print("Fout: Kon detector of actie niet vinden.")

if __name__ == "__main__":
    main()
