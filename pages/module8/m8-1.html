M8.1: Integratie (Stop op Rood)

Theorie: De 'Sense-Think-Act' Loop

Dit is de meest fundamentele loop in robotica. We combineren concepten uit eerdere modules tot één werkend geheel.

  1. Sense (Zien): We gebruiken de ColorVisionSensor (M7.7) [cite: 253-254] om een *getal* (aantal pixels) te lezen.
  2. Think (Denken): We gebruiken een simpele if-statement om dat getal te vergelijken met een drempel (threshold).
  3. Act (Doen): We roepen een AbstractRobotAction (M5.3) [cite: 249-250] aan om de robot te laten reageren.

We bouwen een while-loop in main.py die de robot een actie laat uitvoeren (bv. zwaaien) *totdat* hij 'rood' ziet, en dan stopt.

Python Voorbeeld (`main.py`)

We bouwen een script dat stopt zodra het 'rood' ziet.

# In main.py
import numpy as np
import time
from spiderpi_core.robot import SpiderPi
from spiderpi_core.camera import Camera
from spiderpi_core.sensors import ColorVisionSensor
from spiderpi_core.actions import WaveAction # (Uit M5.4)

# --- 1. Sense (Setup) ---
# Definieer de grenzen voor rood (herhaling van M7)
LOWER_RED = np.array([0, 120, 70])
UPPER_RED = np.array([10, 255, 255])
# De 'drempel': hoeveel rode pixels telt als 'stop'
RED_THRESHOLD = 5000

# --- 3. Act (Setup) ---
my_robot = SpiderPi()
wave_action = WaveAction(my_robot)
# We hebben de camera nodig voor de sensor
cam = Camera()
red_sensor = ColorVisionSensor(cam, LOWER_RED, UPPER_RED)

print("Starten... Hou iets roods voor de camera om te stoppen.")

# --- De Sense-Think-Act Loop ---
while True:
    # 1. Sense
    pixel_count = red_sensor.read_value()
    print(f"Rode pixels: {pixel_count}")

    # 2. Think
    if pixel_count > RED_THRESHOLD:
        print("ROOD GEDETECTEERD! Stoppen.")
        break # Stopt de while-loop

    # 3. Act (als 'Think' niet stopt)
    print("Actie: Zwaaien... (geen rood gezien)")
    wave_action.execute()

    time.sleep(1) # Wacht 1 seconde

print("Programma gestopt.")
