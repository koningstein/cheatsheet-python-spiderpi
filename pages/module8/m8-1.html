M8.1: Integratie (Stop op Rood)

Uitleg: De Reflex

We beginnen met een simpele reflex: "Als ik rood zie, stop ik meteen." We gebruiken hiervoor de ColorVisionSensor uit Module 7.

We maken een nieuw bestand main_reflex.py. Eerst importeren we alles en maken we de robot. 

# main_reflex.py
import time
import numpy as np
from spiderpi_core.robot import SpiderPi
from spiderpi_core.sensors import ColorVisionSensor
from spiderpi_core.actions import WalkAction

# 1. Maak de robot
my_robot = SpiderPi()

Uitleg: De Sensor Instellen

Nu maken we de "rode" sensor aan. We vertellen hem welke kleur hij moet zoeken (HSV). 

# 2. Definieer Rood (HSV)
LOWER_RED = np.array([0, 120, 70])
UPPER_RED = np.array([10, 255, 255])

# 3. Maak de sensor (gekoppeld aan de camera)
red_sensor = ColorVisionSensor(my_robot.camera, LOWER_RED, UPPER_RED)

# 4. Maak een actie (om te testen)
walker = WalkAction(my_robot)

Uitleg: De Loop

Nu maken we de "hersenen". Een oneindige loop die kijkt en beslist. 

print("Reflex test gestart. Ctrl+C om te stoppen.")
try:
    while True:
        # A. Waarnemen (Sense)
        pixels = red_sensor.read_value()
        print(f"Rood niveau: {pixels}")

        # B. Beslissen (Think)
        if pixels > 5000:
            # C. Doen (Act) - STOP
            print("STOP! Gevaar!")
            # my_robot.stop()
        else:
            # C. Doen (Act) - GA
            print("Veilig. Lopen...")
            walker.execute()

        time.sleep(0.1)
except KeyboardInterrupt:
    print("Gestopt.")

Uitleg: Resultaat

Als je dit script draait en iets roods voor de camera houdt, zie je de tekst veranderen. De robot reageert op zijn omgeving!
